先学 20 张

只想建立大模型工程的完整骨架，先读这 20 张：模型 → 推理 → 上下文与检索 → 智能体与评测 → 生产，2–4 小时。这里不出现具体框架、源码拆解和前沿实践；读完 接着走主干 42。

学完这 20 张，你会：
  • 讲清模型怎么算出下一个 token：注意力机制、架构选型、token 计费、采样参数，以及 KV Cache 为什么让显存随序列增长
  • 解释推理为什么又慢又贵：prefill / decode 两阶段的资源画像、并发下吞吐与延迟怎么互相咬、量化的显存与精度档位
  • 设计一套 RAG 的上下文供给：分清「怎么说」和「给什么」，说清分层架构、混合检索、重排买到的增益和吃掉的延迟
  • 搭出并评估一个最小 Agent 闭环：模型、工具、记忆、停止条件齐备，评测时先评检索再评回答
  • 上线前留好几手：五段架构全景、延迟 / 吞吐 / 成本三本账、API 的超时重试限流降级、Prompt 注入防护
