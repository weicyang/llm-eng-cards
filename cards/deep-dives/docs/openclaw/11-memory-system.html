3. 核心概念与术语

Markdown 资产人类可直接审阅和修改的知识。它是内容权威，不是数据库投影。
Source索引来源类别，当前规范值为 memory 与可选 sessions；默认只含 memory。
Chunk带 path、source、行范围、hash、model、text、embedding 的检索单元。
Index identityprovider/model/providerKey、source、scope、chunk 参数、vector dims、FTS tokenizer 的一致性指纹。
FTS / Vector / Path正文 BM25、语义相似度、文件路径精确度是三个信号；path exactness 形成优先 tier。
Shadow publish在临时 DB 完整构建，校验 live revision 后在短事务内替换 memory-owned tables。
Flushcompaction 前的一次受限 housekeeping turn，只能 read 与 append daily memory。
Dreaming / Promotion可选后台整理：积累 grounded recall signal，重读真实源行，达到门槛后写入长期 MEMORY.md。

5. 完整运行流程

5.1 成功：一次 builtin 检索

  1. 工具从可信 run context 解析 agent、session、sandbox 与可搜索 corpus；模型提供的 corpus 只能收窄，不能扩大 trusted recall。extensions/memory-core/src/tools.ts:451-487
  2. manager 确认 index identity；必要时执行同步。source 文件切成带行号 chunk，embedding cache 避免重复请求。
  3. query embedding 与 FTS/path 查询并行取候选；sqlite-vec 使用 MATCH ? AND k = ?，后过滤不足时扩大或回到 bounded scan。extensions/memory-core/src/memory/manager-search.ts:414-490
  4. vector/text 加权；exact full path、basename、stem 按 specificity 3/2/1 固定在普通结果之前。extensions/memory-core/src/memory/manager-search.ts:139-161、extensions/memory-core/src/memory/hybrid.ts:238-252
  5. 可选 decay/MMR 只重排 tier 内结果；session hits 再通过 visibility guard；最后附 citation 并受 injected-char cap。extensions/memory-core/src/tools.ts:719-759

5.2 拒绝：跨会话隐私 fail-closed

conversation recall 只有在非 sandbox、scope 为 same-agent-private、requester 是 anchor 或受控 active-memory 子会话、anchor 与所有 alias 都是同 agent 私聊时成立。任一 alias 指向 group/channel 即拒绝；当前 transcript 本身也按 identity 排除。extensions/memory-core/src/session-search-visibility.ts:157-225、extensions/memory-core/src/session-search-visibility.ts:227-275

5.3 恢复：shadow reindex

identity 不匹配 / 强制 / retry-dirty → 获取 reindex 锁 + 捕获 live revision → 创建临时 agent DB → 在 live DB 外重建 sources/chunks/FTS/vector → 关闭临时 DB → ATTACH temp + BEGIN IMMEDIATE → 验证 revision 未变 → 替换 memory 拥有的表 + meta → 提交，标记 vector 干净，删除临时文件 提交前失败 → 恢复 live handles + 标记 retry dirty revision 已变 → 拒绝发布并稍后重试

extensions/memory-core/src/memory/manager-sync-ops.ts:363-530；publish transaction：extensions/memory-core/src/memory/manager-db.ts:136-235。

5.4 Flush、Dreaming、Grounded backfill、Promotion

Flush 配置默认开启，但只有 compaction 压力、阈值和 cycle gate 满足时才构造只写当日 memory/YYYY-MM-DD.md 的 append-only turn；MEMORY.md、DREAMS.md 与 bootstrap 文件明确只读。Dreaming 默认是可选能力：recall、daily 与 grounded signal 写入 plugin state，Cron 运行 sweep；候选按频率、相关性、多样性、时效、巩固、概念信号评分。真正 promotion 前重新读取源文件并迁移行范围；找不到原文、落入 managed dreaming fence 或疑似 prompt/转录污染即拒绝。extensions/memory-core/src/flush-plan.ts:12-43、extensions/memory-core/src/flush-plan.ts:97-136；extensions/memory-core/src/short-term-promotion.ts:1388-1669、extensions/memory-core/src/short-term-promotion.ts:2308-2344、extensions/memory-core/src/short-term-promotion.ts:2487-2678

9. 并发、性能与资源

  • sqlite-vec native KNN 候选 oversample 8 倍，k 上限 4096；过滤后覆盖不足时扩大，仍不足则 bounded scan。extensions/memory-core/src/memory/manager-search.ts:20-28、extensions/memory-core/src/memory/manager-search.ts:452-490
  • fallback scan 每 256 行 yield 一次，避免阻塞 Channel I/O 与 liveness。extensions/memory-core/src/memory/manager-search.ts:493-575
  • full reindex 在 shadow DB 做昂贵工作，只把 publish 放入短同步 SQLite transaction；live revision 防止覆盖并发增量更新。extensions/memory-core/src/memory/manager-sync-ops.ts:363-488
  • watch 使用平台原生目录粒度优先，避免大树 per-file watcher fan-out；压力过高发 warning。extensions/memory-core/src/memory/manager-watch-ops.ts:146-203
  • 工具检索有 deadline、manager cache 与 60 秒失败 cooldown；cleanup 为 best-effort，不隐藏已得到结果。extensions/memory-core/src/tools.ts:68-171

10. 安全与信任边界

  1. Corpus 不由模型扩权。未知 corpus 枚举 fail-closed；trusted runtime 可强制 sessions，模型参数不能扩大 trusted recall。extensions/memory-core/src/tools.ts:72-90、extensions/memory-core/src/tools.ts:479-487
  2. Session recall 双门。先要求有效 session visibility，再要求 same-agent-private anchor 与所有 aliases 都是私聊；sandbox 禁止 protected recall。extensions/memory-core/src/session-search-visibility.ts:165-220
  3. Exact get 不是通用 read。路径由 memory manager 解析到已注册 corpus；任意 workspace/host 文件不属于工具契约。
  4. Promotion 必须 grounded。写 MEMORY.md 前重新读 source、重定位 line range、拒绝 fenced dreaming 与 prompt/transcript 污染。extensions/memory-core/src/short-term-promotion.ts:2308-2344、extensions/memory-core/src/short-term-promotion.ts:2510-2544
  5. 文件权限。promotion 原子替换目标、保留既有 mode，新文件 0600；只有真实权限失败且现有文件可写才保留 in-place compatibility。extensions/memory-core/src/short-term-promotion.ts:2593-2639

11. 失败、恢复与兼容

现象即时行为状态影响恢复

15. 设计权衡与已知限制

选择收益成本/限制重新评估条件
Markdown 权威 + SQLite 派生透明、可编辑、可备份；索引可重建。需要 watch/sync，短期可能 stale。内容规模使文件资产不可维护。
Hybrid 三信号兼顾语义、精确词和文件名。分数跨 backend 不可直接比较。统一校准模型可证明更好。
MMR/decay 默认关闭保持稳定排序，不擅自偏新或多样。大历史可能重复或陈旧。按数据集证明默认开启净收益。
Shadow reindex失败不破坏 live index，publish 短。临时占用额外磁盘与一次完整构建。索引规模超出单机影子副本成本。
插件边界QMD/Honcho/LanceDB/wiki 可独立演进。能力与隐私契约不完全等价。形成可证明的统一 memory capability contract。
