一句话目标：Context Engineering 把持久 Session、当前输入、System Prompt、Workspace Bootstrap、Tool Schema、Attachment 和动态 hook 内容投影成满足模型窗口与 Provider 约束的一次调用；它通过缓存边界、清洗、裁剪、压缩和诊断控制成本，但不把“上下文”误等同于“记忆”。

3. 核心概念与术语

Context window当前模型单次可接收的总 token 上限；不是 Session 的无限历史容量。
Prompt budgetcontext window 扣除 output/compaction reserve 与固定 prompt 后留给 messages 的预算。
System PromptOpenClaw 每 run 由显式输入渲染的规则、工具、技能、workspace、Project Context 与 runtime 信息。
Cache BoundarySYSTEM_PROMPT_CACHE_BOUNDARY 把稳定字节前缀与 channel/session/clock 等动态后缀分开。
Bootstrap / Project Context从 workspace 发现并有界注入的 AGENTS、SOUL、TOOLS、IDENTITY、USER、HEARTBEAT、BOOTSTRAP、MEMORY。
History sanitization在 replay 前按 Provider/Transcript policy 修复 reasoning、tool pairing、images、usage 和顺序。
Pruning只改变本次内存 prompt 的旧 tool result；通常不重写 transcript。
Compaction把较早 conversation 语义压缩为 summary，并把新 transcript 视图持久化。
Memory Flush压缩前可选、静默、受限工具的 housekeeping turn，把耐久事实写入 memory 文件。
Context Engine独占 slot 的 assemble/compact/lifecycle owner；默认 legacy 是 pass-through + runtime compaction adapter。

5. 完整运行流程

5.1 成功路径：一次普通 Embedded turn

解析模型 context window + reserve → 发现/过滤 bootstrap 文件 → 执行单文件 + 总预算限制；构建截断 report/warning → 构建稳定 System Prompt 前缀 → 追加 cache boundary + 动态 channel/runtime/hook 段落 → 加载 Session 活跃 history → 清洗 provider replay + 校验 turns + 限制 history + 修复 pairs → ContextEngine.assemble(messages, messageBudget, prompt) → 前置可选 systemPromptAddition → 截断过大的实时 tool result；附加隐藏 runtime context → 归一化当前 LLM boundary → 检测/加载/清洗 attachments → provider 接收 system + messages + tool schemas + media → afterTurn/ingest + 可选维护 → 持久化仅含 metadata 的 SystemPromptReport

Message budget 是 context budget 扣除 compaction reserve 和渲染后 fixed prompt token 后的结果；ContextEngine 返回值还会再次 repair tool-use/result pairing。src/agents/embedded-agent-runner/run/attempt-history-prepare.ts:199-269；src/agents/harness/context-engine-lifecycle.ts:140-218

5.2 拒绝/提前结束路径：Context Engine 不可安全运行

解析 plugins.slots.contextEngine → 缺失 / 仅只读 / factory 抛错 / 无效 contract → 自定义 engine 被隔离 → 解析 core 默认 "legacy" → 继续正常 turn 声明的 hostRequirements 未满足 → backend 启动前 fail closed → 不静默部分组装

Custom engine 的普通运行异常会触发进程期 quarantine；后续 guarded call 使用 legacy。Abort 是调用者意图，不会把 engine 判坏。compact() 与 subagent preparation 的失败不在同一调用中静默重跑 fallback，以免重复不可逆工作。src/context-engine/registry.ts:801-892、src/context-engine/registry.ts:906-1024

5.3 恢复路径：Provider 报 context overflow

prompt/assistant 被分类为 context overflow → 发出 context-overflow-diag（source、messages、estimates、payload bytes） → 若本次 attempt 已发生 compaction：有界重试（≤3） → else ContextEngine.compact(force=true, target=budget) → 压缩成功？采用 successor transcript + 维护 + 重试 → precheck 路由可能额外截断过大的 tool result → 若 compaction 无操作且 token snapshot 过期：重置 snapshot + 重试 → 否则执行一次 tool-result 截断恢复 → 耗尽：提示 reset/new/更大 context 的指引

Context overflow 不进入第 9 章模型 fallback；换到更小窗口模型可能更糟。恢复最多三轮 overflow compaction/retry，并在最终失败时明确标记 context_overflow 或 compaction_failure。src/agents/embedded-agent-runner/run/overflow-context-recovery.ts:106-206、src/agents/embedded-agent-runner/run/overflow-context-recovery.ts:273-456；src/agents/model-fallback.ts:1858-1865

9. 并发、性能与资源

  • 稳定 System Prompt prefix 按所有稳定输入 hash，LRU-like 上限 64；动态 channel/session 信息严格放在 boundary 下。src/agents/system-prompt.ts:87-168、src/agents/system-prompt.ts:1037-1079、src/agents/system-prompt.ts:1297-1313
  • Tool schema report 使用 WeakMap 缓存 schema size/hash，不重复 JSON stringify 稳定 tool definitions。src/agents/system-prompt-report.ts:14-20、src/agents/system-prompt-report.ts:51-98
  • Bootstrap 注入有 per-file/total 双预算，warning signature history 最多 32；不会把无限 workspace 文本塞入每个 turn。
  • Pruning 先软裁旧 tool result，再在整体压力和可裁字符达到门槛时 hard clear；保护最近 assistant tail 和首个 user 之前的 bootstrap reads。src/agents/agent-hooks/context-pruning/pruner.ts:294-416
  • Compaction 和 transcript rewrite 受 Session write lock/owner 保护；Context Engine 可把 turn maintenance 声明为 background，但 reply 不等待未要求的维护。
  • 图片在读取后 sanitize/缩放并受 root、size、sandbox bridge 限制；历史图片还有独立 prune transform。

10. 安全与信任边界

  1. Project Context 是指令输入，不是授权：AGENTS/TOOLS/Skill 不能授予不存在或被 policy deny 的工具。
  2. Bootstrap 路径：hook 返回路径先规范化、去重；缺失/非法 path 跳过并告警。src/agents/bootstrap-files.ts:169-197、src/agents/bootstrap-files.ts:290-337
  3. Attachment：拒绝 Windows network path、NUL/path traversal；sandbox 使用 bridge 验证，HTTP(S) refs 不作为本地自动注入。src/agents/embedded-agent-runner/run/images.ts:58-81、src/agents/embedded-agent-runner/run/images.ts:421-470、src/agents/embedded-agent-runner/run/images.ts:481-542
  4. History provenance：跨 Session user 消息会标注来源；内部 runtime custom messages 在交给 Context Engine 前剥离。src/agents/embedded-agent-runner/replay-history.ts:115-180；src/agents/harness/context-engine-lifecycle.ts:165-179
  5. Plugin owner：legacy id core-only；插件经公开 SDK 注册，冲突或 invalid contract 被隔离。
  6. 报告脱敏：Context report 记录长度与 hash，不 dump 完整 System Prompt、Tool Schema 或 secret。

11. 失败、恢复与兼容

故障/现象检测即时行为恢复
Bootstrap 文件过大/context TRUNCATED + prompt warning。有界注入；源文件不变。精简/按需 read，或有意提高预算。
History 跨 Provider 不合法sanitize/validate hook。修 reasoning、turn order、tool IDs/pairs、images；不可修时拒绝。检查 provider replay policy/测试。
Tool result 过大prompt-pressure log/precheck。本次截断；必要时 overflow 后重写 active target。让工具分页/摘要；启用适当 pruning。
Custom engine missing/invalid/throwscontext-engine log/quarantine health。进程期 quarantine，降级 legacy。修 plugin 并重启/清 quarantine。
Host 不满足 engine requirementsoperation preflight。fail-closed，不启动 backend。换支持的 Harness/host 或 legacy。
Context overflowprovider error + precheck/token estimate。compaction → retry → tool truncation。耗尽后 /reset//new/更大窗口。
Compaction 无真实 conversationcompact no-op + preflight stale token。重置 stale token snapshot 并重试。检查 report 与 Session token freshness。
Memory Flush 失败flush failure count/notice。有界重试；不让路径逃出 workspace。修 memory plan/model/write 权限；必要时继续降级 compaction。

禁止捷径：不要把动态时钟/channel 放到 stable prefix；不要让 ContextEngine 深导入 runner internals；不要把 Pruning 当持久删除；不要把 Memory Flush 当 Compaction；不要用 model fallback 掩盖 context overflow；不要为了“估算准确”记录完整 prompt、schema 或 secret。

15. 设计权衡与已知限制

选择收益成本/限制
Stable/dynamic cache boundaryWorkspace 大前缀可跨 turn 复用。每个新动态字段必须正确放置和计入 cache key。
字符预算 + token estimate快速、跨模型、可预检。无法完全复制每个 Provider tokenizer/hidden wrapper。
Bootstrap 自动注入Agent 持续获得 persona/policy/workspace context。大文件是固定税；截断可能隐藏关键细节。
Pruning 非持久低风险减压，保留可审计 transcript。下一 turn 可能重新计算；不能替代长期压缩。
Compaction 持久摘要长期 Session 可继续。摘要有信息损失，需要 pairing、identifier、quality guard。
Exclusive Context Engine slot单一 assembly/compaction owner，避免多 engine 争写。切换 engine 是产品行为；插件必须承担完整 compact 契约。
Quarantine → legacy可选 plugin 故障不让回复整体沉默。行为会降级；必须通过日志/health 暴露，不能长期忽略。
当前限制：src/agents/system-prompt.ts、Context Engine registry 与 overflow recovery 都是复杂大文件；重构应保持单一 assembly owner、cache byte stability、Session write ownership 和重试收敛，不应为了拆文件创建第二条 prompt/compaction 路径。
