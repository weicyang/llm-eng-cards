1. 模块定位：扩展的是契约，不是内部偶然结构

第 18 章负责跨包回答三个问题：扩展点由谁拥有、实现者必须保持什么不变量、需要哪些测试才足以声称“兼容”。它不重复讲 StateGraph、Pregel、持久化、Streaming 或远程 SDK 的完整实现；这些模块只在决定扩展边界时被引用。

2. 系统位置与依赖：从业务扩展到真正副作用

调用方 ├─ StateGraph / Functional API │ ├─ Channel ──► step 屏障后的状态合并 ──► Checkpointer │ ├─ Node + CachePolicy ──► BaseCache │ └─ ToolNode ──► wrapper ──► Tool / 外部系统 ├─ stream_events(version="v3") │ └─ StreamMux ──► StreamTransformer ──► extensions / StreamChannel └─ langgraph.json ──► CLI 校验与容器路径重写 └─ 仓库外 API Server ──► Auth / Encryption handlers 独立持久边界 ├─ Checkpointer：thread 执行位置与恢复 ├─ Store：跨 thread 的业务记忆 └─ Cache：由输入 key 命中的节点结果
核心包方向

langgraph 1.2.11 声明依赖 checkpoint >=4.1,<5、sdk >=0.4.2,<0.5、prebuilt >=1.1,<1.2。扩展发布不能只固定核心包而忽略这些窗口。libs/langgraph/pyproject.toml:5-33

持久化兄弟实现

SQLite 3.1.1 与 Postgres 3.1.2 都声明 checkpoint >=4.1,<5，并在测试依赖中引入 conformance。libs/checkpoint-sqlite/pyproject.toml:5-35；libs/checkpoint-postgres/pyproject.toml:5-36

运行进程边界

Tool wrapper 在节点执行进程内包围工具；Saver/Store/Cache 由本地 Runtime 调用；Auth/Encryption 的实际消费方是仓库外 Server。不要让领域节点反向 import CLI 内部函数。

SDK-JS 证据边界

当前工作区没有可审计的 libs/sdk-js/package.json；因此本章不给出 JS SDK 版本或 Auth/Encryption 等价实现承诺，只陈述 Python SDK 和 CLI 当前代码。

3. 核心概念：四种存储、两种拦截、一个所有权原则

概念精确定义最常见混淆
ChannelState key 的值容器、update 合并器和可 checkpoint 状态机；update(values) 在每个 step 末被调用，输入顺序被契约声明为任意。libs/langgraph/langgraph/channels/base.py:89-99不是多个节点即时共享修改的 dict。
Checkpointer按 thread_id + checkpoint_ns + checkpoint_id 保存 checkpoint、metadata 与 task pending writes；无 thread_id 不能可靠恢复。libs/checkpoint/langgraph/checkpoint/base/__init__.py:182-192不是跨用户业务知识库。
Store以任意层级 namespace 组织、跨 thread 共享的持久 KV，batch/abatch 是实现者最小核心。libs/checkpoint/langgraph/store/base/__init__.py:708-745不是 checkpoint，也不自动参与 replay。
Cache以 (namespace,key) 批量读取/写入节点结果，entry TTL 单位由 BaseCache.set 契约传入为秒数；策略 TTL 也是秒。libs/checkpoint/langgraph/cache/base/__init__.py:10-38；libs/langgraph/langgraph/types.py:524-529命中只复用结果，不证明外部副作用发生过一次。
Tool wrapper围绕单个 tool call 的策略函数，可零次、一次或多次调用 execute，并返回 ToolMessage 或 Command。libs/prebuilt/langgraph/prebuilt/tool_node.py:202-217多次 execute 就是多次真实工具副作用，除非工具自身幂等。
StreamTransformer观察 ProtocolEvent 并产生 typed projection；process/aprocess 的布尔返回值决定事件是否保留在主事件日志。libs/langgraph/langgraph/stream/_types.py:127-184不是改变图状态的 reducer，也不应把 projection 当 checkpoint。
所有权谁定义数据生命周期、顺序、错误和兼容语义，谁就是 Owner；扩展只能实现公开协议，不应复制私有调度或服务端行为。“能 import”不等于“稳定公共契约”。

4. 架构组成：逐扩展面实现契约

4.1 自定义 Channel

必须实现 ValueType、UpdateType、from_checkpoint、get、update。空 Channel 的 get() 抛 EmptyChannelError；默认 checkpoint() 把空状态编码为 MISSING；默认 copy() 走 checkpoint round-trip，因此复杂对象必须在恢复时复制，不能共享可变引用。libs/langgraph/langgraph/channels/base.py:28-65

禁止依赖 update 顺序。values 的顺序明确是 arbitrary。若业务要求顺序，应把顺序编码进 update 并显式排序，或证明 reducer 具备所需结合/交换性质；不能依赖线程完成先后。libs/langgraph/langgraph/channels/base.py:90-99

4.2 自定义 Saver

基础 async 能力是 aput、aput_writes、aget_tuple、alist、adelete_thread；copy、按 run 删除、prune 与 delta history 是可选扩展。Conformance 通过“方法是否覆盖基类”检测能力，因此空壳 override 会使测试启动后失败，而不是安全降级。libs/checkpoint-conformance/langgraph/checkpoint/conformance/capabilities.py:29-63

put_writes 属于 task 级中间写，put 属于超级步 checkpoint；二者不能合并成同一“保存函数”。同一 (task_id, idx) 重放必须幂等，pending writes 还必须按 checkpoint namespace 隔离。libs/checkpoint-conformance/langgraph/checkpoint/conformance/spec/test_put_writes.py:148-167；libs/checkpoint-conformance/langgraph/checkpoint/conformance/spec/test_put_writes.py:207-239

4.3 自定义 Store

实现 batch 与 abatch 后，基类用它们组合 get/search/put/delete/list API；结果必须与输入操作同序。TTL 默认关闭，只有子类显式 supports_ttl=True 才能接受非空 TTL。libs/checkpoint/langgraph/store/base/__init__.py:716-755；libs/checkpoint/langgraph/store/base/__init__.py:919-935

namespace 不能为空、标签必须是无点号的非空字符串，根标签不能是保留值 langgraph。这些是本地准入规则，不是多租户授权；租户身份仍必须由应用或 Server Auth 强制加入 namespace。libs/checkpoint/langgraph/store/base/__init__.py:1263-1283

4.4 自定义 Cache

同时实现 sync/async 的批量 get/set/clear。默认 serializer 是禁用 pickle fallback 的 JsonPlusSerializer；如替换 serde，必须单测跨版本 round-trip 与不可信数据边界。libs/checkpoint/langgraph/cache/base/__init__.py:15-48

CachePolicy.key_func 默认对输入做 pickle hash，TTL 缺省为永不过期。密钥稳定性属于应用责任：模型版本、prompt 版本、租户、权限、工具实现版本若影响结果，就必须进入 key 或 namespace。libs/langgraph/langgraph/types.py:520-529

4.5 ToolNode wrapper

同步 wrapper 和异步 wrapper 分开；异步执行优先 awrap_tool_call，缺失时会回退到同步 wrapper，并使用同步工具执行路径。若策略需要异步 KMS、数据库或网络调用，应提供真正的 async wrapper，不能阻塞 event loop。libs/prebuilt/langgraph/prebuilt/tool_node.py:1191-1210

工具参数注入发生在 wrapper 选择之后、真正 invoke 之前；wrapper 因而可短路未注册工具或替换 tool 实现。GraphBubbleUp 始终重新抛出，不能被普通 handle_tool_errors 转成错误消息。libs/prebuilt/langgraph/prebuilt/tool_node.py:944-983

4.6 StreamTransformer

init() 必须返回 dict，key 合并到 run.extensions；冲突 key 会在注册时拒绝并指出既有 Owner。Transformer 需要 async lane 时，sync stream() 会 fail-fast。libs/langgraph/langgraph/stream/_mux.py:227-267

before_builtins=True 可用于在 built-in snapshot 前做内容脱敏，但不得修改 tasks 事件中被生命周期 bookkeeping 使用的 namespace、id、result、error、interrupts。libs/langgraph/langgraph/stream/_types.py:94-109

4.7 SDK Auth / Encryption 与 CLI

Auth 每个请求先认证，再按“resource+action → resource → global”选择最具体 handler；没有 global handler 时，未匹配请求会被接受，所以安全基线应显式注册 global deny。handler 返回 False 表示 403，None/True 表示接受，filter 用于约束查询。libs/sdk-py/langgraph_sdk/auth/__init__.py:96-106；libs/sdk-py/langgraph_sdk/auth/__init__.py:140-149

Encryption 是 Beta；blob 与 JSON 各自只允许注册一对 handler，handler 必须是恰好两个位置参数的 async 函数。JSON encryptor 只能改变 value，不能增删 key，因为 Server 的 JSONB merge 依赖 key 级结构。libs/sdk-py/langgraph_sdk/encryption/__init__.py:22-64；libs/sdk-py/langgraph_sdk/encryption/__init__.py:235-255

5. 完整运行流程：正常、拒绝与恢复

5.1 正常路径：审批后执行幂等副作用

  1. Graph 节点先规范化业务请求，只向 State 写入“待审批操作 + 幂等键”，不调用外部系统。
  2. 审批节点调用 interrupt(proposal)；checkpointer 持久化可恢复状态并把 interrupt 返回客户端。interrupt 要求启用 checkpointer。libs/langgraph/langgraph/types.py:851-871
  3. 客户端以 Command(resume=decision) 恢复；节点从头执行，interrupt 按 task 内调用顺序匹配 resume 值。libs/langgraph/langgraph/types.py:862-868
  4. 审批为允许时，路由到独立副作用节点；该节点用稳定业务键调用外部 API，重复请求返回同一结果或查询既有结果。
  5. 节点输出成为 task writes，step 屏障后 Channel 批量合并；Saver 分别保存 pending writes 与 checkpoint。
  6. 如节点声明 CachePolicy，只缓存纯计算或可安全复用的读取结果；副作用节点默认不缓存。
最终状态：审批决定与副作用结果都是显式 State/Write；外部调用至少一次时仍由业务幂等键消除重复效果。Checkpoint 不保存 Python 栈，也不提供外部系统的 exactly-once。

5.2 拒绝 / 提前结束路径

  1. Tool wrapper 检查用户、租户、工具名、参数范围和审批证明；不满足策略时不调用 execute，直接返回 status=error 的 ToolMessage 或明确的 Command 路由。
  2. 远程请求先进入 Auth；认证失败由 handler 抛 401，授权 handler 返回 False 得到 403。若没有 global handler，未匹配授权默认接受，因此拒绝策略必须显式配置。libs/sdk-py/langgraph_sdk/auth/__init__.py:49-64
  3. Store 在 namespace 非法或不支持 TTL 时拒绝，不应把请求静默降级到全局 namespace 或永久存储。libs/checkpoint/langgraph/store/base/__init__.py:919-924
  4. StreamTransformer projection key 冲突、init() 非 dict、sync 注册 async-only transformer 时在运行开始前拒绝。libs/langgraph/langgraph/stream/_mux.py:227-256
最终状态：拒绝应成为明确 4xx、ToolMessage(error)、Command 分支或配置异常；不要 fail-open 调用工具，也不要把拒绝伪装成空成功结果。

5.3 恢复 / 重试 / 降级路径

  1. 节点失败后，Runtime 可按 retry policy 再次执行；Tool wrapper 也可多次调用 execute。两层重试预算必须统一，否则产生乘法放大。
  2. interrupt 恢复从节点开头重跑。中断前已经执行的审计写、通知或扣款必须幂等，最佳做法是把它们移到审批后的独立节点。
  3. Saver 恢复读取 checkpoint tuple 与 pending writes，已持久化 task 结果可被复用；但外部副作用是否成功仍需业务记录核对。
  4. Stream async scheduled task 默认 on_error="log" 只记录错误，不终止 run；关键投影应改用 "raise"，使 close 路径转为 fail。libs/langgraph/langgraph/stream/_types.py:233-257
  5. Encryption 解密必须接受加密时不同的 model/field，因为 Server merge 可能移动值；密钥不可用时应 fail-closed，不可返回密文冒充明文。libs/sdk-py/langgraph_sdk/encryption/__init__.py:314-355
  6. 可选 Saver 能力没有 override 时 conformance 跳过；应用必须在启动时核对能力矩阵，不能调用失败后才临时降级。libs/checkpoint-conformance/langgraph/checkpoint/conformance/validate.py:74-90

9. 并发、性能与资源：扩展不能破坏 Runtime 的节奏

Channel 屏障

同 step 收集到的 updates 在 step 末一次交给 Channel。Channel reducer 不应做网络 I/O，也不能依赖 task 完成顺序；慢 reducer 直接拉长屏障。

Tool 并行

同步 ToolNode 使用 executor.map，异步路径使用 asyncio.gather 并发工具调用。两个工具对同一外部资源写入时，图 reducer 不提供锁。libs/prebuilt/langgraph/prebuilt/tool_node.py:793-860

Store 批处理

batch/abatch 应保留结果顺序，并明确事务粒度：接口只要求一个调用返回对应结果，不自动承诺整个 batch 原子。

Stream 串行点

aprocess 按 transformer 顺序 await；慢操作会串行化事件管线。独立异步计算应使用 schedule，并选择 log/raise。libs/langgraph/langgraph/stream/_mux.py:351-378

关闭与取消

async close 先 join scheduled tasks，再 afinalize；fail 会取消并等待 scheduled tasks，最后 afail。自建裸 task 会逃逸这一生命周期。libs/langgraph/langgraph/stream/_types.py:216-227

重试预算

Runtime retry × wrapper retry × HTTP client retry 会乘法放大。统一总尝试次数、deadline 与幂等键，并把每层 attempt 写入 trace。

性能数字边界：当前代码没有为第三方 Saver/Store/Cache 或 transformer 提供通用 SLA。文档只能要求基准覆盖吞吐、p95、连接池耗尽、锁竞争、队列积压与取消清理，不能从内存实现推导生产数据库性能。

10. 安全与信任边界：认证、授权、加密和工具策略分层

  1. 认证不等于授权：@auth.authenticate 只产生 identity/permissions；resource/action handler 再做准入、filter 或 namespace 重写。建议 global deny + 精确 allow。libs/sdk-py/langgraph_sdk/auth/__init__.py:129-202
  2. OpenAPI security 不等于执行策略：auth.openapi 描述文档中的 scheme/requirements，真实拒绝仍由 Server 调用 Auth handler。libs/cli/langgraph_cli/schemas.py:323-343
  3. Store namespace 是数据组织，不是天然 ACL：Auth handler 可原地重写 value["namespace"]，应强制 tenant 前缀，而不是信任客户端提供的首段。libs/sdk-py/langgraph_sdk/auth/__init__.py:190-215
  4. Tool policy 在执行前：wrapper 必须先校验 tool、args、identity、审批 token，再调用 execute；日志中对 token、PII 与工具返回做脱敏。GraphBubbleUp 必须继续传播。
  5. 加密只覆盖 at-rest 指定字段：它不自动覆盖日志、trace、stream、模型 prompt、网络 transport 或外部工具。JSON 非确定性密文不可可靠搜索，需把可过滤 owner/tenant 字段保持明文或建立独立受控索引。libs/sdk-py/langgraph_sdk/encryption/types.py:74-101
  6. EncryptionContext metadata 非 Secret：该 metadata 会随密文持久化；KMS key id 可以保存，原始密钥、token、DEK 不应保存。libs/sdk-py/langgraph_sdk/encryption/types.py:17-40
  7. 配置打包边界：auth/encryption 文件必须位于 dependencies 覆盖范围，CLI 会拒绝漏打包路径；Secret 应来自环境/Secret manager，不写入 langgraph.json。
Fail-closed 原则：认证服务、KMS、审批存储不可用时，拒绝敏感操作；不要为了“可用性”跳过 Auth、返回未解密数据、扩大 Store namespace 或直接执行工具。

14.1 推荐交付顺序

  1. 先写行为矩阵：sync/async、成功/拒绝/恢复、内存/目标后端、本地/Server、当前/最低依赖版本。
  2. 再实现最小公共接口，不 override 未支持的可选 capability。
  3. 先跑单元与 conformance，再跑真实 Graph 集成；安全扩展必须进入实际 Server。
  4. 故障注入覆盖连接中断、重复请求、取消、超时、KMS/数据库不可用和进程重启。

Checkpoint超级步边界的 Channel 值、版本、versions_seen 等可恢复执行状态。
Pending writes绑定 checkpoint 与 task id 的中间写；与超级步 put 分离。
Conformance一致性测试；验证第三方实现是否满足公共存储契约，而不只验证其自身示例。
Capability实现声明支持的一组能力；base 必需，extended 通过 override 检测并按需测试。
Store跨 thread、按 namespace 组织的长期业务记忆。
Cache按稳定输入 key 复用节点结果的派生数据层；不提供副作用 exactly-once。
TTLTime To Live，存活时间；Store 的文档单位为分钟，CachePolicy 的单位为秒，不能混用。
ToolNode wrapper包围单个工具调用的策略函数，可修改、拒绝、短路或多次执行请求。
GraphBubbleUpinterrupt 等图控制流向上传播的异常族，普通工具错误处理不得吞掉。
StreamTransformerv3 stream 的自定义事件投影扩展点，拥有独立 projection 与生命周期。
ProjectionTransformer 从 ProtocolEvent 派生并放入 run.extensions 的视图/通道。
StreamMux按顺序分发协议事件、合并 projection、管理 close/fail 和 seq 的流多路复用器。
Fail-fast / Fail-closed尽早拒绝错误配置 / 安全依赖失败时拒绝访问或写入，而不是放行降级。
Idempotency key幂等键；让外部系统把重复业务请求识别为同一操作的稳定标识。
Exactly-once恰好一次效果。LangGraph checkpoint 与 pending writes 不自动给外部 API 提供该保证。
AuthPython SDK 定义、API Server 执行的认证与授权 handler 系统，不属于本地 Pregel 内核。
Encryption at rest静态数据加密；当前 SDK Encryption 为 Beta，不能推导为 trace、stream 或网络加密。
KMS / DEKKey Management Service / Data Encryption Key，密钥管理服务 / 数据加密密钥。
ACLAccess Control List，访问控制列表；namespace 自身不是 ACL。
Owner定义数据生命周期、顺序、错误与兼容语义的源码模块或外部系统。
Version matrix核心包、扩展包、Python/Node、CLI 与 API Server 的被测组合，不是单一版本号。
