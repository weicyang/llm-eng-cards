1. 模块定位

StateGraph 是声明式 Builder。公共文档直接规定它不能执行，必须先调用 compile()，结果才支持 invoke、stream、batch 及异步兄弟方法。CompiledStateGraph 继承 Pregel，而不是另造执行引擎。证据：libs/langgraph/langgraph/graph/state.py:131-145、libs/langgraph/langgraph/graph/state.py:1189-1192、libs/langgraph/langgraph/graph/state.py:1404-1407

边界本模块负责委托或明确不负责
DSL 准入检查入口、边源/目标、分支目标和静态 interrupt 节点。节点返回值是否合法在生成的 writer 与运行时执行时检查。
Schema 降级把 State/Input/Output Schema 映射到 Channel 集合，选择输入、输出和 stream Channel。Channel 的屏障合并、版本推进属于 Channel/Pregel 算法。
执行图组装生成 PregelNode、ChannelRead、ChannelWrite、边触发和 barrier。Runner、Loop、重试调度、checkpoint 写入属于 Pregel Runtime。
策略固化在编译时合并 Builder 默认策略与节点显式策略。策略何时触发以及副作用幂等由 Runtime 和业务节点负责。
持久化接线校验并保存 checkpointer/cache/store 引用，准备严格 serde allowlist。不创建数据库表、不保存 checkpoint、不保证外部副作用 exactly-once。
相邻模块：第 4 章拥有 StateGraph DSL；第 6 章拥有 Channel 合并；第 7 章拥有 Pregel 超级步；第 8、9 章分别展开子图 namespace 与持久化。本章只追踪“声明如何成为运行图”及其准入和配置语义。

3. 核心概念

Builder 与 ExecutableStateGraph 是可变声明容器；CompiledStateGraph 是 Pregel 可执行对象。Builder 后续改动不会进入已生成对象，并会打印警告。
Channel map运行态 State 不是共享 Python dict，而是 Schema key 对应的 Channel 集合；START 另建临时输入 Channel。
PregelNode节点的运行描述：读哪些 Channel、由哪些 Channel 触发、如何映射输入、执行哪个 Runnable、写出什么，以及 retry/cache/timeout/error-handler 元数据。
Trigger Channel普通边写入 branch:to:<target>，目标节点订阅它；多源边改用命名 barrier Channel。
Partial update节点输出经 writer 过滤成已声明 state key；非法非 dict/Command 输出在运行时抛 InvalidUpdateError。
双层 validateBuilder 校验图声明引用；Pregel 校验编译产物的 Channel 订阅、输入输出、interrupt 与 timeout 支持。

普通节点的 PregelNode.node 是 bound → writers 的 Runnable 序列；写操作发生在节点函数返回之后，先成为 task writes，再由 Runtime 在屏障后应用。证据：libs/langgraph/langgraph/pregel/_read.py:209-248、libs/langgraph/langgraph/pregel/_write.py:75-126

5. 完整运行流程

5.1 成功：声明图编译为可执行 Pregel

  1. compile() 先以公共联合类型校验 checkpointer；只接受 None/True/False/BaseCheckpointSaver。libs/langgraph/langgraph/types.py:100-119、libs/langgraph/langgraph/graph/state.py:1231-1231
  2. 严格 msgpack 开启时，收集 State/Input/Output/Context、节点/分支输入 Schema 和 Channel 值/更新类型，构建 allowlist，并尽可能包装 saver。libs/langgraph/langgraph/graph/state.py:1233-1254、libs/langgraph/langgraph/_internal/_serde.py:87-123
  3. 把空 interrupt 参数规范化为列表，执行 Builder validate；入口、边、分支与 interrupt 引用必须存在。此阶段只检查声明，不运行节点。libs/langgraph/langgraph/graph/state.py:1256-1267、libs/langgraph/langgraph/graph/state.py:1129-1175
  4. 根据 Output Schema 选择最终输出 Channel，根据完整 State Channel 选择默认 stream Channel；单一 root schema 保持标量形状。libs/langgraph/langgraph/graph/state.py:1269-1286
  5. 生成默认 error-handler 节点并合并 retry/cache/timeout/error-handler。节点级值优先；handler 节点不接 error-handler 和 cache，但可接 retry/timeout。libs/langgraph/langgraph/graph/state.py:1290-1338
  6. 创建 CompiledStateGraph：State Channel 加上 ManagedValue 和 START: EphemeralValue(input_schema)；默认 stream mode 为 updates，输入 Channel 为 START。libs/langgraph/langgraph/graph/state.py:1346-1370
  7. 依次 attach START、业务节点、普通边、waiting edge 和 branch。节点输出成为 state writes 与控制 writes；边成为目标 trigger。libs/langgraph/langgraph/graph/state.py:1373-1399
  8. 最后执行 Pregel 级 validate，建立 trigger_to_nodes 索引并返回可执行对象。libs/langgraph/langgraph/graph/state.py:1401-1401、libs/langgraph/langgraph/pregel/main.py:933-948

5.2 校验拒绝：在副作用执行前失败

compile() ├─ checkpointer 类型非法 → TypeError ├─ 无 START 入口 → ValueError ├─ edge/branch/interrupt 引用未知节点 → ValueError ├─ 默认 handler 名冲突 → ValueError ├─ 编译产物读/订阅/输出未知 Channel → ValueError └─ 节点 timeout 与 Runnable 能力不兼容 → validate 拒绝 结果：不进入 Pregel Loop，不执行模型、工具、数据库或节点副作用。

真实测试覆盖未知 edge source、非法 checkpointer 和运行时 LastValue 多写冲突；前两者在编译期拒绝，后者只能等节点产生并发 writes 后拒绝，不能被 compile 静态推断。证据：libs/langgraph/tests/test_pregel.py:104-137、libs/langgraph/tests/test_pregel.py:162-175

5.3 失败恢复：编译期重建与运行期 handler 恢复

  • 编译失败：没有自动重试或事务回滚协议。Builder validate 会设置 compiled=True，策略合并还会改写 NodeSpec 并可能插入默认 handler；若失败发生在后续阶段，最稳妥的恢复方式是修正声明后重建 Builder 再编译，而不是假定原对象完全未变。libs/langgraph/langgraph/graph/state.py:1170-1175、libs/langgraph/langgraph/graph/state.py:1290-1338
  • 节点瞬时失败：compile 固化的 retry policy 在 Runtime 执行；真实测试证明默认 retry 可运行三次，且节点级 policy 覆盖默认 policy。libs/langgraph/tests/test_retry.py:2500-2529、libs/langgraph/tests/test_retry.py:2532-2570
  • handler 自身崩溃：启用 checkpointer 后，恢复会重新调度 handler，而不重新执行原失败节点；这是 pending writes/错误路由的 Runtime 行为，不是 compile 自己回滚。libs/langgraph/tests/test_retry.py:2689-2744

9. 并发、性能与资源

compile() 是同步、进程内的对象组装过程，没有 Executor、Queue、Lock 或背压协议。它会修改 Builder 的 compiled 标志和 NodeSpec 默认值，因此不应在多个线程上并发编译或一边编译一边继续修改同一个 Builder。源码只对“编译后再 add”发 warning，不提供锁。证据：libs/langgraph/langgraph/graph/state.py:788-792、libs/langgraph/langgraph/graph/state.py:945-949

成本点当前行为开发含义
Schema 扫描严格 serde 开启时递归收集容器、Union、TypedDict、Pydantic、dataclass、Enum 和 Channel 类型。复杂递归 Schema 增加编译成本，但不是每超级步重复工作。libs/langgraph/langgraph/_internal/_serde.py:126-199
节点/边组装按节点、边、waiting edge、branch 线性遍历；没有网络或磁盘 I/O。编译对象可复用，不要为每个请求重建无变化的图。
writer 扁平化PregelNode.flat_writers 合并连续 ChannelWrite。减少 Runnable 层级，不改变 write 顺序。libs/langgraph/langgraph/pregel/_read.py:209-224
运行并发compile 只编码 triggers/writers/policies。超级步并发、取消、重试预算和背压必须到 Runtime 章节分析，不能从 attach 顺序推断执行顺序。

10. 安全与信任边界

  1. Builder 输入不是权限边界：compile 校验结构，不审核节点 callable 是否可信。节点仍可访问进程权限、网络、文件、Store 或 secret；副作用必须由应用层最小权限与幂等策略约束。
  2. 严格 serde allowlist：开启 strict msgpack 时，allowlist 来自核心消息类、Schema 字段及 Channel Value/UpdateType；这缩小反序列化类型面，但不是任意代码安全沙箱。libs/langgraph/langgraph/_internal/_serde.py:60-98、libs/langgraph/langgraph/_internal/_serde.py:101-123
  3. 能力降级：若 checkpoint 基类不支持 with_allowlist，代码只记录一次 warning 并继续使用原 saver，属于显式 fail-open 兼容路径；生产上必须观测该 warning。libs/langgraph/langgraph/_internal/_serde.py:36-57
  4. 输出过滤：普通 dict/Command update 只写已声明 output key，降低意外状态扩散；但这不是数据脱敏，合法 key 中的敏感值仍会进入 stream/checkpoint。libs/langgraph/langgraph/graph/state.py:1456-1486
  5. 本地与远程边界：本章是本地 OSS 编译器。Auth、多租户、部署队列和服务端加密不属于 StateGraph.compile() 默认能力。
安全决策：不得把“通过 compile”解释为节点代码安全、输入业务合法、工具获准或 checkpoint 已加密。它只证明静态图与当前 Pregel 结构契约相容。

15. 设计权衡与已知限制

问题当前选择收益成本/失败模式重评条件
Builder 与 Runtime 分离显式 compile，返回 Pregel 子类静态准入、运行对象可复用、DSL 不污染 Loop两份对象；compile 后修改易被误解需要不可变 Builder 或增量编译时。
边编码为 Channel统一成 trigger writes/barrier边、版本、checkpoint 和调度共享模型内部 Channel 名进入迁移成本布局迁移成本超过统一模型收益时。
双层 validate先 DSL 引用，再 Pregel 产物错误靠近所有权层，保护内部扩展Builder 可能在第二层失败前已被修改引入事务式 compile 或不可变中间表示时。
编译时策略合并把默认值固化到每个 NodeSpec运行时读取简单、节点覆盖清晰默认值后改不生效；handler 插入改变 Builder需要运行期动态策略或多租户覆盖时。
strict allowlist 从 Schema 推导自动收集已声明类型减少手工名单漂移动态类型可能缺失；旧 saver 会 fail-open warning需要强制 fail-closed 安全模式时。
checkpointer 三态None/False/True 区分继承、禁用、独立持久化覆盖 stateless interrupt 与 stateful subgraph布尔值语义不直观，True 不能作 root公共配置改为具名枚举且可兼容迁移时。

当前限制：compile 不证明业务终止、reducer 结合性、外部副作用幂等、动态 Command/Send 目标合法性或生产 saver 可用性；这些只有运行测试、持久化 conformance 与应用级策略才能证明。

17. 术语表

术语本章含义易混边界
Builder收集 Schema、节点、边和策略的可变 StateGraph。不是可执行 Runnable。
Compile静态校验并组装 Pregel 运行图的同步过程。不是执行、打包 Python 字节码或生成远程部署。
CompiledStateGraph保留 Builder 元数据并继承 Pregel 的 Graph API 可执行对象。不是独立于 Pregel 的第二套 Runtime。
PregelLangGraph 本地 Channel/超级步执行内核。本章只讨论编译接线，不展开 Loop/Runner。
PregelNode节点的 channels、triggers、mapper、bound、writers 与策略容器。它本身不是用户节点函数。
ChannelState key 的值、更新合并、版本和持久化契约。不是普通共享 dict 字段。
Trigger其版本变化可使节点在下一超级步获得 PULL 调度资格的 Channel。不代表节点在当前函数返回前立即执行。
Partial update节点只返回要更新的 state key/value。不是完整 State 替换。
ManagedValue运行时计算、可读但不作为普通 State Channel 输出的值。不会被当成普通 output/stream Channel。
Serde allowliststrict msgpack 可反序列化类型的允许列表。不是认证、加密或 Python 沙箱。
Checkpointer保存和恢复 Pregel 执行 state 的 saver 或子图三态标志。与 Store、Cache 不同。
Stateless subgraph本章测试中指 checkpointer=None：可借父 saver 完成 interrupt/resume，但独立父调用间不累积子图 state。不等于完全禁用 checkpoint；完全禁用是 False。
Stateful subgraphcheckpointer=True 的嵌套图，以稳定子 namespace 跨调用累积 state。True 不能作为 root graph saver。
二次 validateBuilder 声明校验之后，对已组装 Pregel nodes/channels 再校验。两层校验关注不同所有权。
