1. 模块定位

StateGraph 面向“节点读取共享状态、返回部分更新”的图。状态字段可声明 reducer，以定义同一超级步多个更新如何聚合；节点签名的核心语义是 State → Partial<State>。证据：libs/langgraph/langgraph/graph/state.py:131-153

边界本模块负责委托或明确不负责
Schema登记 State、Input、Output 与节点私有 Schema，把字段解析为 Channel 或 ManagedValue。类型系统和 JSON Schema 生成依赖 Pydantic/typing；业务输入语义仍由应用负责。
图结构保存 Node、普通 Edge、Conditional Edge、Waiting Edge 和可视化目的地。不在 Builder 阶段运行节点、模型、工具或网络副作用。
编译边界执行结构校验并装配 CompiledStateGraph。超级步调度、重试、checkpoint、stream 与取消由 Pregel Runtime 负责。
控制值把节点返回的 Command/Send规范化为状态 writes 与动态路由。interrupt 的持久恢复、父子图 namespace 和 task 执行不由 DSL 独占。
排除边界：本章解释 DSL 如何表达和编译契约，但不展开完整 compile 流程、Channel 屏障算法、Pregel Loop、checkpoint 存储或远程 API Server。包本身定位为低层、长运行有状态 agent 编排框架；依赖要求包括 Python ≥3.10、langchain-core >=1.4.7,<2 与 langgraph-checkpoint >=4.1.0,<5。证据：libs/langgraph/README.md:20-26、libs/langgraph/pyproject.toml:5-32

3. 核心概念

State Schema图内可变共享状态的完整逻辑视图。运行本体不是一个任意 Python dict，而是字段到 Channel/ManagedValue 的映射。
Input Schema外部调用允许写入的入口形状；未显式给出时等于 State。ManagedValue 禁止出现在 Input。
Output Schema最终对外投影的形状；未显式给出时等于 State。ManagedValue 禁止出现在 Output。
Context Schema每次 run 注入的上下文类型，如用户 ID 或数据库连接；节点通过 Runtime.context 读取，不作为节点 partial update。
Channel字段的值、更新和合并语义所有者。普通字段使用单写 LastValue；reducer 字段使用聚合 Channel。
ManagedValue基于 task scratchpad 运行时计算的值，不是普通 Channel write；例如剩余步数。
Waiting Edgeadd_edge([a,b], c) 表示等待全部前驱，通过 NamedBarrier 编译，而不是两条独立普通边。
Conditional Edge节点退出时运行 Branch，目标可为节点名、多个目标或 Send，并可依赖本节点刚写出的值。

四类 Schema 的默认关系和 ManagedValue 限制在构造时确定：Input/Output 默认复用 State；State、Input、Output 会登记字段，但后两者以 allow_managed=False 解析。证据：libs/langgraph/langgraph/graph/state.py:216-270、libs/langgraph/langgraph/graph/state.py:343-373

5. 完整运行流程

5.1 正常成功路径：声明、编译、执行

Schema 声明 → StateGraph 登记 State/Input/Output，保存 Context → 普通字段 → LastValue；Annotated reducer → Aggregate；ManagedValue → managed map → add_node 包装 callable/Runnable，确定节点 input schema → add_edge / add_conditional_edges / waiting edge 保存控制关系 → compile 校验入口、source、target、interrupt → attach_node：读取 Schema keys，输出 partial writes + control writes → attach_edge/branch：创建 trigger、barrier 或 Send → Pregel 超级步读取稳定快照并执行节点 → 屏障后按 Channel 语义合并 writes → Output Schema 投影最终结果
  1. 字段归一化。带注解 Schema 逐 key 解析；普通类型得到有 key 的 LastValue，合法二元 reducer 得到 BinaryOperatorAggregate。libs/langgraph/langgraph/graph/state.py:1815-1873、libs/langgraph/langgraph/graph/state.py:1904-1921
  2. 节点准入。名称和 action 校验后，输入 Schema 优先级为显式参数、函数首参类型提示、图 State；Command[Literal[...]] 返回提示可推断静态 ends，但仅服务校验/渲染。libs/langgraph/langgraph/graph/state.py:778-865
  3. 图结构准入。普通 edge 保存一对 source/target；多起点 edge 保存为 waiting edge；conditional edge 保存 BranchSpec。libs/langgraph/langgraph/graph/state.py:928-1030
  4. partial update。编译节点把 dict、Schema 实例或当前图 Command.update 过滤为已知 output keys，再生成 Channel writes；未知 dict key 不进入状态。libs/langgraph/langgraph/graph/state.py:1444-1505
  5. 本节点可见路由。Branch reader 以 fresh=True 读取，把当前节点 writes 应用到 Channel 副本后运行 route；这是本 task 的 read-your-writes，不是跨 task 即时共享。libs/langgraph/langgraph/graph/state.py:1598-1624、libs/langgraph/langgraph/pregel/_algo.py:188-224
  6. 屏障合并。Pregel 先按 task path 稳定排序，再按 Channel 聚合 writes 并推进版本；因此 reducer 决定并发更新的状态语义。libs/langgraph/langgraph/pregel/_algo.py:232-269、libs/langgraph/langgraph/pregel/_algo.py:294-333

5.2 拒绝与提前结束路径

阶段拒绝条件即时结果状态副作用
Schemareducer 不是恰好两个位置参数；Input/Output 含 ManagedValue。构造时 ValueError。无 compiled graph。
Node名称重复、使用 START/END、含保留 namespace 字符、缺 action。ValueError 或内部 RuntimeError。目标节点不登记。
EdgeEND 作起点、START 作终点；waiting edge 引用未登记节点。ValueError。无对应 edge。
Compile validate没有 START 入口、未知 source/target/interrupt。编译失败。不可执行。
Branch返回 None/START，或 Send 目标为 END。ValueError/InvalidUpdateError。该 task 失败，不产生合法路由。
节点输出不是 dict、Command、可解析 Schema 或合法 root 更新。InvalidUpdateError。该 task 的正常 state writes 不提交。
并发合并同一超级步多个 task 写同一 LastValue key。INVALID_CONCURRENT_GRAPH_UPDATE。屏障合并失败。

校验不是可选提示：validate() 要求至少一个 START source，并逐一检查 source、静态 branch target、edge target 与 interrupt 节点。证据：libs/langgraph/langgraph/graph/state.py:1129-1175

5.3 恢复与降级路径

运行中 task 失败/interrupt → DSL 已生成的 ChannelWrite/trigger 契约保持不变 → Pregel/checkpointer 决定 pending writes 与 checkpoint → 重新 invoke / Command(resume=...) → Runtime 从边界恢复 task → 节点可能重新从头执行 → reducer/幂等副作用仍须满足重复执行约束

StateGraph 本身没有恢复日志，也不保存 Python 栈。它仅在 compile(checkpointer=...) 把 saver 交给执行层；启用后需要 thread_id，并支持 pause/resume/replay。动态 interrupt 恢复时节点从头重跑，因此中断前副作用必须幂等或拆成独立节点。证据：libs/langgraph/langgraph/graph/state.py:1177-1214、libs/langgraph/langgraph/types.py:851-868

降级边界是显式失败而非静默采用“最后写入”：普通字段并发多写会失败；开发者必须通过 Annotated reducer、重新设计边或拆分 key 明确冲突语义。测试验证同一节点 fan-out 到两个 writer 时 hello 触发 InvalidUpdateError。证据：libs/langgraph/langgraph/channels/last_value.py:56-67、libs/langgraph/tests/test_pregel.py:104-137

7. 接口、协议与事件

接口输入输出/语义错误与幂等要求
StateGraph(state_schema, context_schema, input_schema, output_schema)四类类型 Schema。Builder；后三者可选，Input/Output 默认 State。非法 ManagedValue/reducer 在构造期失败。
add_node(...)名称 + callable/Runnable，及策略/私有 input schema。登记 StateNodeSpec；节点通常返回 partial update。副作用节点须按重试/恢复设计幂等。
add_edge(a,b)单 source 或 source 列表。单边触发或等待全部 source 的 barrier。保留端点和未知 waiting 节点立即拒绝。
add_conditional_edgessource、sync/async route、可选 path_map。返回节点名、多个目标或 Send。无类型提示/path_map 时主要影响可视化可知性。
Commandgraph/update/resume/goto。一次返回同时表达 state update 与控制跳转。Command.PARENT 通过 ParentCommand 上抛最近父图。
Sendtarget node、独立 arg、可选 timeout。创建目标节点 PUSH task，适合 map-reduce fan-out。同一 Send 可能在恢复语义下重现，外部副作用仍需幂等。

Command.goto 接受节点名、节点名序列、Send 或 Send 序列；graph=None 指当前图，Command.PARENT 指最近父图。证据：libs/langgraph/langgraph/types.py:798-848

Send 的 arg 可不同于主图 State，因此同一节点可被并行调用并通过 reducer 回收结果；公共测试验证多个并发 Send 的确定性聚合顺序。证据：libs/langgraph/langgraph/types.py:704-776、libs/langgraph/tests/test_pregel.py:1173-1217

DSL 自身不定义 REST、WebSocket 或远程事件协议。stream_mode、callbacks 和远程 transport 属执行/SDK 边界；本模块只产生可供 Pregel 发出 updates/values 等事件的 node/channel 结构。

9. 并发、性能与资源

并发单位不是 Builder。Builder 只声明拓扑；编译后的 Pregel 在超级步中运行所有已触发 task。兄弟 task 读取同一稳定快照，其 writes 到屏障才合并。local_read(fresh=True) 仅叠加当前 task writes，不能用来实现兄弟间同步。证据：libs/langgraph/langgraph/pregel/_algo.py:188-224、libs/langgraph/langgraph/pregel/_algo.py:232-256

关注点当前机制开发含义
同 key 多写LastValue 每步最多一个值；多写 fail-closed。并行 writer 必须声明 reducer、拆 key 或收敛控制流。
reducer 顺序tasks 先按 path 稳定排序，再把 vals 交给 Channel。仍应优先使用结合、最好交换的 reducer；不要依赖线程完成先后。
Waiting Edge多 source 编译为 NamedBarrier，全部到达才触发目标。它是同步点，不是普通边列表的语法糖。
Send fan-out每个 Send 产生带独立 arg 的 PUSH task。并行数量、Executor、背压、timeout 由 Runtime 配置与实现所有。
锁与队列StateGraph Builder 未定义执行锁、queue 容量或背压阈值。不能从 DSL 推断吞吐、并发上限或 SLA。
资源清理Builder 无 socket/thread/DB 生命周期。节点创建的客户端和连接由应用或 Runtime context 管理。

Waiting Edge 编译时为目标创建 NamedBarrierValue，每个 source 向 barrier 写自己的名字；真实测试同时存在提前触发目标的普通边，并验证 barrier 后目标仍拿到完整 reducer 结果。证据：libs/langgraph/langgraph/graph/state.py:1551-1575、libs/langgraph/tests/test_pregel.py:2735-2804

10. 安全与信任边界

边界已有保护未提供的能力开发要求
图结构输入保留节点名、未知端点、缺入口与非法 branch destination 被拒绝。不是租户授权或业务 policy。动态构图若来自不可信输入，先做应用层 allowlist。
状态字段节点 dict 输出只保留已登记 output key。不校验每个业务值安全、不自动清洗提示注入内容。在节点边界使用 Pydantic/业务 validator。
动态路由Send(END,...)、None/START branch 目标被拒绝。goto 不是权限模型。不要让用户文本未经策略映射直接成为节点名。
Context/SecretContext 与可写 State 分离。不提供 Secret 存储、加密、日志脱敏。只注入最小能力对象；在 tracing 层脱敏。
序列化compile 可为严格 msgpack 收集 Schema 类型 allowlist。本地 DSL 不等于远程 Auth/Encryption。远程 Server 的认证与多租户隔离需单独评审。
副作用节点失败不会把非法 partial update 当成功 state。无法回滚已发生的外部 HTTP/DB 副作用。使用 idempotency key、事务 owner 或补偿节点。

Branch 在写目标前显式拒绝 None/START，并禁止发送 packet 到 END；这保证控制图内部不接受几类无效目的地，但不等同于业务授权。证据：libs/langgraph/langgraph/graph/_branch.py:192-224

15. 设计权衡与已知限制

问题当前选择收益成本/失败模式重评条件
共享状态并发字段级 Channel + 显式 reducer局部、可组合，冲突语义清楚错误 reducer 会产生顺序依赖；普通字段 fan-out 失败需要批量 delta 或更强代数属性时评估专用 Channel
路由可见性稳定快照 + 本 task fresh read既可读己写，又不破坏兄弟隔离用户可能误以为所有并发更新即时可见需要 task 间实时通信时应换模型而非绕过屏障
声明式图Builder 编译为 Pregel可视化、静态校验、统一 State 契约动态 Command/Send 使完整路径无法总是静态枚举纯代码控制流更自然时考虑 Functional API
Schema 灵活性支持 TypedDict/Pydantic/dataclass/root 类型适配现有 Python 模型运行时校验强度取决于 Schema 类型；dict partial update 会过滤未知 key跨网络严格契约应引入显式 Pydantic/协议 Schema
等待多个前驱NamedBarrier waiting edge直接表达 join循环和重复触发下语义比普通 DAG 更复杂复杂动态 fan-in 应审计调度与 barrier 测试
恢复委托 Pregel/checkpointer，节点从边界重跑无需保存 Python 栈，跨进程可恢复外部副作用可能重复要求 exactly-once 时必须由业务事务/幂等协议提供

最重要的权衡是：StateGraph 不承诺把任意 Python 函数变成事务。它只把状态更新变成可合并、可 checkpoint 的 Channel writes；外部系统的一致性仍在节点设计、幂等键和资源 owner 手中。

17. 术语表

术语本章含义
DSLDomain-Specific Language，领域专用语言；这里指用 Schema、Node、Edge 描述状态图的 Builder API。
State图内逻辑共享状态；运行时按 key 分解为 Channel map。
Partial update节点只返回要更新的字段，而不是替换整个 State。
Contextrun-scoped 注入数据，通过 Runtime 读取，不属于节点可写 State。
Channel拥有某个 State key 的值、更新、合并、可用性和 checkpoint 语义的对象。
Reducer把旧值与新更新合并为新值的二元函数。
ManagedValue从 task scratchpad 动态计算、而非由普通 Channel write 保存的运行时值。
PregelLangGraph 的 BSP 风格执行 Runtime；CompiledStateGraph 继承它。
BSP / 超级步Bulk Synchronous Parallel；任务读取稳定快照并行执行，writes 在屏障统一合并。
Waiting Edge等待多个 source 全部完成后才触发 target 的 join 边。
Branch条件路由规范，节点退出后根据 route 结果生成目标 writes 或 Send。
fresh local read稳定 Channel 副本叠加当前 task writes 的临时读取；不包含兄弟 task 未提交 writes。
Command同时承载 state update、resume 和 goto 的控制返回对象。
Send向指定节点发送独立 arg 并创建 PUSH task 的动态路由对象。
Command.PARENT把 Command 交给最近父图处理的特殊 graph 标记。
LastValue每超级步最多接受一个更新的默认 Channel。
Checkpoint执行层保存的 Channel 值、版本及调度恢复信息；不是 Python 栈快照。
