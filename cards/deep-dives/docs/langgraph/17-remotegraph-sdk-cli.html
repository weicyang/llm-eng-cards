1. 模块定位

RemoteGraph 是把 LangGraph Server API 映射成图式调用体验的客户端适配器；Python SDK 是资源和传输客户端；CLI 是配置校验、开发服务器入口、镜像/Compose 生成器及托管部署编排器。三者都不等于远程执行器本身。libs/langgraph/langgraph/pregel/remote.py:118-127 libs/sdk-py/langgraph_sdk/client.py:1-7 libs/cli/README.md:17-23

表面负责委托明确不负责
RemoteGraph配置清洗、请求转换、流事件/namespace/interrupt 适配、远程异常映射SDK 客户端和 Server API节点执行、调度队列、checkpoint 存储
Python SDKAssistants、Threads、Runs、Crons、Store；HTTP/SSE 与 v3 WS 客户端httpx、websockets、Server资源的服务端授权、事务与持久化实现

4. 架构组成

4.1 PregelProtocol 与 RemoteGraph

PregelProtocol 规定 with_config、图可视化、state/history、update/bulk update、invoke/ainvoke 和 stream/astream 的同步/异步表面；v1 返回传统值，v2 返回 typed StreamPart/GraphOutput。libs/langgraph/langgraph/pregel/protocol.py:25-105 libs/langgraph/langgraph/pregel/protocol.py:107-269

RemoteGraph 实现该协议，但当前 bulk_update_state/abulk_update_state 明确抛出 NotImplementedError，因此“实现协议”不等于每项能力都可用。构造时至少要能形成一个 sync 或 async client；缺失对应 client 时在调用点拒绝。libs/langgraph/langgraph/pregel/remote.py:132-193 libs/langgraph/langgraph/pregel/remote.py:588-600

5. 完整运行流程

正常路径：RemoteGraph 流式调用。
  1. 调用方传入 input、RunnableConfig、stream modes 和中断选项；实例合并默认 config 并清洗为 wire-safe 值。
  2. thread_id 存在时请求 /threads/{thread_id}/runs/stream，否则请求 /runs/stream；if_not_exists="create" 由 RemoteGraph 显式传入。
  3. 客户端以 SSE 接收 event/data；RemoteGraph 拆分 mode 与 namespace，将 messages 规范化、把父图 namespace 前缀补回，并将 v2 形状映射为 {type, ns, data, interrupts}。
  4. 请求的 mode 才向调用方产出；invoke 本质上消费 values 流直到结束并返回最后一项。
libs/langgraph/langgraph/pregel/remote.py:757-876 libs/langgraph/langgraph/pregel/remote.py:1162-1212
拒绝/提前结束路径：配置或能力不成立。
  1. 同步调用但未配置 sync_client，或异步调用未配置 client，立即抛 ValueError，不会发网络请求。
  2. v3 传入 control、transformers、interrupt before/after 或未知参数时抛 NotImplementedError；v3 Command(goto/update) 同样被拒绝。
  3. SDK 对 400/401/403/404/409/422/429/5xx 映射类型化异常；Store 在本地先拒绝含 . 的 namespace label。
  4. CLI 在 graphs 为空、Python 版本过低、auth/encryption import path 无冒号、Docker 缺失或 TLS cert/key 不成对时提前失败。
libs/langgraph/langgraph/pregel/remote.py:181-221 libs/langgraph/langgraph/pregel/_remote_run_stream.py:21-41 libs/sdk-py/langgraph_sdk/errors.py:190-210 libs/cli/langgraph_cli/config.py:431-468
恢复/降级路径：断线、恢复与部署中断。
  1. 经典 SSE 首次响应若给出受校验的 Location，断线后最多重连 5 次，以 GET + Last-Event-ID 恢复；无 reconnect location 时传输错误直接上抛。
  2. v3 thread stream 使用 since cursor 与去重/缓冲；Command(resume=...) 只发送原始 resume 值，由 Server 根据 thread 状态判断恢复。恢复执行和 checkpoint 读取都在 Server。
  3. abort() 尝试 runs.cancel(..., wait=False) 并关闭流；取消请求失败会记录 debug 并继续关闭，故“本地流已关”不能证明远程 run 已取消。
  4. 远程 deploy 被 Ctrl+C 中断时远程 build 继续，CLI 输出 deployment/revision ID；轮询超时也只停止等待，不等于 Server 停止部署。

6. 数据与状态模型

RemoteGraph 不维护 Channel map，也不持久化 checkpoint；它把 Server 返回的 ThreadState 转为本地 StateSnapshot，包含 values、next、checkpoint config、metadata、parent config、tasks 和 interrupts。该对象是远程状态的客户端视图。libs/langgraph/langgraph/pregel/remote.py:322-405

7. 接口、协议与事件

7.1 HTTP 资源 API

SDK 方法以 JSON 请求映射资源路径：Assistant CRUD 位于 /assistants；Thread 及 state/history 位于 /threads；Run 有 stateful 和 stateless 两套路径；Store 位于 /store/items 与 /store/namespaces。客户端路径参数先 quote，HTTP 状态错误再映射为类型化异常。libs/sdk-py/langgraph_sdk/_async/assistants.py:314-450 libs/sdk-py/langgraph_sdk/_async/runs.py:599-622

7.2 SSE v1/v2

Runs stream 默认 v1，产出 raw StreamPart；v2 是客户端转换后的 typed dict。RemoteGraph 又把远程事件适配为本地 v1/v2 形状。SSE 响应必须是 text/event-stream，否则按 transport error 失败。libs/sdk-py/langgraph_sdk/_async/runs.py:195-270 libs/sdk-py/langgraph_sdk/_async/http.py:187-245

7.3 v3 thread-centric stream

threads.stream() 返回 context manager：命令发往 POST /threads/{id}/commands，事件通过过滤后的 SSE POST /threads/{id}/stream/events 或异步 WS 获取。WS 首帧是 subscription.subscribe envelope；同步 SDK 只支持 SSE，异步 SDK 才可选择 WS。libs/sdk-py/langgraph_sdk/_async/threads.py:739-783 libs/sdk-py/langgraph_sdk/stream/transport/http.py:33-106 libs/sdk-py/langgraph_sdk/stream/transport/ws.py:85-123 libs/sdk-py/README.md:52-57

RemoteGraph v3 提供 values/messages/tool_calls/subgraphs typed projection，以及 updates/checkpoints/tasks/custom 解码 projection；lifecycle 和 debug 故意不伪装成本地 projection。sync 与 async 的 interrupted/interrupts 也是非阻塞快照，与本地 v3 驱动到终态的语义存在明确差异。libs/langgraph/langgraph/pregel/_remote_run_stream.py:80-123 libs/langgraph/langgraph/pregel/_remote_run_stream.py:172-219 libs/langgraph/langgraph/pregel/_remote_run_stream.py:290-347

9. 并发、性能与资源

  • SDK factory 为普通 HTTP transport 配置 5 次连接级 retry；经典 SSE 另有最多 5 次、仅在 Server 提供 reconnect location 后启用的流重连。两者不是业务 run 重试。libs/sdk-py/langgraph_sdk/_async/client.py:128-139 libs/sdk-py/langgraph_sdk/_async/http.py:211-285
  • v3 SSE/WS transport 的事件队列默认上限 1024；队列满时 pump 等待，形成客户端侧背压。共享 SSE fan-out、subscription cursor 和去重集合有独立生命周期。libs/sdk-py/langgraph_sdk/stream/transport/http.py:41-62 libs/sdk-py/langgraph_sdk/stream/transport/http.py:110-187
  • WebSocket 默认 ping interval/timeout 均 20 秒；只有异步 thread stream 暴露 WS。同步长连接使用后台线程运行 lifecycle watcher，context manager 退出前会占用该线程。libs/sdk-py/langgraph_sdk/stream/transport/ws.py:28-53 libs/sdk-py/README.md:54-57
  • 必须显式关闭 client 或使用 context manager；仅停止消费一个 iterator 不应被当作远程 run 已取消。取消远程 run 应调用 runs.cancel 或 v3 adapter abort。libs/sdk-py/langgraph_sdk/_async/client.py:162-178 libs/sdk-py/langgraph_sdk/_async/runs.py:943-999

15. 设计权衡与已知限制

  • Runnable/Pregel 兼容 vs 远程真实语义：RemoteGraph 让远程图可嵌入本地图，但网络分区、序列化、权限和远程取消带来本地调用不存在的失败面；v3 adapter 已显式记录 interrupted 行为差异。
  • SSE 默认 vs WS 可选：SSE 更易穿透基础设施且 sync/async 都可用；WS 只在 async v3 暴露，并仍用 HTTP 发送命令，避免把“WS transport”误解成全双工业务协议。
  • 客户端重连 vs exactly-once：cursor 与 event id 提高连续性，但 replay 要求消费者幂等；客户端代码没有提供 exactly-once 保证。
  • 统一 CLI vs 外部运行面：CLI 能生成镜像并启动/部署，但实际 Server 包、Docker、数据库和 Host Backend 都是外部依赖；CLI 测试不能替代部署环境验证。
  • 灵活配置 vs安全风险：自定义 graph/auth/encryption/checkpointer import path 便于扩展，也扩大代码执行与 secret 管理边界；配置校验只验证形状和路径覆盖，不证明 handler 安全。
  • 当前证据缺口：本仓没有 JS/TS SDK 当前实现，也没有 LangGraph API Server 主体；多租户隔离、队列调度、数据库事务、at-rest encryption 覆盖面和服务端取消终态必须在对应仓库/部署版本验证。

17. 术语表

术语本章含义
PregelProtocol图式执行对象的抽象公共表面；RemoteGraph 适配其中大部分能力，但 bulk update 当前不实现。
RemoteGraph把 Pregel 风格调用映射到远程 LangGraph Server API 的客户端适配器。
Assistant远程图的版本化配置资源，不是单次执行。
Thread跨多个 run 的远程状态与 checkpoint 身份容器。
Run一次 assistant 调用；可绑定 thread 或无状态执行。
Store跨 thread 的远程 namespace KV/搜索资源，与 checkpoint 分离。
SSEServer-Sent Events，HTTP 上的服务器单向事件流；本章经典/v3 流的默认 transport。
WSWebSocket；本章仅指 async v3 的事件 transport，命令仍通过 HTTP。
Cursor / Last-Event-ID传输恢复位置，用于 replay/去重；不是 LangGraph checkpoint id。
Projectionv3 从共享 thread event stream 派生的 values、messages、tools、subgraphs 等类型化视图。
Abort / CancelAbort 是 adapter 尝试取消并关闭本地流；Cancel 是显式远程 run 操作，两者成功语义不能等同。
Auth DSLSDK 提供、由 Server 调用的身份/资源授权 handler 注册表面。
Encryption DSLBeta 的 Server-side at-rest 自定义加解密 handler；不是 TLS 或本地 saver serializer。
inmem extraCLI dev 所需的可选依赖组，会安装仓库外 API Server/runtime 包。
Host Backendlanggraph deploy 对接的托管部署控制面，不是 LangGraph 本地 Pregel runtime。
