17. 术语表

Tool
可持久化的工具初始化规格，仅含注册名称和参数；不是执行器。
ToolDefinition
模型可见 schema、annotations、Action/Observation 类型与运行期 executor 的冻结组合。
ToolExecutor
接收 Action 并真正执行 I/O 或副作用的同步可调用对象；可实现 close/interrupt。
ToolSet
本仓库的约定名称：一个 ToolDefinition 子类充当 factory，create 时展开多个或一个实际工具；没有独立 ToolSet 基类。
Action
工具输入的冻结 Schema；在标准 Agent 路径中由 ActionEvent 持久化后才执行。
Observation
工具输出 Schema；is_error 表示工具级失败，未必等于 Conversation ERROR。
ActionEvent
包含 tool_call、规范化 Action、risk 与 summary 的事件，是后续结果配对的起点。
ObservationEvent
包装 Observation，并通过 action_id/tool_call_id 关联原 ActionEvent 的事件。
AgentErrorEvent
不可执行调用、executor 异常、取消等路径产生的错误型 tool result，可补齐 Action 配对。
DeclaredResources
工具针对单个 Action 声明的共享资源 key 与“是否已明确分析”标志。
ResourceLockManager
按资源 key 管理 FIFO 互斥锁、timeout 和引用清理的进程内组件。
FIFO
First In, First Out，先进先出；此处用于锁等待公平性。
CDP
Chrome DevTools Protocol，Browser executor 与 Chromium 交互所依赖的协议。
MCP
Model Context Protocol；ToolDefinition 能导出 MCP tool schema，但 MCP 连接与动态发现属于独立模块。
structured output
附加到工具参数 schema 的结构化响应字段；Agent 在构造 Action 时拆出并校验。
wire contract
跨配置、持久化、模型或客户端传递的稳定数据契约，例如工具名称和参数 schema。
head-of-line blocking
队首阻塞；较早的慢调用让较晚已完成结果因顺序发射策略而延迟可见。
fail-closed / fail-open
故障时默认拒绝/默认继续。registry usability 异常按不可用是 fail-closed；Terminal Secret 注入/遮蔽异常被忽略是 best-effort，并非 fail-closed。
