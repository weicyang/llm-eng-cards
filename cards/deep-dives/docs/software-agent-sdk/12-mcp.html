MCP：从配置契约到动态工具

3. 核心概念

三种配置形状

  • 外部 wrapper：{"mcpServers": {"name": {...}}}，用于 .mcp.json 和 FastMCP 风格输入。
  • SDK 规范形状：dict[str, MCPServer]，用于 Settings、Agent、Plugin 内存模型和持久化。
  • FastMCP typed config：FastMCPConfig，只由 _prepare_mcp_config() 在连接边界构造。

coerce_mcp_config() 可接受前两种形状及已有 FastMCPConfig，但 create_mcp_tools() 明确只接受 SDK 原生 map，迫使外部兼容集中在入口处。 openhands-sdk/openhands/sdk/mcp/config.py:617-645 openhands-sdk/openhands/sdk/mcp/utils.py:154-173,315-354

发现、定义与执行器

MCP server 返回的 mcp.types.Tool 是协议广告；MCPToolDefinition 保存原始 schema，并创建 MCPToolExecutor。LLM 可见 schema 直接从原始 inputSchema 深拷贝，运行时则动态创建 Pydantic model 做参数校验。 openhands-sdk/openhands/sdk/mcp/tool.py:209-239,242-359,376-430

list_changed 与 reconcile

additions-only 的 on_tools_changed 是兼容回调；完整 on_tools_reconciled 接收当前快照，才能表达新增、定义更新和删除。两者不可混为 “事件历史”：它们是运行时回调，不写入 Conversation EventLog。 openhands-sdk/openhands/sdk/mcp/utils.py:37-51,197-260

10. 安全与信任边界

认证与 Secret

SDK auth 是 discriminator union：none、api_key、bearer、basic、header、oauth2。 Secret 字段统一使用 SecretStr 与公共 Pydantic secret helper；默认序列化不应产生 明文，连接边界才显式请求 plaintext。openhands-sdk/openhands/sdk/mcp/config.py:127-231,469-491,706-753

LocalConversation 展开 MCP config 与工具参数时只查询 conversation SecretRegistry； 工具参数明确 check_env=False，不读取任意 host 环境变量。返回 Observation 仅遮罩 text block，image 原样保留。openhands-sdk/openhands/sdk/mcp/tool.py:126-195

OAuth 与部署信任

Agent Server token store 把 FastMCP token/client-info/expiry key 映射回匹配 URL 的 OAuth MCPServer；同步 settings I/O 经 asyncio.to_thread。配置了 OH_SECRET_KEY 时 secret 走加密存储；未配置时实现只告警，不拒绝启动。 openhands-agent-server/openhands/agent_server/mcp_oauth_store.py:43-116,118-215,352-363

浏览器协调 callback 对提交 URL 做 scheme、loopback hostname、port 与 path 校验， 限制后端代请求目标。openhands-agent-server/openhands/agent_server/mcp_router.py:765-810

当前存在两个 fail-open 边界
Secret 展开失败时执行器继续发送原始变量引用；Observation 遮罩失败时返回未遮罩原结果。 这保证工具链不中断，却可能造成凭据误传或回显泄漏。部署方应把相关 warning 视为安全告警， 并避免让 MCP server 回显凭据。openhands-sdk/openhands/sdk/mcp/tool.py:140-153,174-195

MCP 工具作为普通 ToolDefinition 进入 Agent 的通用安全/确认/Hook 链；MCP 自身并不 赋予额外权限。server 的 readOnlyHint 会影响风险字段注入，但它是 server 声明的 annotation，不是独立授权机制。openhands-sdk/openhands/sdk/mcp/tool.py:327-350,399-410

17. 术语表

术语本章含义
MCPModel Context Protocol，模型上下文协议；client 连接 server，发现并调用工具。
MCP server mapSDK 规范配置 dict[str, MCPServer]；key 是 OpenHands 内的 server 名称。
外部 wrapper以 mcpServers 包裹 server map 的 .mcp.json/FastMCP 风格输入，只应停留在外部适配边界。
typed configFastMCP 的 MCPConfig Pydantic 模型，连接前由 SDK map 转换并验证。
stdio通过标准输入/输出与本地子进程通信的 MCP transport。
SSEServer-Sent Events，服务器发送事件；本章涉及远端 transport 与 server notification 通道。
OAuth开放授权协议；FastMCP 负责授权交换，SDK/Agent Server 提供认证 metadata 与 token storage。
DCRDynamic Client Registration，动态客户端注册；FastMCP OAuth 流程可能使用。
PKCEProof Key for Code Exchange，授权码交换保护机制；由 OAuth client 实现处理。
ToolDefinitionSDK 对工具名称、schema、annotation 与 executor 的统一描述；MCP 工具最终适配到该协议。
ToolExecutor真正执行工具副作用并返回 Observation 的对象；MCP 实现持有 MCPClient。
Observation与 Action 配对的执行结果事件内容；is_error 表达工具层失败而非抛出整个 loop。
tools/list_changedMCP server 通知 client 工具列表变化；client 随后重新 list，而不是从通知本身读取增量。
reconcile协调：用 server 当前完整工具快照计算新增、更新和删除，并按 client ownership 更新 Agent map。
progressive disclosure渐进披露：server 初始只暴露少量入口工具，调用后再通过 list_changed 发布更多工具。
BlockingPortalAnyIO 提供的同步到异步桥；MCPClient 用其后台事件循环从同步 ToolExecutor 调用 async FastMCP。
fail-open保护步骤失败后仍继续主操作；本章特指 secret 展开或遮罩异常后继续发送/返回原值。
fail-closed保护步骤失败即停止操作；当前 MCP secret helper 失败路径并非此语义。
幂等重复执行不会增加副作用；MCP 工具未统一声明幂等，因此调用异常后默认不自动重放。
