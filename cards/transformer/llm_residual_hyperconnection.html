T23 · 残差网络 / 超连接 / MHC

深层网络信号消失 → 残差网络保底 → HC 多通道扩展 → 梯度爆炸 → MHC 双随机矩阵约束

深度模型连接方式的演进就是一部"既要又要"史：残差连接先保证信号不死，HC 再让信号变宽变聪明，MHC 最后给变宽的信号装上限速器——每一步都在回答同一个问题：如何让网络又深、又宽、又稳。

一、深层网络的困境：信号为什么会消失

大模型本质上是多层神经元的堆叠，每一层都是一堆数学运算 Y = F(X)。层数越多，模型能学到的特征就越抽象、越强大——但层数一多，一个致命问题就浮现出来：信号在层层传递中会逐渐衰减。这就像传话游戏：第一个人说了一句完整的话，传到第十个人时已经面目全非，如果中间有人声音太小，后面的人干脆就听不见了。神经网络里，如果某一层的输出接近零，后续层收到的信号就会越来越弱，深层几乎学不到任何东西。

与信号消失相伴而生的是梯度消失（Vanishing Gradient）：训练时梯度要从最后一层一路乘回第一层，每经过一层就乘一次该层的导数。只要这些导数普遍小于 1，连乘几十次后梯度就趋近于零，浅层参数几乎得不到更新——网络名义上有几十层，实际只有最后几层在学习。

传话游戏传十次就面目全非，何况上百层的网络——信号在前向传播中衰减，梯度在反向传播中衰减，深层网络两头受困。

现象发生阶段原因后果
信号消失前向传播层输出接近零，逐层衰减深层收不到有效输入
梯度消失反向传播导数小于 1 的连乘效应浅层参数停止更新
退化现象训练全程上述问题的综合表现56 层网络的训练误差反而高于 20 层

2015 年前后，"退化现象"是业界公认的魔咒：普通网络堆到 20~30 层就是极限，再深反而更差——不是过拟合，是训练误差本身更高。VGG-19 已经是当时的工程天花板，更深的路被堵死了。

二、残差连接：Y = F(X) + X 的保底哲学

解决思路其实很朴素：既然信号会在传递中丢失，那就给每层留一条"应急通道"——让每层输出时都加上这一层的原始输入：

Y = F(X) + X

这个"+ X"就是残差连接（Residual Connection），也叫恒等映射（Identity Mapping）捷径：无论 F(X) 这层变换学得怎么样，原始输入 X 都能原封不动地传下去，信号有了保底。同时，模型的学习目标也悄悄变了——不再是直接学输出 Y，而是学输出与输入的差值 F(X) = Y - X，这个差值就叫"残差"，采用这种结构的网络因此得名残差网络（ResNet）。

输入 X ─────────────────────────┐ │ │ 恒等捷径 (shortcut) ▼ │ 信号与梯度的应急通道 ┌──────┐ │ │ F(X) │ 本层的变换 │ │卷积/注意力/FFN 等 │ └──┬───┘ │ ▼ ▼ ⊕ ←─────────────────────── 逐元素相加 │ ▼ 输出 Y = F(X) + X │ ▼ 下一层…（堆叠 152 层信号也不会死）

残差连接对梯度的拯救同样关键：反向传播时，梯度沿 shortcut 可以直达浅层，不需要经过每一层的导数连乘，梯度消失的链条被打断。从此"堆层数"不再是一场赌博。

生产案例 · ResNet 打破深度魔咒：背景是 2015 年之前，卷积网络普遍止步于 20 层左右，VGG-19 已是工程极限。问题是著名的退化现象——微软团队实验发现，56 层的普通网络训练误差反而比 20 层更高，深层根本训不动。方案是残差连接 + 批量归一化 + He 初始化的组合拳，让每一层只学习残差而非完整映射。效果：ResNet 成功堆到 152 层，以 3.57% 的 top-5 错误率拿下 ILSVRC 2015 冠军，首次超越人类水平（约 5.1%）。更重要的是，残差结构从此成为所有深度模型的标配——今天每一个 Transformer 的每一层里，都住着这个 "+ X"。

残差连接给每层留了一条"应急通道"：学得好就用变换结果，学不好至少原样传下去——信号和梯度都不会死，网络才敢往深了堆。

三、大模型时代的残差流：信息高速公路

残差连接从 CNN 时代一路活到了大模型时代。Transformer 的每一层都是"注意力 + FFN"两个子层，每个子层后面都跟着一次 Add（残差相加）和 Norm（归一化）。几十上百层堆下来，那条贯穿始终的 "+ X" 链条被形象地称为残差流（Residual Stream）：它像一条主干道，所有层都只是路边的服务站——每层从主干道上取信息、加工、再把"修正量"叠加回去，而主干道本身始终畅通。

这个视角带来一个重要推论：既然大部分内容只是"在残差流上叠加修正"，那么层与层之间传递的信息容量就成了模型能力的天花板。残差流有多宽（向量维度多大），每一轮修正能交换的信息就有多少。这为下一节的超连接埋下了伏笔。

归一化位置写法深层稳定性使用者
Post-LNY = Norm(X + F(X))较差，需要精细的学习率预热原始 Transformer、BERT
Pre-LNY = X + F(Norm(X))好，梯度沿残差流稳定传播GPT 系列、LLaMA、DeepSeek

残差流像一条双向八车道的主干道：每一层只是路边的一个服务区，车辆（信号）永远在主干道上行驶，服务区只负责装卸货（叠加修正）——主干道不堵，一百层也畅通。

四、超连接 HC：把单车道扩成多车道

残差网络解决了稳定性问题，但如何让模型更聪明？无非两个方向：①增加学习资料（数据总量总有上限，高质量语料更是稀缺）；②增加层与层之间传递的信息量。2024 年字节跳动提出的超连接（Hyper Connections, HC）走的就是第二条路：把原本单通道的残差流扩展成多通道——通过乘以一个可学习的连接矩阵，把同一份数据变换成 N 份不同表示（论文中典型取 N=4，残差流宽度扩大 4 倍），每一层可以从不同角度处理这些数据，层间交换的信息量成倍增长。

残差网络: 单车道 X ──→ [层1] ──→ [层2] ──→ [层3] ──→ Y （一条 d 维信号流，每层叠加一次修正） 超连接 HC: 多车道 (N = 4) ┌ x₁ ┐ ┌ x₁ ┐ ┌ x₁ ┐ │ x₂ │ → │ x₂ │ → │ x₂ │ → … │ x₃ │ │ x₃ │ │ x₃ │ └ x₄ ┘ └ x₄ ┘ └ x₄ ┘ │ │ │ 连接矩阵 连接矩阵 连接矩阵 (混合 4 份 (每层从 4 个 (变换结果 表示) 角度加工) 重新分配) 同一份数据 → 4 份不同表示, 层间信息容量 ×4

效果是直观的：在同等计算预算下，HC 让模型的推理能力和知识储备都有提升，多项推理基准优于传统残差基线。但天下没有免费的午餐——多通道是靠矩阵乘法实现的，而矩阵连乘，恰恰是数值稳定性的天敌。

HC 把单车道改成了四车道：同一时刻路上的信息翻了四倍，每层还能从四个视角同时加工——流量上去了，但没人管限速，车祸（梯度爆炸）也随之而来。

五、MHC：给多车道装上限速器

HC 的问题出在数学本质上：多通道混合靠的是矩阵乘法，层数一多就相当于矩阵连乘。只要连接矩阵的平均"放大率"略大于 1，连乘几十上百次后数值就会指数级膨胀——DeepSeek 在 27B 参数规模的实验中测到，HC 的信号放大约 3000 倍。信号爆炸直接导致梯度爆炸（Exploding Gradient）：参数更新剧烈震荡，训练早期出现明显的 loss 尖峰，大规模预训练根本跑不完就崩溃了。

DeepSeek 提出的MHC（Manifold-Constrained Hyper-Connections，流形约束超连接）保留了 HC 的多通道结构，但给连接矩阵加了一道硬约束：把它约束为双随机矩阵（Doubly Stochastic Matrix）——要求矩阵每行每列加起来都等于 1。行和为 1 意味着每个输出通道是输入通道的加权平均而非放大；列和为 1 意味着信息不会被凭空复制。在这样的矩阵上连乘，信号能量近似守恒，放大问题从根上被解决。工程上，MHC 用 Sinkhorn-Knopp 算法（一种交替归一化行和列的迭代方法）把任意矩阵投影到双随机矩阵流形上，每次更新后执行几步迭代即可。

HC: 连接矩阵 W 自由学习 信号 ──→ ×W ──→ ×W ──→ ×W ──→ … ──→ 放大 ~3000 倍 （矩阵连乘, 数值指数膨胀, 训练崩溃） MHC: W 被投影到双随机矩阵流形 信号 ──→ ×W' ──→ ×W' ──→ ×W' ──→ … ──→ 放大 ~1.6 倍 （每行每列和 = 1, 加权平均 ≈ 能量守恒） 实现: W' = SinkhornKnopp(W) 交替归一化行/列, 迭代几步即收敛
方案信号放大倍数训练稳定性
残差网络1 倍稳定

生产案例 · MHC 把 3000 倍的野马驯回 1.6 倍：背景是 HC 的多通道设计确实能涨点，但 DeepSeek 团队在 27B 参数规模的预训练实验中发现，HC 模型训练早期出现明显的 loss 尖峰，实测信号放大约 3000 倍，参数更新剧烈震荡，无法支撑大规模训练。问题在于矩阵连乘的指数放大是结构性的，靠调学习率、梯度裁剪只能缓解不能根治。方案是 MHC：把连接矩阵约束到双随机矩阵流形（行列和均为 1），用 Sinkhorn-Knopp 迭代做投影，从数学上恢复类似恒等映射的能量守恒性质。效果：信号放大从约 3000 倍压到约 1.6 倍，27B 规模全程训练平稳，推理与知识类基准全面优于 HC 和传统残差基线；代价方面，通过算子融合等优化，通道数扩展 4 倍时额外时间开销仅 6.7%——用零头般的成本买回了训练稳定这张大规模预训练的入场券。

残差网络 = 一条车道；HC = 加宽到多车道（流量大但容易失控飙车）；MHC = 多车道 + 限速和交通规则（既保证流量又避免失控）——约束不是束缚，而是让系统跑得远的前提。

MHC 的代价需要单独说清楚：残差流宽度扩大 4 倍，意味着激活值显存、层间搬运的数据量都随之增加，双随机矩阵投影本身也有计算成本。DeepSeek 的解法依然是第 19 张卡片讲过的算子融合——把投影、混合、归一化等操作合并编译，最终通道扩展 4 倍只带来 6.7% 的额外时间开销，让这套方案在工程上真正可用。

  • 评估新连接结构时，先测信号放大倍数和梯度范数，再谈 benchmark 涨幅
  • 小规模（几百 M）验证稳定性之后，再放大到预训练规模
  • 用算子融合抵消多通道带来的小算子开销
  • 把激活值显存纳入预算：残差流加宽 N 倍，激活显存近似加宽 N 倍
  • 不要只看 benchmark 涨幅就忽视训练稳定性——loss 尖峰在千卡训练上意味着真金白银的损失
  • 不要把无约束的 HC 直接用于大规模预训练
  • 不要指望梯度裁剪能根治结构性数值爆炸，约束要加在结构上
  • 不要忽略 6.7% 之外的隐性成本：显存、通信、调试复杂度都要算总账

架构创新不是"越花哨越好"，而是在信号放大、显存、计算三者之间找平衡——MHC 的价值不在于多通道本身，而在于用 6.7% 的开销买回了"能稳定训完"这张入场券。

Q&A

残差网络解决了什么问题？为什么它能工作？
残差网络解决深层网络中信号消失和梯度消失的问题。随着层数增多，如果某一层输出接近零，信号在前向传递中会越来越弱（类似传话游戏），梯度在反向传播中经过导数连乘也会趋近于零，导致深层网络训不动、甚至出现 56 层不如 20 层的退化现象。残差网络让每层输出时加上原始输入：Y = F(X) + X。即使 F(X) 学坏了，原始输入 X 作为保底确保信号不消失；反向传播时梯度也能沿这条捷径直达浅层，不必经过每层导数连乘。模型因此只需学习输出与输入的差异（残差），网络得以堆到上百层而保持稳定，ResNet-152 拿下 ILSVRC 2015 冠军就是证明。
MHC 是什么？它解决了 HC 的什么问题？
MHC（Manifold-Constrained Hyper-Connections，流形约束超连接）是 DeepSeek 提出的改进方案。HC（超连接）通过矩阵乘法将单通道残差流扩展为多通道，让每层从不同角度处理数据、提升层间信息容量，但矩阵连乘导致数值指数膨胀——27B 参数模型上信号放大约 3000 倍，造成梯度爆炸、loss 尖峰和训练崩溃。MHC 在 HC 基础上加入双随机矩阵约束（矩阵每行每列之和均为 1），用 Sinkhorn-Knopp 迭代把连接矩阵投影到双随机流形上，使多通道混合近似于加权平均而非放大，信号放大被控制在约 1.6 倍，训练恢复稳定。代价是额外计算量，但通过算子融合优化，4 倍通道扩展的额外耗时仅 6.7%。
残差网络、HC、MHC 三者的演进关系是什么？
三者是逐步解决不同问题的演进链条。第一步，残差网络解决"信号消失"：通过 Y = F(X) + X 保底原始输入，使深层网络能稳定训练，成为所有现代模型的底座。第二步，HC 解决"想得不够多"：将单通道残差流扩展为多通道（乘以可学习矩阵变换为 N 份表示），每层可从不同角度处理数据，层间信息容量扩大约 4 倍，推理能力随之提升，但引入了梯度爆炸（矩阵连乘导致信号放大约 3000 倍）。第三步，MHC 解决"HC 的梯度爆炸"：加入双随机矩阵约束限制数值范围（信号放大仅 1.6 倍），以 6.7% 的额外开销换回训练稳定。用交通类比：残差是单车道，HC 是加宽到多车道但容易失控，MHC 是多车道加限速规则——既保流量又保安全。
深层网络为什么会出现信号消失？它和梯度消失是什么关系？
信号消失源于前向传播的逐层衰减：每一层都是 Y = F(X) 这样的变换，只要某些层的输出幅值小于输入，信号穿过几十层后就会指数级衰减，深层收到的输入接近噪声，学不到有用特征。梯度消失是同一枚硬币的另一面：反向传播时，梯度要从末层一路乘回首层，每经过一层就乘一次该层的局部导数，导数普遍小于 1 时连乘结果趋近于零，浅层参数几乎不更新。两者的共同根源是"信息必须逐层串行传递"这一结构缺陷，所以解决方案也是同一个——残差连接提供一条信号和梯度都能直达的捷径，同时治好了前向的信号消失和反向的梯度消失。
HC 的梯度爆炸从何而来？为什么小模型上不明显？
HC 用可学习的连接矩阵把单通道扩展为 N 个通道，信号每过一层就被矩阵乘一次。矩阵连乘的数值行为取决于矩阵的谱性质：只要平均放大率略大于 1，经过 L 层后信号就会被放大约"放大率的 L 次方"倍——这是指数增长。小模型层数少（比如十几层），指数效应还不显著，训练看起来一切正常；但大模型动辄几十上百层，DeepSeek 在 27B 规模实测到信号放大约 3000 倍，前向数值爆炸传导到反向就是梯度爆炸，参数更新剧烈震荡，训练早期出现 loss 尖峰直至崩溃。所以 HC 的问题不是"有没有"，而是"规模够不够大才会暴露"，这也解释了为什么约束是大规模预训练的必需品。
双随机矩阵为什么能稳住信号？
双随机矩阵要求每行每列加起来都等于 1，这两条约束各自封死了一种失控方式。行和为 1 意味着每个输出通道是各输入通道的加权平均——加权平均的幅值不会超过输入的最大幅值，单步变换不可能放大信号。列和为 1 意味着每个输入通道的信息被"分配"而非"复制"，信息总量守恒，不会凭空增殖。在这样的矩阵上连乘，信号能量近似保持不变，相当于恢复了残差连接"信号守恒"的优良性质，同时保留了多通道的信息容量。工程上通过 Sinkhorn-Knopp 算法交替归一化行和列，几步迭代就能把任意正矩阵投影到双随机流形上，实现成本很低。
MHC 多花 6.7% 开销值不值？工程上怎么选？
值不值要看规模。小规模实验或微调场景下，HC 的数值问题不明显，直接用无约束 HC 甚至传统残差即可，没必要为稳定性约束付费。但到了大规模预训练，账就完全反过来：一次训练中断（loss 尖峰导致的崩溃重启）在千卡集群上损失的算力成本，远超 6.7% 的开销；而且 MHC 在 27B 规模上不仅稳，benchmark 还全面优于 HC 和残差基线，属于"既稳又强"。工程选型建议：先评估训练规模——百层以内、参数几 B 以下可以观望；一旦进入几十 B、上百层的预训练区间，信号放大倍数就是必须监控的一级指标，此时 MHC 这类带流形约束的结构是更稳妥的选择。同时记得把激活显存纳入预算，残差流加宽 4 倍意味着激活显存近似加宽 4 倍。
