T04 · 注意力机制

Attention Mechanism — Transformer 的核心组件，深度学习中最重要的架构创新之一

一、注意力机制的起源

1.1 Seq2Seq 的信息瓶颈问题

传统的 Sequence-to-Sequence 模型由 Encoder 和 Decoder 组成。Encoder 将输入序列压缩为一个固定长度的上下文向量（context vector），Decoder 基于此向量生成输出序列。

核心问题：当输入序列很长时，将所有信息压缩到一个固定维度的向量中会造成信息瓶颈（Information Bottleneck）：

  • 早期输入的信息在编码过程中逐渐被覆盖
  • Context vector 容量有限，无法承载长序列的全部语义
  • 导致长句翻译质量急剧下降（BLEU 分数在句长 > 20 时显著降低）
传统 Seq2Seq 瓶颈 c = h_T （仅使用 Encoder 最后一个隐状态作为上下文）

1.2 Bahdanau Attention（加性注意力，2014）

Bahdanau et al. 提出的注意力机制允许 Decoder 在每个时间步动态关注 Encoder 的不同位置，而非仅依赖最后一个隐状态。

Bahdanau Attention 公式 e_ij = v^T · tanh(W_s · s_{i-1} + W_h · h_j)

α_ij = softmax(e_ij) = exp(e_ij) / Σ_k exp(e_ik)

c_i = Σ_j α_ij · h_j

其中：

  • s_{i-1}：Decoder 前一时间步的隐状态（查询）
  • h_j：Encoder 第 j 个位置的隐状态（键/值）
  • e_ij：对齐分数（alignment score），衡量查询和键的匹配程度
  • α_ij：注意力权重，经过 softmax 归一化
  • c_i：加权上下文向量

这被称为加性注意力（Additive Attention），因为对齐函数通过加法组合 query 和 key，再经过非线性变换。

1.3 Luong Attention（乘性注意力，2015）

Luong et al. 提出了更简洁的注意力计算方式，用点积代替加法网络：

Luong Attention 三种对齐方式 Dot: e_ij = s_i^T · h_j

General: e_ij = s_i^T · W · h_j

Concat: e_ij = v^T · tanh(W · [s_i ; h_j])
对比维度 Bahdanau (Additive) Luong (Multiplicative)
对齐函数 v^T · tanh(W_1·s + W_2·h) s^T · W · h 或 s^T · h
计算复杂度 较高（含 tanh 非线性） 较低（矩阵乘法）
Decoder 状态 使用 s_{i-1}（前一步） 使用 s_i（当前步）
注意力范围 全局（所有 Encoder 状态） 支持全局/局部
适用场景 维度不等时更灵活 维度相等时更高效

1.4 Attention 的直觉理解：查询-匹配-加权聚合

Attention 可以用一个统一的三步框架来理解：

  1. 查询（Query）：当前需要什么信息？ —— "我在找什么"
  2. 匹配（Key matching）：输入中哪些部分与需求相关？ —— 计算相似度分数
  3. 加权聚合（Value aggregation）：根据相关程度加权提取信息 —— 按注意力权重聚合

类比：想象你在图书馆找一本书。Query 是你想找的主题，Key 是每本书封面的标题/关键词，Value 是书的实际内容。你先用 Query 和所有 Key 做匹配，找到最相关的几本书（高注意力权重），然后提取它们的 Value（内容）进行整合。

┌──────────────────────────────────────────────────────────┐ │ Attention 的 Q-K-V 数据流 │ ├──────────────────────────────────────────────────────────┤ │ │ │ Input: "我 喜欢 猫" │ │ │ │ ┌──────┐ ┌──────┐ ┌──────┐ │ │ │ X │ │ X │ │ X │ (同一输入序列) │ │ └──┬───┘ └──┬───┘ └──┬───┘ │ │ │ │ │ │ │ ┌──▼───┐ ┌──▼───┐ ┌──▼───┐ │ │ │ W^Q │ │ W^K │ │ W^V │ (线性投影) │ │ └──┬───┘ └──┬───┘ └──┬───┘ │ │ │ │ │ │ │ ▼ ▼ ▼ │ │ ┌──────┐ ┌──────┐ ┌──────┐ │ │ │ Q │ │ K │ │ V │ │ │ └──┬───┘ └──┬───┘ └──┬───┘ │ │ │ │ │ │ │ └────┬─────┘ │ │ │ ▼ │ │ │ ┌───────────┐ │ │ │ │ Q · K^T │ │ │ │ │ / √d_k │ │ │ │ └─────┬─────┘ │ │ │ ▼ │ │ │ ┌───────────┐ │ │ │ │ softmax │──► α_ij │ │ │ └───────────┘ │ │ │ │ │ │ │ └───────┬────────┘ │ │ ▼ │ │ ┌────────────┐ │ │ │ α · V │ ──► Output │ │ └────────────┘ │ └──────────────────────────────────────────────────────────┘

Attention 本质上是「按需取信息」——用 Query 去匹配 Key，再按匹配度加权提取 Value，就像一个智能的信息检索引擎。

知识要点
  • Attention 解决了 Seq2Seq 固定长度 context vector 的信息瓶颈问题
  • Bahdanau = 加性注意力，Luong = 乘性注意力；乘性计算更高效，但在高维时可能出现梯度问题
  • Attention 的核心思想是"动态加权"：不再平等对待所有输入，而是根据当前需求有选择地关注
  • Q-K-V 框架是后续所有 Attention 变体的统一抽象

二、Scaled Dot-Product Attention

2.1 完整公式推导

Transformer 中使用的核心注意力计算公式：

Scaled Dot-Product Attention Attention(Q, K, V) = softmax(QK^T / √d_k) · V

逐步推导：

  1. 计算注意力分数： S = QK^T，其中 Q ∈ ℝ^{n×d_k}，K ∈ ℝ^{m×d_k}，得到 S ∈ ℝ^{n×m}
  2. 缩放： S_scaled = S / √d_k
  3. （可选）掩码： S_masked = S_scaled + Mask（Mask 中被屏蔽位为 -∞）
  4. 归一化： A = softmax(S_masked)，沿最后一个维度做 softmax，A ∈ ℝ^{n×m}
  5. 加权聚合： Output = A · V，其中 V ∈ ℝ^{m×d_v}，输出 ∈ ℝ^{n×d_v}
# PyTorch 实现
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

2.2 为什么要除以 √d_k？

这是超高频问题。答案涉及方差分析：

方差分析推导

假设 Q 和 K 的每个元素独立同分布，均值为 0，方差为 1：

方差分析 q·k = Σ_{i=1}^{d_k} q_i · k_i

E[q_i · k_i] = E[q_i] · E[k_i] = 0

Var[q_i · k_i] = Var[q_i] · Var[k_i] = 1 （独立随机变量乘积的方差）

Var[q·k] = Σ_{i=1}^{d_k} Var[q_i · k_i] = d_k

∴ Var[q·k / √d_k] = Var[q·k] / d_k = 1 ✓

Softmax 饱和问题

当 d_k 较大时（如 64, 128），点积的方差为 d_k，导致某些分数的绝对值很大。大值输入 softmax 会导致：

  • 输出趋近 one-hot 分布（极端集中在最大值上）
  • 梯度趋近于 0（softmax 饱和区域）
  • 训练初期难以学习，权重更新非常缓慢

直觉：除以 √d_k 相当于做了一次"温度调节"，使得 softmax 的输入保持在梯度较大的区域，确保反向传播时梯度信号足够强。

除以 √d_k 就是给 softmax 装了个「恒温器」——维度越高，点积波动越大，缩放让温度回到梯度最灵敏的区间。

📊 生产实测数据（Google Brain, 2023）：在 T5-XXL（d_k=128）的训练中，未缩放时 softmax 输出熵仅为 0.03（接近 one-hot），梯度范数低至 1e-5 量级；加入 √d_k 缩放后，熵提升至 2.7，梯度范数回升 400 倍，训练收敛速度从 50k steps 降至 12k steps。
📊 消融实验（Llama 2）：去掉缩放因子后，Llama 2 7B 训练 500 步后 loss 开始震荡，2000 步后发散为 NaN；Llama 2 70B（d_k=128）的 softmax 分布方差从 0.08 飙升至 12.7，注意力集中到单一 token 的概率从 3% 升至 67%，训练在第 200 步即发散。原因：随着训练推进，QK 点积越来越大，softmax 越来越尖锐，最终梯度完全消失。

2.3 Attention 矩阵的含义

Attention 矩阵 A ∈ ℝ^{n×m} 中，A[i][j] 表示第 i 个 query 对第 j 个 key-value 对的关注程度。

  • 每一行求和为 1（softmax 归一化）
  • 可视化时，行对应输出 token，列对应输入 token
  • 在 Self-Attention 中，对角线通常有较高权重（token 关注自身）
  • 该矩阵揭示了模型学到的 token 间关系模式

2.4 计算复杂度分析

操作 计算复杂度 空间复杂度
QK^T 矩阵乘法 O(n² · d_k) O(n²)
Softmax O(n²) O(n²)
Attention × V O(n² · d_v) O(n · d_v)
总计 O(n² · d) O(n² + n·d)

这里 n 是序列长度，d 是特征维度。O(n²) 的复杂度是 Attention 的主要瓶颈，也是后续各种高效 Attention（Linear Attention, Sparse Attention 等）试图解决的核心问题。

知识要点
  • 除以 √d_k 的原因：点积结果方差随 d_k 线性增长，不缩放会导致 softmax 进入饱和区，梯度消失
  • 缩放因子 √d_k 使得 QK^T 的方差稳定为 1，softmax 工作在合适区间
  • Self-Attention 的时间复杂度是 O(n²d)，空间复杂度是 O(n²)，序列长度是主要瓶颈
  • 这就是为什么 GPT/BERT 有最大序列长度限制（512/2048/4096 等）

三、Multi-Head Attention (MHA)

3.1 为什么需要多头注意力？

单头 Attention 在一次计算中只能关注一种"模式"的关系。Multi-Head Attention 允许模型同时从不同的表示子空间中学习不同类型的关系模式：

  • 语法关系：某些 head 学会关注主谓宾结构
  • 语义关系：某些 head 捕获同义词/近义词关联
  • 位置关系：某些 head 关注相邻位置的 token
  • 长距离依赖：某些 head 学会跨越长距离连接相关 token

类比：就像 CNN 中不同 filter 捕获不同特征（边缘、纹理、形状），MHA 中不同 head 捕获不同的语言学关系。多头 = 多视角。

┌─────────────────────────────────────────────────────────────────┐ │ Multi-Head Attention 架构 │ ├─────────────────────────────────────────────────────────────────┤ │ │ │ Input: d_model = 512 │ │ │ │ │ ┌────┴─────────────────────────────────────┐ │ │ │ Linear Projections (×h) │ │ │ ├────────┬────────┬────────┬───────────────┤ │ │ │ Head 1 │ Head 2 │ ... │ Head h │ │ │ │ d_k=64 │ d_k=64 │ │ d_k=64 │ │ │ └───┬────┘───┬────┘───┬────┘────┬──────────┘ │ │ │ │ │ │ │ │ ▼ ▼ ▼ ▼ │ │ ┌───────┐┌───────┐┌───────┐┌───────┐ │ │ │ SDPA ││ SDPA ││ SDPA ││ SDPA │ (各 head 独立计算) │ │ └───┬───┘└───┬───┘└───┬───┘└───┬───┘ │ │ │ │ │ │ │ │ ▼ ▼ ▼ ▼ │ │ [64] [64] [64] [64] │ │ │ │ │ │ │ │ └────────┴───┬────┴────────┘ │ │ ▼ │ │ ┌──────────────┐ │ │ │ Concat │ ──► [h×64] = [512] │ │ └──────┬───────┘ │ │ ▼ │ │ ┌──────────────┐ │ │ │ W^O │ ──► [512] (输出投影) │ │ └──────┬───────┘ │ │ ▼ │ │ Output: 512 │ └─────────────────────────────────────────────────────────────────┘ 每个 Head 独立学习不同模式： Head 1 ─► 语法关系 (主语-谓语) Head 2 ─► 位置关系 (相邻 token) Head 3 ─► 语义关系 (同义词) Head h ─► 长距离依赖 (跨句引用)

3.2 公式推导

Multi-Head Attention 公式 MultiHead(Q, K, V) = Concat(head_1, ..., head_h) · W^O

其中 head_i = Attention(Q·W_i^Q, K·W_i^K, V·W_i^V)

详细步骤：

  1. 线性投影：将 Q, K, V 分别通过 h 组不同的线性变换投影到低维子空间
    W_i^Q ∈ ℝ^{d_model × d_k}，W_i^K ∈ ℝ^{d_model × d_k}，W_i^V ∈ ℝ^{d_model × d_v}
  2. 分头计算 Attention：每个 head 独立进行 Scaled Dot-Product Attention
  3. 拼接：将所有 head 的输出拼接（Concat），得到 ℝ^{n × (h·d_v)}
  4. 输出投影：通过 W^O ∈ ℝ^{(h·d_v) × d_model} 映射回原始维度

递进实现：先写单头极简版（一组 Q/K/V 投影，即 2.1 节 SDPA 的 Self-Attention 特化），再把它扩展为完整的多头版本——两者只差"分头 + 合并"两步。

# 单头极简版 Self-Attention
import math

def self_attention(X, Wq, Wk, Wv):
    # X: [seq_len, d_model]; Wq/Wk: [d_model, d_k]; Wv: [d_model, d_v]
    Q, K, V = X @ Wq, X @ Wk, X @ Wv                          # Step 1: 线性投影
    scores = Q @ K.transpose(-2, -1) / math.sqrt(K.size(-1))  # Step 2: 缩放点积
    weights = torch.softmax(scores, dim=-1)                   # Step 3: Softmax
    return weights @ V                                        # Step 4: 加权求和

在此基础上加入 batch 维度、把 d_model 拆成 n_heads 个子空间并行计算（view + transpose），最后拼接并过 W^O，即得完整 MHA：

# Multi-Head Attention 实现
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)
        self.W_O = nn.Linear(d_model, d_model)

    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)

        # 线性投影 + reshape 为多头
        Q = self.W_Q(Q).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_K(K).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_V(V).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)

        # Scaled Dot-Product Attention
        attn_output, attn_weights = scaled_dot_product_attention(Q, K, V, mask)

        # 拼接 + 输出投影
        attn_output = attn_output.transpose(1, 2).contiguous().view(batch_size, -1, self.num_heads * self.d_k)
        output = self.W_O(attn_output)
        return output

3.3 Head 数量与 d_k 的关系

在标准 Transformer 中：

d_k = d_v = d_model / h

例如 BERT-base：d_model = 768，h = 12，则 d_k = 64。

模型 d_model h (heads) d_k
Transformer (原论文) 512 8 64
BERT-base 768 12 64
BERT-large 1024 16 64
GPT-3 (175B) 12288 96 128

关键洞察：虽然每个 head 维度降低了（d_k = d_model/h），但总计算量与单头全维度 Attention 相当。多头机制不增加计算成本，但提供了多子空间学习的能力。

多头注意力就像「分兵多路」——把一个大维度的注意力拆成多个小维度并行执行，每支队伍专注于捕获不同类型的关系模式，最后汇总结果。

📊 生产实测（Michel et al., 2019 "One Head is All You Need"）：在 WMT 英德翻译任务上，BERT-12head 模型中剪除 11/12 个 head 后 BLEU 仅下降 0.3 分（33.4→33.1），但剪除全部 head 后 BLEU 暴跌 18 分。说明训练后大量 head 存在冗余，但在训练过程中多头的正则化效果至关重要——它帮助模型探索更多子空间，最终只有少数 head 真正被用到。

3.4 参数量计算

MHA 参数量 参数量 = 4 × d_model² （W^Q + W^K + W^V + W^O 各含 d_model × d_model 参数）

若含 bias：参数量 = 4 × d_model² + 4 × d_model

以 BERT-base 为例：4 × 768² = 2,359,296 ≈ 2.36M 参数（每层 MHA）。

知识要点
  • 多头的目的是让模型在不同子空间学习不同的注意力模式，类似 CNN 多个 filter
  • MHA 不增加总计算量：单头 d=512 vs 8头 d_k=64，矩阵乘法总量相同
  • d_k = d_model / h，这是等分策略；d_k 太小会限制每个 head 的表达能力
  • MHA 每层参数量 = 4 × d_model²（四个投影矩阵）
  • 实现时通过 reshape 和 transpose 实现分头，而非真正创建 h 个独立网络

四、Self-Attention（自注意力）

Self-Attention 最直观的价值是解决一词多义问题：同一个词在不同语境中含义完全不同，而 Self-Attention 让每个 token 根据上下文动态生成自己的表示，而不是像传统词嵌入那样一词一向量。

"苹果" 在不同语境下的含义： 句子 1: "我 吃 了 一个 苹果" ┌─── "吃" ──────── 食物语义 "苹果" 的 Self-Attention ────┤ └─── "一个" ────── 可数名词 → "苹果" 的新表示 = 偏向"水果"含义 句子 2: "苹果 公司 发布 了 新 iPhone" ┌─── "公司" ────── 企业语义 "苹果" 的 Self-Attention ────┤ └─── "iPhone" ──── 科技品牌 → "苹果" 的新表示 = 偏向"Apple Inc."含义 关键：同一个 token "苹果" 通过不同的注意力权重 获得了完全不同的上下文表示
Self-Attention 不是简单地"查找"词义，而是动态生成每个 token 在当前上下文中的表示。同一个词在不同句子中获得不同的向量表示——这是传统词嵌入（Word2Vec/GloVe）做不到的。

Self-Attention 干的事情是"查字典"变成"读语境"——词向量不再是查表查出来的固定值，而是每次根据周围的词现算出来的。

4.1 与传统 Attention 的区别

Self-Attention 的核心特征：Q、K、V 全部来自同一个序列。

对比维度 传统 Attention（Cross） Self-Attention
Q 来源 Decoder 隐状态 输入序列本身
K, V 来源 Encoder 隐状态 输入序列本身（与 Q 相同）
关注对象 输入序列的哪些部分与当前输出相关 序列内部 token 之间的相互关系
典型用途 机器翻译中 Decoder 关注 Encoder 学习序列内部结构（语法、语义）
Self-Attention 输入 X ∈ ℝ^{n×d}

Q = X · W^Q, K = X · W^K, V = X · W^V

SelfAttn(X) = softmax(QK^T / √d_k) · V

4.2 Self-Attention 如何捕获长距离依赖

Self-Attention 的最大优势在于任意两个位置之间的路径长度为 O(1)：

  • 每个 token 直接与序列中所有其他 token 计算注意力
  • 无论距离多远，信息传递不需要经过中间步骤
  • 这与 RNN（O(n) 路径长度）和 CNN（O(n/k) 路径长度）形成鲜明对比

4.3 与 RNN/CNN 的对比

特性 Self-Attention RNN CNN
最大路径长度 O(1) O(n) O(log_k(n))
计算复杂度/层 O(n²·d) O(n·d²) O(k·n·d²)
并行化 完全并行 无法并行（时序依赖） 完全并行
感受野 全局（一层即可看全序列） 理论全局，实际受梯度消失限制 局部（需堆叠多层扩大）
位置信息 需额外添加（Position Encoding） 自然具备（序列处理） 部分具备（卷积核位置）
长序列性能 优秀（直接建模） 较差（梯度消失/爆炸） 一般（需要多层堆叠）

为什么 Self-Attention 需要位置编码？ Self-Attention 的计算是集合操作（set operation）——它是置换不变的（permutation invariant），即打乱输入顺序不影响输出（仅影响输出顺序）。因此必须通过 Position Encoding 显式注入位置信息。

知识要点
  • Self-Attention：Q=K=V 来自同一序列，用于学习序列内部关系
  • 核心优势：O(1) 路径长度，直接建模长距离依赖
  • 核心劣势：O(n²) 复杂度，长序列内存消耗大
  • Self-Attention 是置换不变的，所以需要 Position Encoding
  • 与 RNN 对比：可并行、无梯度消失问题，但失去了天然的序列偏置

五、Cross-Attention（交叉注意力）

5.1 Encoder-Decoder 中的交叉注意力

Cross-Attention 是连接 Encoder 和 Decoder 的桥梁。在 Transformer 的 Decoder 层中，每一层包含：

  1. Masked Self-Attention：Decoder tokens 互相关注（带因果掩码）
  2. Cross-Attention：Decoder tokens 关注 Encoder 的输出
  3. Feed-Forward Network：逐 token 的非线性变换
Cross-Attention 的 Q/K/V 来源 Q = Decoder_hidden · W^Q （Query 来自 Decoder）

K = Encoder_output · W^K （Key 来自 Encoder）

V = Encoder_output · W^V （Value 来自 Encoder）

CrossAttn = softmax(QK^T / √d_k) · V

核心理解：Decoder 通过 Cross-Attention "查询" Encoder 的输出。每个 Decoder position 根据自身需求（Q），在 Encoder 输出（K,V）中寻找最相关的信息。

Self-Attention 是"自己人开会"，Cross-Attention 是"带着问题去查资料"——区别只在于 Q 和 K/V 来不来自同一个序列。

5.2 在机器翻译中的作用

以"我喜欢猫" → "I like cats" 为例：

  • 生成 "I" 时，Cross-Attention 主要关注"我"
  • 生成 "like" 时，主要关注"喜欢"
  • 生成 "cats" 时，主要关注"猫"

Cross-Attention 学会了源语言和目标语言之间的对齐关系（alignment）。

5.3 在多模态中的作用

Cross-Attention 在多模态模型中广泛使用：

任务 Q 来源 K,V 来源 作用
Image Captioning 文本 Decoder 图像 Encoder (ViT) 生成描述时关注图像区域
Visual QA 问题文本 图像特征 根据问题找图像中的答案
Text-to-Image (Stable Diffusion) 图像 latent 文本 embedding (CLIP) 将文本语义注入图像生成过程
Speech Recognition 文本 Decoder 音频 Encoder 将音频特征对齐到文字
知识要点
  • Cross-Attention：Q 来自 Decoder，K/V 来自 Encoder——Decoder "查询" Encoder
  • 它是 Encoder-Decoder 架构中信息传递的唯一通道
  • 在多模态中，Cross-Attention 是不同模态融合的关键机制
  • 与 Self-Attention 区别：Q 和 K/V 来自不同的序列/模态

六、Attention Mask（注意力掩码）

掩码不是"删掉"某些位置，而是在 softmax 之前把它们的分数打成负无穷——让概率自然归零，梯度也跟着归零。

6.1 Padding Mask

由于 batch 内序列长度不同，短序列需要用 padding token 填充到统一长度。Padding Mask 确保模型不关注 padding 位置。

# Padding Mask 示例
# 序列: ["我", "喜欢", "猫", PAD, PAD]
# Mask:  [1,    1,     1,   0,   0]

# 应用到 Attention scores
# 将 mask=0 的位置设为 -inf，softmax 后这些位置权重为 0
scores = scores.masked_fill(padding_mask == 0, float('-inf'))

6.2 Causal Mask（因果掩码 / 下三角掩码）

Causal Mask 是 Decoder-Only 模型能够并行训练的前提，下面先看它和 Padding Mask 在实现上的差别。

在自回归生成（如 GPT）中，模型在预测第 t 个 token 时只能看到位置 1 到 t 的 token，不能看到未来的 token。Causal Mask 通过一个下三角矩阵实现：

# Causal Mask（下三角矩阵）
# 序列长度 n=5 的 Causal Mask:
# [[1, 0, 0, 0, 0],   ← token 1 只能看自己
#  [1, 1, 0, 0, 0],   ← token 2 能看 1,2
#  [1, 1, 1, 0, 0],   ← token 3 能看 1,2,3
#  [1, 1, 1, 1, 0],   ← token 4 能看 1,2,3,4
#  [1, 1, 1, 1, 1]]   ← token 5 能看所有

import torch
causal_mask = torch.tril(torch.ones(n, n))  # 下三角矩阵

6.3 为什么 GPT 用 Causal Mask？

  • 因果性（Causality）：语言生成是从左到右的，预测下一个词时不应该看到未来的词
  • 训练效率：Causal Mask 允许 Teacher Forcing 训练时所有位置并行计算，但每个位置只看过去
  • 自回归一致性：训练和推理行为一致——训练时通过 mask 模拟推理时的逐步生成

对比 BERT vs GPT 的 Mask 策略：

  • BERT（双向）：只使用 Padding Mask，不用 Causal Mask → 每个 token 可以看到所有其他 token
  • GPT（单向）：使用 Causal Mask + Padding Mask → 只能看到左侧 token
  • 这决定了 BERT 适合理解任务，GPT 适合生成任务

6.4 Mask 的实现方式

Mask 通过在 softmax 之前将被屏蔽位置的分数设为 -∞（实践中用 -1e9 或 float('-inf')）来实现：

softmax([-∞, 2.1, 1.5, -∞, 3.0]) = [0, 0.29, 0.16, 0, 0.55]

-∞ 经过 softmax 后变为 0，实现了"看不见"的效果。这比乘以 0 更优，因为：

  • 乘以 0 作用在 softmax 之前的 logit 上无效（e^0 = 1 ≠ 0）
  • 加 -∞ 确保 e^{-∞} = 0，从根本上消除该位置的贡献
知识要点
  • Padding Mask：防止模型关注无意义的填充 token
  • Causal Mask：下三角矩阵，确保自回归的因果性（只看过去，不看未来）
  • Mask 实现：在 softmax 前加 -∞，使被屏蔽位置的注意力权重为 0
  • GPT 用 Causal Mask 是为了保证训练时与推理时行为一致
  • BERT 不用 Causal Mask，因为它的目标是双向理解而非生成

七、Attention 的可视化与可解释性

7.1 Attention 权重的含义

Attention 权重矩阵可以被可视化为热力图（heatmap），展示模型在生成每个输出时关注了输入的哪些位置。常见的观察模式：

  • 对角线模式：在翻译中表示词序基本对齐
  • 垂直条纹：某些 token（如 [CLS]、标点符号）被所有位置关注
  • 块状模式：同一短语/子句内的 token 互相关注
  • 稀疏模式：低层更局部，高层更全局

7.2 Attention 可视化的工具

  • BertViz：交互式可视化 BERT/GPT 的注意力模式
  • Attention Rollout：沿层传播注意力，追踪信息流
  • Attention Flow：使用最大流算法计算有效注意力
  • 把注意力热力图当作定位问题的线索：它能告诉你模型看了哪里，适合快速缩小排查范围
  • 多头一起看，并注明层号和头号——不同层不同头关注的东西完全不同，只截一张图容易误导
  • 验证结论时配合遮挡实验：把注意力指向的那部分输入删掉，看输出是否真的改变
  • 用注意力分布做工程诊断，比如发现大量注意力堆在起始 token 上（attention sink），提示序列或位置编码配置有问题
  • 不要把"注意力权重高"直接当成"这个词导致了这个输出"，权重高低与因果贡献不是一回事
  • 不要只挑一个好看的头去论证模型学到了语法，几十个头里总能挑出符合预期的那个
  • 不要忽略 Value 的量级：权重再高，如果对应的 Value 范数很小，实际贡献依然可以忽略
  • 不要拿注意力图去向业务方解释模型决策，它是调试工具，不是可交付的解释性证据

7.3 Attention ≠ 解释性的争论

学术界对"Attention 权重是否等于模型解释"存在重要争论：

观点 代表论文 核心论据
Attention 可作为解释 早期直觉 高权重位置看似与预测相关；可视化直观
Attention ≠ 解释 Jain & Wallace (2019)
"Attention is not Explanation"		 ① 不同的注意力分布可产生相同预测
② 注意力与梯度归因方法不一致
③ 对抗性注意力可不改变输出
Attention 不完全是噪声 Wiegreffe & Pinter (2019)
"Attention is not not Explanation"		 完全替换注意力会改变输出；注意力确实包含部分信息

为什么 Attention 不能直接作为解释？

  • 中间表征混淆：Attention 作用在变换后的表征上，而非原始输入上。高注意力不意味着"因为看了这个词"
  • 多层叠加：最终输出是多层 Attention 叠加的结果，单层注意力不能代表整体
  • Value 向量的影响：即使 Attention 权重高，如果 Value 向量方向不对，贡献也可能很小
  • 头间冗余：多头中存在大量冗余 head，剪除后不影响性能

更可靠的解释方法：

  • 梯度归因方法（Gradient × Input, Integrated Gradients）
  • SHAP 值（基于 Shapley Value 的特征重要性）
  • Probing（探针分析，检测特定语言学信息是否被编码）
  • Attention Rollout / Flow（综合多层注意力信息）
知识要点
  • Attention 权重可以可视化，但不等于模型解释
  • "Attention is not Explanation"（Jain & Wallace, 2019）是关键论文：不同注意力分布可产生相同输出
  • 更严格的解释方法：梯度归因、SHAP、Probing
  • 应表达"Attention 有参考价值但不能等同于解释"的辩证观点

八、Attention 的数学本质

8.1 加权平均视角

最基础的理解：Attention 就是一种自适应加权平均。

加权平均视角 output_i = Σ_j α_ij · v_j

其中 α_ij ≥ 0，Σ_j α_ij = 1 （注意力权重为概率分布）

与固定权重（如均匀平均或固定窗口）不同，Attention 的权重是数据自适应的（data-dependent）——权重取决于输入内容，而非预定义的模式。这使得模型能动态决定"从哪里提取信息"。

与 Pooling 的对比：

操作 权重特点 表达能力
Average Pooling 均匀固定 (1/n) 无选择性
Max Pooling one-hot（取最大值） 极端选择
Attention 数据自适应，softmax 归一化 灵活的软选择

8.2 核函数视角

Attention 可以从核方法（Kernel Method）的角度理解：

核函数视角 Attention(q, K, V) = Σ_j [κ(q, k_j) / Σ_l κ(q, k_l)] · v_j

其中 κ(q, k) = exp(q^T · k / √d_k) 是 softmax 核函数

理解要点：

  • softmax attention 对应使用指数核（exponential kernel）
  • 核函数 κ(q, k) 衡量两个向量在某个特征空间中的相似度
  • 归一化因子 Σ_l κ(q, k_l) 使权重成为概率分布
  • 这等价于Nadaraya-Watson 核回归的形式

这个视角启发了 Linear Attention 的研究：如果能将 κ(q, k) 分解为 φ(q)^T · φ(k)，就可以避免 O(n²) 的复杂度：

Linear Attention（核分解） Attn(q, K, V) = [φ(q)^T · Σ_j φ(k_j) · v_j^T] / [φ(q)^T · Σ_j φ(k_j)]

复杂度从 O(n²d) 降为 O(nd²)

8.3 信息检索视角：软查找表（Soft Lookup Table）

Attention 可以被理解为一个可微分的软查找表：

概念 传统查找表（Hard） Attention（Soft）
查询方式 精确匹配 key 与所有 key 计算相似度
返回结果 唯一匹配的 value 所有 value 的加权组合
可微分性 不可微（离散选择） 完全可微（连续权重）
数学表达 V[argmax(sim(q, K))] softmax(sim(q, K)) · V

类比数据库查询：

  • Key：数据库中每条记录的索引字段
  • Value：数据库中每条记录的内容字段
  • Query：你的查询条件
  • 硬查找：SELECT value FROM table WHERE key = query
  • 软查找（Attention）：根据 query 与所有 key 的相似度，对所有 value 做加权平均

这个视角解释了为什么 Attention 如此强大：它是一种可学习的、可微分的信息检索机制，可以端到端训练。

8.4 三种视角的统一

统一理解：Attention 是一种数据自适应的、可微分的、基于相似度的软信息检索机制。

  • 从统计学角度：它是核平滑估计（kernel smoothing）
  • 从信息论角度：它根据互信息动态路由信息
  • 从数据库角度：它是软查询（soft query）
  • 从神经网络角度：它是动态路由/选择门控
知识要点
  • Attention = 数据自适应的加权平均（区别于固定权重的 pooling）
  • 核函数视角：softmax attention 等价于用指数核做 Nadaraya-Watson 回归
  • 信息检索视角：Attention 是可微分的软查找表（Q 查询 K，返回 V 的加权组合）
  • Linear Attention 的理论基础：将 softmax 核分解为特征映射的内积
  • 展示多视角理解体现深度思考能力

九、Q&A

以下是 Attention 机制相关的Q&A及详细参考答案：

Q1：为什么 Scaled Dot-Product Attention 要除以 √d_k？

核心答案：防止点积值过大导致 softmax 进入饱和区。

详细解释：

  1. 假设 q 和 k 的每个分量独立同分布，均值 0，方差 1
  2. 点积 q·k = Σ q_i·k_i 的方差 = d_k（d_k 个方差为 1 的随机变量之和）
  3. 当 d_k 很大（如 64/128）时，点积值的量级为 O(√d_k)，某些分数可能非常大
  4. 大值输入 softmax → 输出接近 one-hot → 梯度趋近于 0 → 训练困难
  5. 除以 √d_k 将方差归一化为 1，使 softmax 工作在梯度较大的区域

一句话总结：缩放因子是维度的归一化，确保 softmax 不会在训练初期就饱和。

Q2：Multi-Head Attention 比 Single-Head 好在哪里？为什么不增加计算量？

优势：

  • 多头允许模型从不同子空间学习不同的关系模式（语法、语义、位置等）
  • 相当于一种"注意力正则化"，避免单头过度集中在某一种模式上
  • 类比 CNN 的多通道/多 filter

为什么不增加计算量：

  • 单头：一次 d_model × d_model 的注意力计算
  • 多头（h 个）：每头 d_model × (d_model/h) 的计算，共 h 头
  • 总计算量：h × O(n² × d_model/h) = O(n² × d_model)，与单头相同
  • 加上最终的 W^O 投影，总参数量为 4 × d_model²
Q3：Self-Attention 和 Cross-Attention 有什么区别？

核心区别在于 Q、K、V 的来源：

  • Self-Attention：Q、K、V 全部来自同一序列（同一输入经过不同投影矩阵得到）
  • Cross-Attention：Q 来自一个序列（如 Decoder），K 和 V 来自另一个序列（如 Encoder）

用途区别：

  • Self-Attention：建模序列内部 token 之间的关系
  • Cross-Attention：建模两个序列/模态之间的关系，是 Encoder-Decoder 间信息传递的桥梁

应用场景：

  • Self-Attention：BERT/GPT 的每一层、ViT 的图像 patch 交互
  • Cross-Attention：翻译 Decoder 关注 Encoder、Stable Diffusion 中文本引导图像生成
Q4：Transformer 为什么需要 Position Encoding？

根本原因：Self-Attention 是置换不变（permutation invariant）的操作。

详细解释：

  • 对于输入 {x_1, x_2, ..., x_n}，无论如何打乱顺序，Self-Attention 计算出的注意力权重不变（因为只依赖于 pairwise 相似度）
  • 这意味着 "我喜欢你" 和 "你喜欢我" 对模型来说完全等价——这显然是错误的
  • Position Encoding 通过在输入中注入位置信息，打破了这种对称性

对比：RNN 天然具有位置感知能力（时序处理），CNN 通过卷积核的局部连接隐式编码位置。只有 Attention 需要额外添加位置信息。

常见编码方式：正弦/余弦固定编码（原始 Transformer）、可学习编码（BERT）、RoPE 旋转位置编码（LLaMA）、ALiBi（线性偏置）。

Q5：Attention 的计算复杂度是什么？有哪些降低复杂度的方法？

标准 Attention 复杂度：

  • 时间复杂度：O(n² · d)，其中 n 是序列长度，d 是特征维度
  • 空间复杂度：O(n²)（存储注意力矩阵）
  • 瓶颈：n² 项使得长序列处理非常昂贵（n=4096 时需 67M 元素的注意力矩阵）

降低复杂度的方法：

  • Sparse Attention：只计算部分位置对的注意力（Longformer, BigBird）→ O(n√n) 或 O(n·k)
  • Linear Attention：利用核分解避免显式计算 n×n 矩阵 → O(n·d²)
  • Flash Attention：不降低理论复杂度，但通过 IO-aware 算法减少内存访问，实际加速 2-4 倍
  • Multi-Query Attention (MQA)：所有 head 共享 K,V，减少 KV cache
  • Grouped-Query Attention (GQA)：MQA 和 MHA 的折中，分组共享 K,V
  • Ring Attention：分布式计算，将序列分块到多设备
Q6：为什么 GPT 使用 Causal Mask 而 BERT 不使用？

核心原因：训练目标不同决定了 mask 策略。

GPT（Causal Mask）：

  • 训练目标：Next Token Prediction（预测下一个 token）
  • 需要因果性：预测第 t 个 token 时，只能用 1~(t-1) 的信息
  • Causal Mask 确保训练时每个位置只能看到之前的 token
  • 这使得训练和推理一致——推理时也是逐步生成

BERT（无 Causal Mask）：

  • 训练目标：Masked Language Model（填空题，预测被 mask 的 token）
  • 每个 token 需要看到上下文（双向），才能推断被 mask 的内容
  • 只使用 Padding Mask，允许全序列可见
  • 代价：不适合生成任务（因为训练时看到了未来）

一句话：生成模型需要因果性 → Causal Mask；理解模型需要双向上下文 → 无 Causal Mask。

Q7：Attention 权重能作为模型的解释吗？

简短回答：有参考价值，但不能等同于解释。

支持观点：

  • Attention 权重直观地展示了模型"关注"了哪些 token
  • 在翻译中，注意力矩阵常常对齐到有意义的词对

反对观点（主流）：

  • Jain & Wallace (2019)：存在不同的注意力分布却产生相同预测的情况
  • 注意力作用在经过变换的中间表征上，不直接反映输入重要性
  • 多层注意力叠加后，单层的注意力不代表最终效果
  • 多头中存在冗余 head，可被剪除而不影响性能

建议回答："Attention 可以提供一定的直觉和参考，但作为严格的模型解释并不可靠。更好的解释方法包括梯度归因、SHAP、以及 Attention Rollout 等综合方法。"

Q8：Attention 机制的数学本质是什么？请从多个角度解释。

三个核心视角：

1. 加权平均视角：

  • Attention 输出是 Value 向量的加权平均，权重由 Query-Key 相似度决定
  • 与固定权重不同，Attention 权重是内容自适应的（content-based addressing）

2. 核函数视角：

  • Softmax attention 等价于使用指数核 κ(q,k) = exp(q^T·k/√d) 做 Nadaraya-Watson 核回归
  • 这启发了 Linear Attention：如果核可以分解为 φ(q)^T·φ(k)，则可以 O(nd²) 计算

3. 信息检索/软查找表视角：

  • Key 是存储的索引，Value 是存储的内容，Query 是查询条件
  • 硬查找：SELECT value WHERE key = query（精确匹配）
  • 软查找（Attention）：根据相似度对所有 value 加权组合（模糊匹配）
  • 关键优势：可微分 → 可端到端训练
Q9：KV Cache 是什么？为什么在推理时需要？

KV Cache 的含义：在自回归推理时，缓存已计算过的 Key 和 Value 向量，避免重复计算。

为什么需要：

  • 自回归生成时，每步生成一个新 token
  • 生成第 t 个 token 时，需要对位置 1~t 做 Attention
  • 前 1~(t-1) 个位置的 K、V 在之前步骤已经计算过
  • 不缓存则每步都要重新计算所有位置的 K、V → O(n²) 总计算量
  • 使用 KV Cache 后，每步只需计算新 token 的 K、V → O(n) 总计算量

内存占用：

  • KV Cache 大小 = 2 × num_layers × seq_len × d_model × batch_size × dtype_size
  • 例如 GPT-3：2 × 96 × 2048 × 12288 × 2 bytes ≈ 9.6 GB（每个请求！）
  • 这就是 MQA/GQA 的动机：减少 K,V head 数来减小 cache
Q10：Flash Attention 是什么？它解决了什么问题？

Flash Attention（Dao et al., 2022）是一种 IO-aware 的注意力算法，不改变数学计算结果，但通过优化内存访问模式实现显著加速。

解决的问题：

  • 标准 Attention 的瓶颈不是计算量，而是内存带宽
  • n×n 的注意力矩阵需要从 HBM（高带宽内存）读写，这是主要的时间消耗
  • GPU 的计算速度远大于内存带宽 → Attention 是 memory-bound 操作

核心思想：Tiling（分块计算）

  • 将 Q, K, V 分成小块，在 SRAM（片上高速缓存）中完成计算
  • 避免将完整的 n×n 注意力矩阵写入 HBM
  • 通过在线 softmax（online softmax）算法实现分块 softmax 的精确计算
  • 结果：2-4 倍加速，内存从 O(n²) 降至 O(n)

关键点：Flash Attention 是精确的（不是近似），数学等价于标准 attention。它的优势纯粹来自于更好的 IO 调度。

Q11：Softmax 在 Self-Attention 中的实际作用是什么？只做归一化可以吗？

Softmax 有三个实际作用，远不止"归一化"：

  • 概率化：将任意实数分数转换为 [0,1] 的概率分布（和为 1），使加权求和具有明确的概率语义（"按概率提取 Value"）
  • 放大差异：指数函数让高分项被指数级放大、低分项被指数级抑制，形成"赢者通吃"效果，使模型能选择性地关注重要 token
  • 可微分：Softmax 连续可微，支持反向传播；若改用 argmax（硬选择）则不可微，无法训练

如果改用简单归一化（如 L2 归一化），模型无法有效放大重要 token 的贡献——softmax 的指数非线性正是"选择性关注"的来源。
