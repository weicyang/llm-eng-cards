IE-05 · Agent 代码解释器报错处理

核心问题

Agent调用了一个Python代码解释器工具，但运行时报错了，你要怎么处理？

处理流程

1. 错误捕获与分类

  • 语法错误：SyntaxError、IndentationError
  • 运行时错误：NameError、TypeError、ValueError
  • 资源错误：FileNotFoundError、PermissionError
  • 逻辑错误：代码能跑但结果不对

2. 自动修复循环

Agent自修复机制：

  1. 捕获错误信息（traceback）
  2. 将错误信息 + 原代码 + 用户意图一起传给大模型
  3. 大模型分析错误原因，生成修复后的代码
  4. 重新执行，检查是否通过
  5. 设置最大重试次数（如3次），防止无限循环

3. 上下文保留

每次修复时，保留：

  • 原始用户意图
  • 之前的代码版本
  • 错误历史信息
  • 已成功的执行结果

4. 降级策略

如果多次修复仍失败：

  • 简化任务：将复杂任务拆解为更简单的步骤
  • 更换工具：尝试其他代码解释器（如Bash）
  • 人工介入：将问题和错误信息提交给人类开发者

安全防护

  • 沙盒执行：Docker容器隔离，防止恶意代码
  • 资源限制：CPU、内存、执行时间上限
  • 权限控制：禁止网络访问、文件系统写入
  • 代码审计：敏感操作拦截（如os.system）

高频考点

展示工程化思维：不只是调API，而是完整的错误处理、自动修复、安全防护体系。
