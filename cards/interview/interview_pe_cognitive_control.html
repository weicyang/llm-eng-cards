IL-04 · Prompt Engineering 能操控大模型认知吗？

核心问题

大模型没有人类的信念和三观。"认知"在数学层面就是参数分布和逻辑权重。Prompt 能否真正改变它？

四种技术手段的层次

Level 1: Prompt Engineering（表层引导）

"你现在是数学天才" → 模型并没有变聪明

  • 只是在潜空间中激活了与"数学天才"相关的表达方式
  • 改变了生成下一个词的条件概率
  • 作用于瞬时 KV Cache（工作记忆），新对话即清空
  • 参数没动，权重没变

如果模型预训练时没见过某知识，再精妙的 Prompt 也只能幻觉。

Level 2: RAG（开卷考试）

给大模型发一本参考书：

  • 大模型本身不变，回答前先"翻书"
  • 书的内容填入 Prompt（仍作用于工作记忆）
  • 能解决"没见过"的问题，但没有重塑内在认知

Level 3: 表征工程（半物理操控）

不改参数，但干预推理的中间处理：

  • 截获流动张量，找到"诚实"向量方向
  • 模型想撒谎时，强加诚实向量 → 说出实话
  • 比 Prompt 深刻（干预中间过程），但仍未改变长期记忆

Level 4: 微调 / 预训练（真正重塑）

只有发动梯度下降 + 反向传播，修改权重参数：

  • 固化在千亿级参数矩阵中（长期记忆）
  • 类比：长期学习和磨练 → 神经通路重新生长
  • 真正的认知操控，必须发生在参数写入的那一刻

技术选型全景

手段改变什么持久性类比
Prompt条件概率（注意力引导）瞬时劝他 → 引导
RAG背景信息（外部知识）会话级让他看书 → 参考
表征工程中间激活（推理干预）单次推理微创手术
微调权重参数（长期记忆）永久长期磨练 → 真的变了

高频考点

通关秘籍

  1. 去魅 - 大模型没有信念，认知 = 参数分布，角色扮演 = 条件概率转移
  2. 核心论点 - Prompt 作用于瞬时 KV Cache，不涉及梯度更新，改不了认知
  3. 工程视野 - 激发已有能力用 Prompt，引入新知识用 RAG，改变长期行为用微调
  4. 加分项 - 提到表征工程（干预隐藏激活）
