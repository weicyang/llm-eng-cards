一、Transformer 架构核心

Transformer 是当前大模型的基础架构，由 Encoder 和 Decoder 组成。重点关注三个核心组件：

组件作用高频考点
Self-Attention计算序列内每个 token 与其他 token 的关联度QKV 矩阵维度、多头注意力
Position Encoding注入位置信息（Attention 本身无位置感知）RoPE vs ALiBi vs Sinusoidal
FFN / MLP非线性变换，提升表达能力SwiGLU 激活函数、参数占比
Self-Attention 计算复杂度 O(n²d)，这是大模型上下文窗口受限的根本原因之一。KV Cache 和 GQA 是降低推理成本的核心手段。

二、KV Cache 与推理优化

Why：为什么需要 KV Cache

自回归生成时，每生成一个新 token 都需要重新计算之前所有 token 的 Key 和 Value。KV Cache 将已计算的 K/V 矩阵缓存，避免重复计算。

How：显存瓶颈

模型参数量KV Cache 显存 (4K context)KV Cache 显存 (32K context)
LLaMA-7B7B~1.2 GB~9.6 GB
LLaMA-13B13B~2.2 GB~17.6 GB
LLaMA-70B70B~8 GB~64 GB

优化方案

  • GQA (Grouped Query Attention)：多个 Query head 共享一组 KV，显存降低 4-8 倍
  • PagedAttention：借鉴操作系统虚拟内存分页，消除显存碎片
  • KV Cache 量化：将 KV 从 FP16 量化到 INT8/INT4

三、MoE 混合专家模型

MoE (Mixture of Experts) 将 FFN 层替换为多个专家网络，每次只激活其中一小部分：

特性Dense 模型MoE 模型
激活参数100% 参数参与仅 ~20% 专家激活
训练成本与推理成本成正比训练用全部专家，推理只用 Top-K
代表模型LLaMA, GPT-4Mixtral 8x7B, DeepSeek-V2
Mixtral 8x7B：总参数 47B，每次激活 13B（2/8 专家），效果接近 70B Dense 模型但推理成本只相当于 13B。

四、Scaling Laws 与涌现能力

Scaling Laws 揭示了三要素（参数量 N、数据量 D、计算量 C）与模型性能的幂律关系：

  • Chinchilla 最优：参数量和数据量应按比例同步增长（1:20 tokens/param）
  • 涌现能力：模型规模超过阈值后突然出现的能力（CoT 推理、多语言等），小模型完全不具备
  • Grokking：训练后期突然从记忆切换到泛化，需要足够长的训练时间

  • 能举出 Scaling Laws 的反例（如 Grokking）

高频问答

Self-Attention 的 QKV 分别代表什么？计算过程是怎样的？
Q(Query) 代表"我在找什么"，K(Key) 代表"我有什么"，V(Value) 代表"我的内容"。计算过程：(1) 输入向量分别乘以三个权重矩阵得到 Q、K、V；(2) 计算 Q·K^T 得到注意力分数矩阵；(3) 除以 √d_k 做缩放（防止梯度消失）；(4) 经 Softmax 归一化为概率分布；(5) 乘以 V 得到加权输出。多头注意力将 QKV 拆分为 h 组并行计算，最后拼接。核心公式：Attention(Q,K,V) = softmax(QK^T/√d_k)V。
KV Cache 的显存消耗为什么是推理优化的关键瓶颈？
自回归生成中，每生成一个新 token 都要用之前所有 token 的 K 和 V 做 Attention 计算。不用 KV Cache 则每个 token 都重算历史 K/V，复杂度 O(n²)；用 KV Cache 缓存历史 K/V，新 token 只需算自己的 K/V 再做一次 Attention，复杂度降到 O(n)。但代价是 KV Cache 随序列长度线性增长：LLaMA-70B 在 32K context 下需 ~64GB 显存存 KV Cache，甚至超过模型参数本身的显存占用。因此 GQA（共享 KV）、PagedAttention（分页管理）、量化压缩成为必选优化。
MoE 相比 Dense 模型，训练和推理的成本差异是什么？
训练时 MoE 所有专家都参与前向/反向传播，训练成本接近总参数量（如 Mixtral 8x7B 的 47B）；推理时 Router 只激活 Top-K 专家（如 2/8），实际推理成本只相当于激活参数量（13B）。因此 MoE 的核心优势是"用训练成本换推理效率"——训练贵但推理快。劣势：(1) 显存仍需加载全部专家参数；(2) 专家负载均衡是难点，Router 倾向选择少数专家导致其他专家训练不充分；(3) 通信开销在分布式场景下不可忽视。
什么是涌现能力？为什么小模型做不到？
涌现能力（Emergent Abilities）指模型规模超过某个阈值后突然出现、小模型完全不具备的能力。典型案例：(1) CoT 推理——参数量 < 100B 时 Chain-of-Thought 反而降低准确率，超过后才有效；(2) 多语言翻译——小模型只能处理训练数据中出现过的语言对；(3) 算术推理——3 位数乘法在 ~6B 参数时突然出现。本质原因是大模型在预训练中接触了足够多的模式和组合，形成了一种"压缩式泛化"。但学术界也有争议：有研究认为涌现是评估指标选择的结果（使用连续指标则平滑变化）。
RoPE 位置编码和传统 Sinusoidal 编码有什么区别？
Sinusoidal 编码将位置信息加到 input embedding 上（加法注入），RoPE（Rotary Position Embedding）将位置信息编码为旋转矩阵，应用到 Q 和 K 上（乘法注入）。RoPE 的优势：(1) 相对位置感知——两个 token 的 Attention 分数只取决于它们的相对距离，而非绝对位置；(2) 外推性更好——理论上可以处理训练时未见过的更长序列（实际仍需 NTK-aware scaling 等微调）；(3) 不增加额外参数。LLaMA 系列、Qwen 系列均采用 RoPE。ALiBi 是另一种方案，直接在注意力分数上加距离偏置，不需要位置编码向量。
被问到"如何优化大模型推理延迟"，怎么组织回答？
从四个层面组织：(1) 架构层——KV Cache（避免重复计算）、GQA/MQA（减少 KV 头数）、MoE（只激活部分参数）；(2) 系统层——Continuous Batching（动态合并请求）、PagedAttention（显存分页管理）、Speculative Decoding（小模型草稿+大模型验证）；(3) 计算层——INT8/INT4 量化、算子融合、FlashAttention（IO-aware 实现）；(4) 部署层——Tensor Parallelism（模型分片）、模型蒸馏（大→小）。回答时给出具体数字加分，如"FlashAttention 将 Attention 速度提升 2-4 倍，显存从 O(n²) 降到 O(n)"。
