IE-04 · RAG、MCP 和 Agent 的协同架构

核心问题

RAG、MCP 和 Agent 三者不是孤立的，在理想的 AI 架构中形成完整闭环。

三者的核心定位

Agent - 大脑（指挥官）

解决：复杂任务的自主规划与执行

  • 任务编排、意图路由、自主反思

工程落地坑：

  • 死循环（反复调用错误工具）→ 状态机/工作流编排
  • 长任务断片 → 分层记忆（短期滑动窗口 + 长期向量库）
  • 黑盒不可控 → 关键节点加 Human-in-the-Loop 审批

MCP - 神经总线（标准化连接）

解决：数据与工具连接的标准化问题（统一 Type-C 接口）

  • 统一定义三种能力：静态资源、动态工具、提示词模板

安全对策：

  • 统一鉴权 + RBAC 最小权限
  • 高频调用走本地 STDIO 直连
  • 远程调用做请求聚合和降级

RAG - 外挂记忆库

解决：知识边界和幻觉问题（开卷考试）

  • 语义分块 + Query 重写 + BM25/向量双路混合检索 + Rerank
  • 多跳推理 → 知识图谱增强

协同架构

在理想的现代 AI 架构中：

  • Agent 是大脑，运筹帷幄
  • MCP 是神经总线，标准化连接一切
  • RAG 是外挂记忆库，可封装成标准 MCP 资源挂在总线上

三者构成：数据接入 → 知识内化 → 智能执行的完整闭环。
