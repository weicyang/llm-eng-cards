DP20 · MiniMax-H3 云端自部署方案

33B 开源权重 / Context-IR 与 2K 超分仍托管 / GPU 租赁 vs 按秒计费 / ComfyUI·SGLang

H3 的「开源」只覆盖生成主干。提示词预处理和 2K 超分仍可走官方 API。成本从按秒计费变成按卡时计费之后，批量出片才可能掉到大约八分之一；偶发几条视频，API 仍然更便宜。

一、H3 不是「又一个文生视频 API」

MiniMax-H3（2026-07-31 上线的全模态视频模型，消费品牌 Hailuo 3）一次前向同时吃文本、图、视频、音频，吐最长 15 秒、最高 2K、带原生立体声的成片。社区拆开 Hugging Face 权重后，主干是约 330 亿参数的密集 Transformer，不是网上流传的 1380 亿（那更像和语言模型 M3 搞混）。

规格数值
输入文本 / 最多约 9 图 / 视频 / 音频
输出4–15 秒，最高 2K，最高 24 fps，原生立体声
主干参数~33B（H3-Base），不是 MoE
官方 API 2K约 0.13 美元/秒（约 0.8 元/秒量级），15 秒接近 2 美元
15 秒 2K 一条接近 2 美元。做产品试 prompt 还能忍；一天出 50 条素材就是 100 美元级。视频标题里的「1/8」针对的是这条成本曲线的右半边——用量起来之后，卡时费才打得过按秒计费。

按秒计费卖的是「零运维」；卡时计费卖的是「利用率」。没用量就不要为 1/8 去养一张卡。

二、三模块：开源的和没开源的

完整 H3 是三段流水线：H3-Context-IR 把自由文本和参考素材改写成模型要的结构化中间表示；H3-Base 本地可部署，原生大约 768p；H3-Regenerate-2K 把 768p 拉到 2K，权重尚未开源。

完整 2K 成片 自由 prompt + 参考图/音/视频 │ ▼ [H3-Context-IR] ← 托管 API（本地没有官方改写器） │ 结构化三字段 IR ▼ [H3-Base FL2VA / Ref2VA] ← 开源，SGLang / ComfyUI / diffusers │ 768p 视频+立体声 ▼ [H3-Regenerate-2K] ← 托管 API（未开源） │ ▼ 2K 成片 只部署 Base = 数据可不出机房，但分辨率停在 768p
路径数据是否离机分辨率运维
官方 API 直出素材上传官方2K 一步到位零
只本地 Base可内网768p要 GPU
本地 Base + 官方 IR/2K中间结果仍出网2K混合
本地跑 Base 并不会自动获得官方那种「随便写一句人话也能出片」的体验。Context-IR 没开源，意味着你要自己写结构化 prompt，或继续调那一段 API。

开源权重 ≠ 开源产品。H3 开的是发动机，方向盘和 2K 后处理还可以继续收费。

三、成本账：为什么能压到约 1/8

API：2K 约 0.13 美元/秒。云端自部署：租 24GB 级 GPU（常见单卡 4090 云主机按小时计），权重量化后在 --lowvram 下能跑，批量排队把卡填满。当生成任务从「一天几条」变成「一条流水线持续出片」，分母变成卡时而不是片长，单价才会掉到标题说的约 1/8。

粗算：15 秒 2K 官方约 2 美元；若云卡每小时 2 美元、满载每小时能出 8 条 768p，单片卡时约 0.25 美元，相对 2 美元就是约 1/8。利用率掉到 30% 以下，空转费会把优势吃光。所以账要按「一周真实出片数」而不是峰值理论吞吐来算。

单片成本 ≈ max( API单价 × 秒数 , 卡时单价 / 每小时出片数 )
利用率 < 30% 时，自部署往往更贵
场景更便宜的一边原因
偶发 demo、改 promptAPI没有空闲卡时
工作日持续出片、可降到 768p自部署卡被排满
必须 2K 且数据敏感混合或等超分开源2K 模块仍可能走 API
消费级 12GB 卡 + 约 64GB 内存「能跑」的是打折体验：768p、动态卸载、速度慢。真要跟官方 2K 比质量，账不能按最低硬件门槛算，要按「能稳定出你要的分辨率」的卡来算。

1/8 是满载批量的数字，不是开机第一小时的数字。空转的 GPU 是最贵的 API。

四、云端自部署路径

两条主流：ComfyUI 可视化（≥0.30，模板搜 T2V / FLF2V / R2V）；SGLang Diffusion 做多用户服务（FL2VA 与 Ref2VA 要分开拉起）。24GB 卡推荐 pruned int8 + 低显存卸载；多卡再用 Ulysses 等并行。权重来自 MiniMaxAI/MiniMax-H3 或 Comfy-Org 单文件封装。

栈何时用坑
ComfyUI + Partner API 节点先验证工作流仍按秒计费，不是自部署
ComfyUI + 本地权重团队内少量出片24GB 必须 lowvram，OOM 常见
SGLang 服务化要给业务系统当 API两套 checkpoint、并行参数要配对
先用短时长、768p 把 prompt 和工作流跑通，再加秒数和 2K；云主机设闲时关机，避免空转把 1/8 吃回去。
一上来按 1380 亿参数去买 8 卡集群；或把家用 12GB 体验当成生产 2K 基线。

自部署的最小闭环是「排队 + 关机策略 + 分辨率降级开关」，不是先把所有量化格式下完。

五、质量、合规与选型

Community License 排除欧盟、英国、韩国、美国商用；中国大陆可下载研究/商用。文本编码器部分是 Apache-2.0。产品要服务被排除地区，本地权重这条路走不通，只能官方 API 或等条款更新。

质量对照不要只看「能不能出 15 秒」。官方 2K 路径包含未开源超分；本地 Base 停在约 768p，运动一致性、字幕边缘和音频同步都要单独抽检。工作流上建议固定三条黄金 prompt（人像、产品、字幕），每周回归一次，避免量化或 Comfy 节点升级把成片质量静默打穿。

约束含义动作
Community License美/欧/英/韩商用排除那些地区只用官方 API 或换模型
权重体积原始数百 GB，剪枝约 42GB云盘首次拉取计入上线工期
分辨率本地 ≈768p，2K 靠托管超分产品页写清默认分辨率
黄金片回归量化/节点会改画质固定 3 条 prompt 做前后对比
怎么选 只要几条 demo？ → 官方 API 批量出片且可接受 768p？ → 云 GPU 自部署 Base 要 2K + 数据尽量不出？ → Base 本地 + 仅超分走 API（仍有出网） 要服务美/欧用户？ → 不要用排除地区的本地权重商用
开源权重体积：原始 diffusers 数百 GB；Comfy 剪枝量化可压到约 42GB 量级。下载时间和磁盘往往比「有没有 12GB 显存」更先成为瓶颈。云端自部署的隐藏成本是对象存储和首次拉取，要算进 1/8。把「权重校验哈希」写进开机脚本，避免下到一半的文件被当成可用模型。
不要把 MiniMax-H3 的出片成本和 M3 的 token 单价放在同一张表里比。一个按秒出视频，一个按 token 出文本，分母不同，1/8 会对不上。

选型顺序是：合规 → 分辨率 → 用量 → 再谈自部署。反过来说会买错卡。

六、上线清单：从试跑到值班

自部署不是装上 Comfy 就算完成。最小值班闭环是：权重在对象存储可重建、队列能重试、闲时关机、三条黄金 prompt 能做回归。缺关机策略，1/8 会被空转吃掉；缺回归，一次节点升级就能把成片质量打穿。

阶段完成定义常见漏项
试跑768p、4–8 秒、单条能出直接上 15 秒 2K
排队失败可重试、可取消人肉点 Comfy 当生产
成本闲时关机 + 周账单对照 API卡 24 小时挂着
质量3 条黄金片前后对比只看「能出」不看「能用」
合规用户地区对照 License用排除地区权重做海外商用
先按一周真实出片量算利用率，再决定续租哪张卡。分辨率做成配置开关，默认 768p，2K 走明确的付费/API 路径。
把 Partner API 节点当成自部署，或把 12GB 点亮体验写成生产容量规划。

值班看的是「坏了能不能重来、闲了会不会停、画质会不会偷偷变」，不是权重是不是最新量化。

Q&A

MiniMax-H3 到底是多少参数？
开源到 Hugging Face 的生成主干经社区拆解约为 33B 密集 Transformer，不是网上流传的 1380 亿。后者更像和同期语言模型规划数字混淆。配硬件、估显存，以实际权重体积和官方 33B 口径为准，不要按自媒体参数去买集群。
为什么本地部署还要调 API？
H3-Context-IR 和 H3-Regenerate-2K 没有随 Base 开源。本地只能稳定产出约 768p，自由文本也缺少官方改写器。要官方同款 2K 或「随便写人话也能出片」，仍需打这两段托管接口，或自己重做预处理。这是产品开源和引擎开源的差别。
什么时候自部署真能到约 1/8 成本？
当生成从偶发变成排队满载，成本从「秒 × API 单价」变成「卡时 / 每小时片数」。空闲 GPU、只跑 768p 却按 2K API 去比、以及首次下载权重的时间，都会让 1/8 失效。先用一周真实出片量算利用率，再决定租卡。
12GB 显存能不能当生产？
社区说 12GB 加约 64GB 内存、动态卸载可以启动，但那是 768p 慢速体验。24GB 卡加 pruned int8 才比较接近可值班。生产基线应按「稳定分辨率和时延」买卡，而不是按「官方最低能点亮」买卡。
ComfyUI 和 SGLang 怎么选？
人和工作流试验用 ComfyUI，模板能覆盖文生、首尾帧、参考生。要对业务系统提供并发 API、把 FL2VA/Ref2VA 当微服务，用 SGLang。两者都能加载开源权重；Partner API 节点仍然是按秒计费，不算自部署。
中国团队能不能商用开源权重？
Community License 排除的是欧、英、韩、美，中国大陆不在排除名单，可以下载做研究和商用。若产品用户在排除地区，不要用这条本地权重路径对那些地区提供服务。文本编码器单独是 Apache-2.0，限制更少，但生成主干仍看 Community License。
H3 和 MiniMax M3 语言模型是不是一回事？
不是。H3 是视频生成模型（Hailuo 3 消费品牌），主干约 33B，输出是带音频的视频。M3 / M3 Pro 是编程和对话用的语言模型。配卡、估成本和写工作流时不要混用文档。视频标题里的 1/8 说的是出片卡时，不是 token 单价。
只部署 Base 能不能对标官方 2K 成片？
不能当成同一产品。本地 Base 停在约 768p，2K 要走未开源的 Regenerate-2K。画质、字幕边缘和运动一致性都要按你实际分辨率验收。若产品页承诺 2K，就必须把超分路径（API 或等待开源）写进方案，不能拿 768p 试跑结果当 2K 承诺。
权重下载为什么经常比显存先成为瓶颈？
原始 diffusers 权重以数百 GB 计，Comfy 剪枝量化后仍约 42GB。云主机第一次拉权重、对象存储流量和磁盘，都会进工期和账单。12GB 显存「能点亮」解决不了「权重还在下载」的问题。上线计划要把拉取和校验写成独立步骤，而不是开机当天开始出片。
