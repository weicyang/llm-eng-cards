一、图数据基础

图就是"点 + 关系"。它和图片、句子最大的区别在于既没有固定顺序也没有固定邻居数——所以任何按位置索引的算子（卷积窗口、位置编码）搬到图上都直接失效，必须换成对邻居顺序不敏感的运算。

1.1 图的定义

图 G = (V, E) 由节点集 V 和边集 E 组成。

  • 邻接矩阵 A：A[i][j] = 1 表示节点 i 与 j 之间存在边
  • 度矩阵 D：对角矩阵，D[i][i] = Σ_j A[i][j]（节点 i 的度）
  • 特征矩阵 X：X ∈ ℝ^(N×F)，N 个节点每个有 F 维特征

1.2 图的类型

类型特点邻接矩阵性质
无向图边无方向A = Aᵀ（对称矩阵）
有向图边有方向A ≠ Aᵀ（非对称）
加权图边带权重A[i][j] = w_ij
异构图多类型节点/边需要多种关系矩阵

1.3 图的表示方法

方法空间复杂度适用场景优缺点
邻接矩阵O(N²)稠密图查询 O(1)，但稀疏图浪费空间
邻接表O(N+E)稀疏图节省空间，遍历邻居高效
边列表O(E)边为中心的算法简单直观，查邻居需遍历
CSR/CSCO(N+E)GPU 计算内存紧凑，适合稀疏矩阵运算
  • 邻接矩阵 vs 邻接表的选择取决于图的稀疏程度；真实世界图通常极其稀疏（社交网络边数远小于 N²）
  • 度矩阵 D 在 GCN 归一化中起关键作用
  • 自环（self-loop）通过 Ã = A + I 添加，确保聚合时包含节点自身信息

二、为什么需要 GNN

MLP 要求输入定长、CNN 要求规则网格、RNN 要求线性序列，图三个都不满足。GNN 的解法是不去描述全局结构，只规定"一个节点该怎么从它的邻居收信息"，然后把这一条规则在所有节点上复用。

2.1 传统神经网络的局限

  • CNN：假设数据在规则网格上（图像像素），无法直接处理不规则拓扑结构
  • RNN：处理序列（一维链式结构），无法捕捉任意图连接关系
  • 全连接网络：将邻接矩阵展平会丢失结构信息，且参数量随节点数平方增长

2.2 图数据的核心挑战

  • 不规则结构：每个节点的邻居数不同，无法用固定大小卷积核
  • 排列不变性 (Permutation Invariance)：节点编号的排列不应影响输出结果，即 f(PAP^T, PX) = Pf(A, X)
  • 无固定参考点：不像图像有左上角，图没有全局坐标系

2.3 GNN 的核心思想

通过局部聚合邻居信息来学习节点表示，天然满足排列不变性。每个节点从其邻域收集信息并更新自身表示。

  • GNN 的排列不变性/等变性是设计核心：对称的聚合函数（sum/mean/max）保证了这一性质
  • "为什么不能直接用 MLP？"→ 丢失拓扑结构 + 无法泛化到不同大小的图 + 不满足排列不变性
  • 图数据无法直接做傅里叶变换是引出谱图卷积的动机

三、消息传递范式 (Message Passing)

消息传递只有三步：邻居各发一条消息、把这些消息聚合成一个向量、用它更新自己。唯一的硬约束是聚合函数必须满足置换不变性（换邻居顺序结果不变），所以能用的就是求和、均值、最大值这几类。

3.1 通用框架

一层消息传递（以中心节点 v 为例，邻居 N(v) = {a, b, c}） 第 l 层输入表示 第 l+1 层输出 ┌────────┐ │ h_a⁽ˡ⁾ │──► m_a = MSG(h_v, h_a, e_va) ─┐ └────────┘ │ ┌────────┐ │ ┌──────────────┐ │ h_b⁽ˡ⁾ │──► m_b = MSG(h_v, h_b, e_vb) ─┼──►│ AGG(·) │ └────────┘ │ │ sum/mean/max│ ┌────────┐ │ │ 必须置换不变 │ │ h_c⁽ˡ⁾ │──► m_c = MSG(h_v, h_c, e_vc) ─┘ └──────┬───────┘ └────────┘ │ a_v ┌────────┐ ▼ │ h_v⁽ˡ⁾ │───────────────────────────────────► UPDATE(h_v⁽ˡ⁾, a_v) └────────┘ │ ▼ h_v⁽ˡ⁺¹⁾ 堆 L 层 ⇒ 每个节点的感受野是 L 跳邻域 L=1 : 直接邻居 L=2 : 邻居的邻居 L=3 : 三跳内全部节点 邻居数按平均度 d 指数增长（d^L），这既是表达力来源，也是显存爆炸的来源

MPNN (Message Passing Neural Network) 将几乎所有 GNN 统一为两步迭代：

消息计算： m_v^(t+1) = AGG({M_t(h_v^(t), h_u^(t), e_{vu}) : u ∈ N(v)})

节点更新： h_v^(t+1) = U_t(h_v^(t), m_v^(t+1))

其中：

  • M_t：消息函数，计算邻居 u 发送给节点 v 的消息
  • AGG：聚合函数（sum / mean / max），需满足排列不变性
  • U_t：更新函数，结合旧表示和聚合消息生成新表示
  • N(v)：节点 v 的邻居集合

3.2 不同聚合函数对比

聚合方式公式特点适用场景
SumΣ h_u保留邻域"总量"信息可区分不同结构（GIN）
Mean(1/|N|)Σ h_u归一化，平滑邻域节点分类（GCN）
Maxmax(h_u)捕捉最显著特征点云处理（PointNet）

3.3 图级读出 (Readout)

对于图级任务（图分类/回归），需要将所有节点表示汇总为图表示：

h_G = READOUT({h_v^(T) : v ∈ V})
常用方法：全局求和、全局均值、全局最大值、层次化池化 (DiffPool/SAGPool)
  • 消息传递 = 邻域聚合 + 特征变换，几乎所有空间域 GNN 都可纳入此框架
  • K 层消息传递 = K-hop 邻域信息传播（感受野随层数线性增长）
  • 聚合函数的选择直接影响模型表达能力：sum ≥ mean ≥ max（GIN 论文证明）

四、GCN (Graph Convolutional Network)

GCN 的公式看着像谱图理论，干的事其实很朴素：把自己和邻居的特征按度做一次加权平均，再线性变换加激活。度大的邻居权重被压低，目的是别让枢纽节点的信息淹没掉所有人。

4.1 从谱图卷积到空间卷积

谱方法发展路径：

  1. Spectral CNN (2014)：在图拉普拉斯 L 的特征空间做卷积，计算量 O(N²)
  2. ChebNet (2016)：用切比雪夫多项式近似滤波器，避免特征分解
  3. GCN (Kipf 2017)：取一阶切比雪夫近似 + 重参数化，得到简洁公式

4.2 GCN 核心公式

H^(l+1) = σ(D̃^(-1/2) Ã D̃^(-1/2) H^(l) W^(l))

其中：
• Ã = A + I_N（添加自环的邻接矩阵）
• D̃ = 对角度矩阵，D̃_ii = Σ_j Ã_ij
• H^(l) ∈ ℝ^(N×d)：第 l 层节点表示
• W^(l) ∈ ℝ^(d×d')：可学习权重矩阵
• σ：激活函数（通常 ReLU）

4.3 归一化的直觉理解

D̃^(-1/2) Ã D̃^(-1/2) 实现的是对称归一化：

  • 对于边 (i,j)：权重为 1/√(d̃_i · d̃_j)
  • 高度节点的贡献被削弱，避免度大节点主导聚合
  • 等价于：h_v = Σ_{u∈N(v)∪{v}} (1/√(d̃_v · d̃_u)) · h_u · W

4.4 过平滑问题 (Over-smoothing)

为什么 GNN 堆不深：每层都是一次邻域平均 初始（节点特征各不相同） A● B◐ C○ D◑ E◍ ● ◐ ○ ◑ ◍ 代表不同的表示 1 层后（各自和直接邻居平均一次） A◐ B◐ C◑ D◑ E◑ 差异还在，感受野 = 1 跳 3 层后（感受野 3 跳，多数节点的邻域已经重叠） A◑ B◑ C◑ D◑ E◑ 差异开始塌缩 8 层后（感受野覆盖全图，收敛到图的平稳分布） A◑ B◑ C◑ D◑ E◑ 全都一样 → 节点不可区分 → 分类失效 数学上：重复乘归一化邻接矩阵 ⇒ 收敛到主特征向量方向 所以主流 GNN 只有 2~3 层。要加深必须额外手段： 残差 / 初始残差（GCNII） · JKNet 把各层输出拼起来 PairNorm 显式拉开节点距离 · DropEdge 随机删边打断平均

GCN 层数增加时，所有节点表示趋于相同（收敛到图的平稳分布）：

  • 原因：每层扩展 1-hop 感受野，K 层后所有节点感受野覆盖全图
  • 表现：节点表示趋于不可区分，分类性能下降
  • 解决方案：
    • 残差连接 (Residual Connection)
    • JKNet：跳跃连接聚合各层输出
    • DropEdge：随机删边减缓信息过度混合
    • PairNorm / NodeNorm：节点表示归一化
    • 深层 GNN 架构：GCNII（初始残差 + 恒等映射）
  • GCN 本质是一阶谱图滤波的空间域实现：每个节点聚合一阶邻居的加权平均
  • "为什么加自环？"→ 确保节点自身特征参与聚合，否则更新后丢失自身信息
  • "为什么不能堆很多层？"→ 过平滑。实验表明 2-3 层 GCN 效果最好
  • GCN 的权重 W 是所有节点共享的 → 参数效率高 + 可泛化到不同大小的图

五、GAT (Graph Attention Network)

GAT 把 GCN 里"由节点度算出来的固定权重"换成"学出来的注意力权重"。收益不只是更准：它算注意力只用到中心节点和邻居的特征，不需要全图的度矩阵，因此纯局部、天然支持新节点。

5.1 注意力系数计算

GAT 注意力：权重来自特征，而不是来自节点度 h_v ──►[W]──► Wh_v ─┐ ├─► concat ──►[a^T]──► LeakyReLU ──► e_vu h_u ──►[W]──► Wh_u ─┘ │ ▼ α_vu = softmax_u(e_vu) = exp(e_vu) / Σ_{k∈N(v)} exp(e_vk) │ h_v⁽ˡ⁺¹⁾ = σ( Σ_{u∈N(v)} α_vu · Wh_u ) 对比 GCN：α_vu = 1 / √(d_v · d_u) ← 只看度，与特征无关，训练前就定了 GAT：α_vu 由 h_v、h_u 学出来 ← 同一个邻居在不同任务下权重可以不同 多头（K=8）：K 组独立的 W 和 a 各算一遍 中间层 h⁽ˡ⁺¹⁾ = concat_{k=1..K}( σ(Σ α^k Wᵏh) ) 维度 ×K 输出层 h⁽ᴸ⁾ = σ( (1/K) Σ_k Σ α^k Wᵏh ) 取平均，维度不变
e_ij = LeakyReLU(aᵀ [Wh_i ∥ Wh_j])

α_ij = softmax_j(e_ij) = exp(e_ij) / Σ_{k∈N(i)} exp(e_ik)

h_i' = σ(Σ_{j∈N(i)} α_ij · Wh_j)

其中：

  • W ∈ ℝ^(d'×d)：共享线性变换矩阵
  • a ∈ ℝ^(2d')：注意力向量（可学习）
  • ∥：拼接操作
  • softmax 在邻居集合上归一化

5.2 多头注意力

h_i' = ∥_{k=1}^{K} σ(Σ_{j∈N(i)} α_ij^k · W^k h_j) （中间层拼接）

h_i' = σ(1/K Σ_{k=1}^{K} Σ_{j∈N(i)} α_ij^k · W^k h_j) （最后一层平均）

5.3 GAT vs GCN

特性GCNGAT
邻居权重固定（基于度的归一化）可学习（注意力机制）
表达能力所有邻居同等对待自适应不同邻居的重要性
计算复杂度O(E·d)O(E·d + E·d')（稍高）
可解释性低高（可视化注意力权重）
是否需要全图是（谱方法依赖拉普拉斯）否（纯局部计算）
  • GAT 的注意力是隐式的：不需要预定义边权重，通过节点特征动态计算
  • 注意力系数 α_ij 仅取决于节点 i 和 j 的特征，不取决于图的全局结构
  • 多头注意力类似 Transformer：稳定训练 + 捕捉不同子空间的信息
  • "GAT 比 GCN 好在哪？"→ 能学习邻居的不同重要性，特别是邻居质量差异大时更有优势

六、GraphSAGE

GraphSAGE 学的不是"每个节点的向量"，而是"一个聚合函数"。函数学到手之后，新来的节点只要有邻居就能算出表示，不必重训整张图——这正是归纳学习与直推学习的分水岭。

6.1 采样 + 聚合策略

GraphSAGE (SAmple and aggreGatE) 的核心创新：

h_{N(v)}^(l) = AGGREGATE_l({h_u^(l-1) : u ∈ S(N(v))})

h_v^(l) = σ(W^(l) · [h_v^(l-1) ∥ h_{N(v)}^(l)])

关键步骤：

  1. 采样：对每个节点均匀采样固定数量的邻居（如 K₁=25, K₂=10）
  2. 聚合：使用聚合器（Mean/LSTM/Pool）汇总邻居信息
  3. 拼接：将自身表示与聚合结果拼接后线性变换
  4. 归一化：对输出做 L2 归一化 h_v ← h_v / ‖h_v‖₂

6.2 归纳学习 vs 直推学习

特性直推学习 (Transductive)归纳学习 (Inductive)
代表模型GCN、DeepWalkGraphSAGE、GAT
训练需求需要全图（含测试节点）仅需训练子图
泛化能力无法处理新节点可泛化到未见过的节点/图
适用场景固定图结构动态增长的图（社交网络）
核心区别学习节点 embedding（查表）学习聚合函数（泛化）

6.3 Mini-batch 训练大图

邻居采样：把"全图前向"变成"每个 batch 一棵小计算图" 不采样（全图 GCN，2 层，平均度 d=100） 目标节点 1 个 → 2 跳邻域 ≈ 100² = 10,000 个节点参与计算 batch 里放 1,024 个目标节点 → 邻域并集接近全图 → 显存直接爆 邻居采样（GraphSAGE，每层采样上限 S₁=25、S₂=10） 目标节点 v │ ┌────────┬───────┼───────┬────────┐ 第 1 跳：从 N(v) 里随机采 25 个 u₁ u₂ u₃ … u₂₅ │ │ ┌───┼───┐ ┌──┼──┐ 第 2 跳：每个 u 再采 10 个 w₁ … w₁₀ w₁₁… w₂₀ 每个目标节点的计算图规模固定为 25 × 10 = 250，与图的实际大小无关 前向：从最外层往里聚合（w → u → v） 反向：只在这棵采样树上回传 ⇒ 显存 O(batch × ∏Sₗ)，可预估、可控；代价是梯度带采样噪声

GraphSAGE 通过邻居采样实现 mini-batch 训练：

  • 计算图构建：从目标节点出发，逐层采样邻居形成计算子图
  • 邻居爆炸问题：2 层每层采样 25 和 10 个邻居 → 每个节点计算涉及 250 个节点
  • 改进方案：Cluster-GCN（子图采样）、GraphSAINT（随机游走采样）、VR-GCN（方差缩减）
  • GraphSAGE 的最大贡献：归纳学习 — 学习的是聚合函数而非固定 embedding
  • "如何处理十亿节点的图？"→ 邻居采样 + mini-batch + 分布式训练
  • 拼接 [h_v ∥ h_N(v)] 保证了节点自身信息不被邻居淹没
  • LSTM 聚合器虽然效果好但不满足排列不变性（需要随机排列输入）

七、GNN 变体

这些变体各补一块短板：GIN 用 sum 聚合加 MLP 把表达力顶到 1-WL 上界，EdgeConv 把边上的差值特征也用起来，异构图 GNN 则给每种关系配一套独立参数——因为"用户-点击-商品"和"用户-关注-用户"本来就不该共享权重。

7.1 GIN (Graph Isomorphism Network)

GIN 从理论上分析了 GNN 的表达能力上界：

h_v^(k) = MLP^(k)((1 + ε^(k)) · h_v^(k-1) + Σ_{u∈N(v)} h_u^(k-1))
  • 证明了 sum 聚合 + 单射更新函数 = 最强表达力（等价于 WL test）
  • ε 可学习或固定为 0，用于区分"自身"与"邻居"
  • MLP（多层感知机）作为更新函数保证单射性

7.2 EdgeConv (DGCNN)

用于点云处理，在特征空间动态构建 k-NN 图：

h_i' = max_{j∈N(i)} MLP(h_i ∥ (h_j - h_i))
  • 边特征 = 邻居与自身的差异（捕捉局部几何）
  • 每层重新构建 k-NN 图（动态图）

7.3 异构图神经网络 (Heterogeneous GNN)

真实世界图通常包含多种类型的节点和边：

  • R-GCN (Relational GCN)：每种关系类型有独立的权重矩阵 W_r
  • HAN (Heterogeneous Attention Network)：基于元路径的层次注意力
  • HGT (Heterogeneous Graph Transformer)：类型相关的注意力头
R-GCN: h_i^(l+1) = σ(Σ_{r∈R} Σ_{j∈N_r(i)} (1/|N_r(i)|) W_r^(l) h_j^(l) + W_0^(l) h_i^(l))
模型核心思想适用场景
GIN最大化表达能力（WL test 等价）图分类/图同构判断
EdgeConv动态图 + 边特征点云分类/分割
R-GCN关系特定权重知识图谱、异构图
HAN元路径 + 层次注意力学术网络、推荐系统
  • GIN 的理论贡献：证明 GNN 表达能力上界是 1-WL test，sum 聚合可达此上界
  • 异构图的关键挑战：不同类型节点/边需要不同的变换，参数量随关系类型线性增长
  • R-GCN 用基分解(basis decomposition)或块对角分解减少参数：W_r = Σ a_ri B_i

八、知识图谱嵌入

知识图谱嵌入做的是把三元组 (h, r, t) 变成向量空间里的一个几何约束：TransE 要求 h + r ≈ t（平移），RotatE 要求 t ≈ h ∘ r（旋转）。选哪种打分函数，本质上是在选你要支持哪几类关系模式。

8.1 知识图谱基础

知识图谱由三元组 (h, r, t) 组成：头实体 h、关系 r、尾实体 t。

核心任务：链接预测 — 给定 (h, r, ?) 或 (?, r, t)，预测缺失实体。

8.2 经典嵌入方法

模型评分函数 f(h,r,t)核心思想局限性
TransE-‖h + r - t‖关系 = 平移向量无法建模 1-N/N-N 关系
TransR-‖M_r h + r - M_r t‖关系特定投影空间参数量大
DistMult⟨h, r, t⟩ = Σ h_i·r_i·t_i双线性对角模型只能建模对称关系
ComplExRe(⟨h, r, t̄⟩)复数空间嵌入可建模非对称关系
RotatE-‖h ∘ r - t‖关系 = 复数旋转可建模多种关系模式

8.3 训练与评估

  • 负采样：替换头或尾实体生成负例
  • 损失函数：Margin-based ranking loss 或 Binary cross-entropy
  • 评估指标：MRR (Mean Reciprocal Rank)、Hit@K、MR (Mean Rank)
  • 过滤设置 (Filtered)：排除训练集中已有的正确三元组
  • TransE 直觉："巴黎" + "首都" ≈ "法国"，关系作为向量空间中的平移
  • "TransE 为何不能处理一对多关系？"→ 若 (h,r,t₁) 和 (h,r,t₂) 同时成立，则 t₁≈t₂，矛盾
  • ComplEx 通过复数的非对称性（共轭）自然建模非对称关系
  • GNN-based 方法（如 R-GCN、CompGCN）可同时利用图结构和实体特征

9.3 GNN 在推荐系统中的应用

示例场景：一个中等规模电商的"猜你喜欢"，用户 400 万、商品 80 万、月交互 1.2 亿条。线上原来是矩阵分解加人工特征，Recall@20 为 0.081。冷启动商品（上架 7 天内）的问题最突出：这类商品交互稀疏，MF 学到的向量几乎是随机初始化的噪声。改造成把用户-商品交互当二部图跑 LightGCN（3 层传播、embedding 64 维），让商品能从"买过它的用户又买过什么"这条二跳路径上借到信号。工程上必须配邻居采样（每层上限 20），否则 2 跳邻域就把 32 GB 显存吃满。上线结果：整体 Recall@20 从 0.081 到 0.104，冷启动商品的曝光点击率相对提升 34%，代价是离线训练时长从 40 分钟涨到 3.1 小时，需要每天而不是每小时重训。

  • LightGCN：去掉非线性变换和特征变换，仅保留邻域聚合
  • NGCF：在协同过滤中引入高阶连接信息
  • 关键思想：用户和物品的表示通过图上的信息传播自然融合协同信号
  • "GNN 在推荐系统中的优势？"→ 自然建模高阶协同信号（user-item-user 路径）
  • 分子属性预测是 GNN 最成功的应用之一：原子=节点、化学键=边，天然图结构
  • 欺诈检测中 GNN 能捕捉"团伙模式"：欺诈者在网络中形成异常子图

十、GNN 的挑战

10.1 过平滑 (Over-smoothing)

  • 层数增加 → 节点表示趋于一致 → 性能下降
  • 理论分析：GCN 的传播矩阵反复乘积收敛到图的平稳分布
  • 限制了 GNN 的深度（通常 2-4 层）

10.2 可扩展性 (Scalability)

示例场景：支付风控里识别欺诈团伙，节点 2.3 亿（账户 + 设备 + 收款码）、边 41 亿。第一版照着论文写全图 GCN，加载邻接矩阵就 OOM——41 亿条边即使用 CSR 存也要上百 GB，根本放不进单机显存。方案换成三层：用 Cluster-GCN 先把图按 METIS 划成 15,000 个子图，每个 batch 取 32 个子图拼起来训练；节点特征放共享内存、边索引放 CPU，采样在 CPU 做、聚合在 GPU 做；层数压到 2 层，靠 JKNet 拼接各层输出而不是靠加深。效果：单机 4×A100 上一个 epoch 从"跑不起来"变成 47 分钟，团伙识别的 AUC 从规则引擎的 0.79 提到 0.88，人工复核量下降约四成。踩过的坑是子图划分把跨社区的边切掉了不少，后来给每个 batch 额外补 5% 的随机跨簇边才把 AUC 从 0.85 拉到 0.88。

  • 全图训练：邻接矩阵乘法需要全图，内存 O(N·d)
  • 邻居爆炸：L 层 GNN 的计算图呈指数增长
  • 解决方案：采样（GraphSAGE）、子图（Cluster-GCN）、简化模型（SGC）

10.3 表达能力上界

  • WL (Weisfeiler-Leman) test：1-WL 是消息传递 GNN 表达力上界
  • 存在 1-WL 无法区分的非同构图（如正则图）
  • 突破方向：高阶 WL (k-WL)、随机特征、子图 GNN、等变 GNN

10.4 动态图

  • 真实图随时间演化（新节点、新边、删除）
  • 方法：TGAT（时间编码注意力）、TGN（时间图网络）、EvolveGCN
  • 需要同时捕捉结构演化和时间依赖

10.5 其他挑战

挑战描述代表工作
过压缩 (Over-squashing)远距离信息通过瓶颈边传播时被压缩图重连 (Graph Rewiring)
异配图 (Heterophily)相连节点标签不同时 GNN 效果差H2GCN, GPR-GNN
公平性图结构可能编码社会偏见FairGNN, NIFTY
鲁棒性图结构容易被对抗攻击GNNGuard, ProGNN
  • "GNN 最多几层？为什么？"→ 通常 2-4 层。过深导致过平滑 + 过压缩
  • "如何突破 WL test 上界？"→ 高阶 GNN、加位置编码、子图方法、随机特征增强
  • 过平滑 vs 过压缩：前者是信息太相似，后者是信息在传播中丢失
  • 工业场景最关心的是可扩展性：十亿级节点图如何高效训练
  • 层数从 2 层起步。GNN 的层数等于感受野跳数，2~3 跳在多数任务上已经够，再加就会过平滑。
  • 大图训练一律配邻居采样或子图采样，把每个 batch 的计算图规模变成可预估的常数。
  • 新节点会持续进来的场景（推荐、风控）选 GraphSAGE / GAT 这类归纳式方法，别选依赖全图拉普拉斯的原始 GCN。
  • 要区分图结构（分子、图同构类任务）时用 sum 聚合，mean 和 max 会丢掉邻居数量信息。
  • 异构图给每种边类型配独立的变换矩阵，共享权重会把语义完全不同的关系混在一起。
  • 不要用加深层数来提精度，先试 JKNet 拼接、初始残差或 DropEdge，这些比加层有效得多。
  • 不要在训练集上做直推式学习后直接给新节点打分，原始 GCN 的嵌入对没见过的节点没有定义。
  • 不要忘记加自环。不加自环时节点表示完全由邻居决定，自身上一层的信息被整个丢掉。
  • 不要指望消息传递 GNN 区分所有非同构图，它的表达力上界就是 1-WL 测试，某些正则图它天然分不开。
  • 不要把过平滑和过压缩混为一谈：前者是信息太相似，后者是远处信息被挤过瓶颈边时丢失，解法不同。

Q&A

Q1: GCN 的核心公式是什么？如何直觉理解？
A: H^(l+1) = σ(D̃^(-1/2)ÃD̃^(-1/2)H^(l)W^(l))。直觉：每个节点将自己和邻居的特征做加权平均（权重由双方度决定），然后通过线性变换和非线性激活。添加自环(Ã=A+I)确保聚合包含自身信息；对称归一化(D̃^(-1/2)...D̃^(-1/2))避免高度节点主导。本质是一阶近似的谱图滤波器在空间域的实现。
Q2: 什么是过平滑？如何缓解？
A: 过平滑是指随着 GNN 层数增加，所有节点的表示趋于相同，导致不可区分。原因：每层扩展感受野 1-hop，多层后每个节点的感受野覆盖全图，表示收敛到图的平稳分布。缓解方法：(1) 残差连接；(2) JKNet 跳跃连接融合各层输出；(3) DropEdge 随机删边；(4) GCNII（初始残差+恒等映射）；(5) 控制层数在 2-4 层。
Q3: GAT 与 GCN 的核心区别？GAT 的优势是什么？
A: GCN 使用基于度的固定权重聚合邻居（所有邻居同等对待），GAT 通过注意力机制为每个邻居学习自适应权重。优势：(1) 能区分邻居的不同重要性；(2) 不依赖全图结构，纯局部计算，支持归纳学习；(3) 注意力权重提供可解释性。代价是额外的注意力参数和计算。
Q4: GraphSAGE 如何实现归纳学习？为什么 GCN 不行？
A: GraphSAGE 学习的是聚合函数（采样邻居 → 聚合 → 拼接更新），新节点只需有邻居即可计算表示。而原始 GCN 本质是对固定图的拉普拉斯做谱分解，依赖完整邻接矩阵，新增节点需要重新训练。GraphSAGE 还通过固定数量邻居采样实现了 mini-batch 训练，可处理工业级大图。
Q5: 消息传递 GNN 的表达能力上界是什么？如何突破？
A: 上界是 1-WL (Weisfeiler-Leman) 图同构测试。GIN 证明了 sum 聚合 + MLP 更新可达此上界。存在 1-WL 无法区分的非同构图（如某些正则图）。突破方向：(1) 高阶 k-WL GNN（计算复杂度高）；(2) 加入随机特征/位置编码打破对称性；(3) 子图 GNN（提取子图增加表达力）；(4) 等变 GNN（利用几何对称性）。
Q6: TransE 的原理是什么？有什么局限？
A: TransE 将关系建模为向量空间中的平移：h + r ≈ t。训练目标是使正三元组的 ‖h+r-t‖ 小，负三元组的距离大。局限：无法处理一对多/多对多关系——若 (h,r,t₁) 和 (h,r,t₂) 都成立，则 t₁≈t₂，造成不同实体坍缩。改进：TransR（关系特定投影空间）、RotatE（旋转建模）、ComplEx（复数空间）。
Q7: 如何训练十亿节点规模的 GNN？
A: 关键技术：(1) 邻居采样（GraphSAGE）：每层固定采样 K 个邻居，构建 mini-batch 计算图；(2) 子图采样（Cluster-GCN）：将图预划分为簇，每次在簇子图上训练；(3) 历史嵌入（GAS）：缓存历史节点表示减少重复计算；(4) 分布式训练：图分区+通信优化；(5) 模型简化（SGC）：去掉非线性变为线性模型，预计算传播矩阵。
Q8: GNN 在推荐系统中相比传统协同过滤的优势？
A: (1) 高阶协同信号：通过多层消息传递捕获 user→item→user→item 的高阶连接路径；(2) 特征融合：自然融合结构信息与节点属性（用户画像、物品描述）；(3) 冷启动缓解：新用户/物品可通过邻居特征推断表示。代表工作：LightGCN（简化非线性变换，仅保留邻域聚合），PinSage（工业级随机游走+采样）。
Q9: GCN 中为什么要加自环？不加会怎样？
A: 加自环 (Ã=A+I) 的目的是让节点在聚合邻居信息时也保留自身信息。不加自环时，更新公式 h_v = σ(Σ_{u∈N(v)} w_{vu} h_u W) 完全由邻居决定，节点自身上一层的信息被丢弃。这会导致：(1) 孤立节点表示为零向量；(2) 节点身份信息在传播中快速丢失；(3) 加速过平滑。实验证实加自环能稳定提升性能。
Q10: 过平滑和过压缩有什么区别？
A: 过平滑 (Over-smoothing)：多层聚合后节点表示趋于相同，是信息"太相似"的问题，源于重复的邻域平均操作。过压缩 (Over-squashing)：远距离节点间的信息需要经过图中的瓶颈边传播，被压缩为固定维度向量导致信息丢失，类似 RNN 的长程依赖问题。过平滑影响浅层也影响深层，过压缩主要影响需要远程信息的任务。解决过压缩：图重连 (Graph Rewiring)、加虚拟节点、Transformer-style 全局注意力。
