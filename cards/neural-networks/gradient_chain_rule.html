一、梯度的数学定义

梯度不是斜率的简单推广，它是一个向量：每个分量回答"只动这一个参数、损失会怎么变"，整体方向则是损失上升最快的方向。优化沿着负梯度走，只是因为那是下降最快的方向——而且这个结论只在无穷小步长下严格成立。

1.1 标量对标量求导

最基础的导数定义：给定函数 f: ℝ → ℝ，导数为

f'(x) = limh→0 [f(x+h) − f(x)] / h

导数衡量函数在某一点处的瞬时变化率。若 f'(x) > 0，函数在 x 处递增；若 f'(x) < 0，函数递减。

1.2 偏导数 (Partial Derivative)

当函数有多个输入变量 f(x₁, x₂, …, xₙ) 时，偏导数只对其中一个变量求导，其余变量视为常数：

∂f/∂xᵢ = limh→0 [f(x₁,…,xᵢ+h,…,xₙ) − f(x₁,…,xᵢ,…,xₙ)] / h

1.3 梯度向量 (Gradient)

对于标量函数 f: ℝⁿ → ℝ，梯度是所有偏导数组成的向量：

∇f(x) = (∂f/∂x₁, ∂f/∂x₂, …, ∂f/∂xₙ)ᵀ

几何意义

  • 方向：梯度指向函数值增长最快的方向
  • 大小：‖∇f‖ 表示该方向上的最大变化率
  • 等值线：梯度向量垂直于函数的等值面 (level set)

1.4 方向导数 (Directional Derivative)

函数沿任意单位方向 u（‖u‖=1）的变化率：

Duf = ∇f · u = ‖∇f‖ cos θ

当 u 与梯度方向一致（θ=0）时，方向导数取最大值 ‖∇f‖；当 u 与梯度方向相反（θ=π）时取最小值 −‖∇f‖。这正是梯度下降的理论基础。

1.5 向量/矩阵求导

情形输入 → 输出导数形状名称
标量对向量ℝⁿ → ℝn 维向量梯度 ∇f
向量对向量ℝⁿ → ℝᵐm×n 矩阵Jacobian 矩阵 J
标量对矩阵ℝᵐˣⁿ → ℝm×n 矩阵梯度矩阵
💡 知识要点
  • 梯度方向 = 函数增长最快方向 → 负梯度 = 下降最快方向
  • Jacobian 矩阵的第 i 行是第 i 个输出分量关于所有输入的梯度
  • 深度学习中 Loss 是标量，参数是高维向量 → 需要的是"标量对向量的梯度"

二、链式法则 (Chain Rule)

链式法则真正说的是"局部导数可以相乘"。有了这一条，深度网络才可拆：每个算子只需要知道自己的局部导数，整条路径的导数就是沿路相乘、遇到分支相加。反向传播不过是把这个规则在计算图上跑一遍。

2.1 单变量链式法则

若 y = f(g(x))，则：

dy/dx = (dy/du) · (du/dx)，其中 u = g(x)

直觉：把复合函数的导数分解为"外层导数 × 内层导数"的乘积。

2.2 多变量链式法则

若 z = f(u, v)，u = g(x, y)，v = h(x, y)，则：

∂z/∂x = (∂z/∂u)(∂u/∂x) + (∂z/∂v)(∂v/∂x)
∂z/∂y = (∂z/∂u)(∂u/∂y) + (∂z/∂v)(∂v/∂y)

关键规则：对所有中间路径求和。

2.3 Jacobian 矩阵与链式法则

向量值函数的链式法则可写成 Jacobian 矩阵的乘法形式。设 y = f(u)，u = g(x)：

Jy/x = Jy/u · Ju/x

这意味着反向传播本质上是Jacobian 矩阵连乘。

2.4 计算图 (Computational Graph) 视角

链式法则在计算图上：沿路径相乘，遇分支相加 前向（实线，从左到右） w ─────┐ ├─► u = w·x ──┐ x ─────┘ ├─► z = u + b ──► a = σ(z) ──► L = ½(a−y)² b ───────────────────┘ 反向（虚线，从右到左，每个节点只关心自己的局部导数） L : ∂L/∂a = a − y σ : ∂a/∂z = σ(z)(1−σ(z)) → ∂L/∂z = (a−y)·σ'(z) + : ∂z/∂u = 1 , ∂z/∂b = 1 → ∂L/∂b = ∂L/∂z × : ∂u/∂w = x , ∂u/∂x = w → ∂L/∂w = ∂L/∂z · x 分支的情形：若 x 同时喂给两条下游路径 p₁、p₂ ∂L/∂x = ∂L/∂x|_{p₁} + ∂L/∂x|_{p₂} ← 多路径贡献相加，不是相乘 这就是为什么共享权重（CNN 的卷积核、RNN 的 W_hh）的梯度是"所有使用处求和"

深度学习框架将复杂表达式表示为有向无环图 (DAG)：

  • 节点：变量或运算
  • 边：数据流向
  • 前向传播 (Forward Pass)：从输入到输出依次计算每个节点的值
  • 反向传播 (Backward Pass)：从输出到输入依次计算每个节点的梯度

反向传播的核心公式

对于中间节点 u，它的梯度等于所有下游路径梯度之和：

∂L/∂u = Σⱼ (∂L/∂vⱼ) · (∂vⱼ/∂u)

其中 vⱼ 是 u 的所有直接后继节点。

前向模式 vs 反向模式自动微分

特性前向模式 (Forward AD)反向模式 (Reverse AD / Backprop)
计算方向输入 → 输出输出 → 输入
一次 pass 获得一个输入对所有输出的导数所有输入对一个输出的导数
适用场景输入少、输出多输入多、输出少（深度学习）
额外内存低高（需存储中间值）
💡 知识要点
  • 深度学习使用反向模式 AD，因为参数（输入）数量远大于 Loss（输出=1 个标量）
  • 反向传播 = 链式法则 + 计算图上的动态规划（避免重复计算）
  • 梯度累积：一个节点被多个后继使用时，梯度要求和而非覆盖

三、梯度下降法

梯度下降只有三个动作：算梯度、乘学习率、减掉。全批量、随机、小批量的差别仅在"用多少样本来估这个梯度"——样本越少估计噪声越大，而这个噪声本身还带来了跳出尖锐极小值的副作用。

3.1 基本更新规则

θ ← θ − α · ∇θL(θ)

其中 α 是学习率 (learning rate)，L(θ) 是损失函数。

3.2 三种变体对比

示例场景：ResNet-50 在 ImageNet 上从零训练，团队里两个人各训一版。A 同学沿用 NLP 项目的习惯用 AdamW（lr 1e-3、wd 0.01），B 同学按 CV 惯例用 SGD + Momentum（lr 0.1、momentum 0.9、wd 1e-4、90 epoch step decay）。前 10 个 epoch AdamW 明显更快，train loss 领先约 0.25；但训到收尾时 AdamW 的 Top-1 停在 74.8%，SGD 版本是 76.3%，而两者的 train loss 差不到 0.02——差距全在泛化上。原因是自适应学习率给每个参数不同的有效步长，更容易停在尖锐极小值。后续统一成 CV 用 SGD+Momentum、NLP 和大模型用 AdamW，并把这条写进模板配置。注意结论不能反过来套：同一个团队在 BERT 微调上把 AdamW 换成 SGD，试了 6 组学习率都没追上 AdamW 的基线。

方法每步使用数据优点缺点
Batch GD 全部训练集 梯度估计精确、收敛稳定 计算开销大、无法在线学习、容易卡在鞍点
SGD 单个样本 更新频繁、有随机噪声可跳出局部最优 方差大、收敛震荡
Mini-batch GD 小批量 (B 个样本) 兼顾效率与稳定性、可利用 GPU 并行 需调 batch size

3.3 收敛性分析

  • 凸函数：以适当学习率，GD 可收敛到全局最优；收敛速率 O(1/T)
  • 强凸函数：线性收敛速率 O(ρᵀ)，0 < ρ < 1
  • 非凸函数（深度学习）：只能保证收敛到驻点 (stationary point)，即 ‖∇L‖ → 0

3.4 学习率的影响

同一个碗形损失面，四种学习率的轨迹 lr 太小 (1e-5) lr 合适 (1e-3) ╲ ╲ ╲ · · · · ╲ ╲· · · · ← 一步挪一点 ╲ · ╲_______ 几万步不到底 ╲___·___·__ 几百步到底 lr 偏大 (1e-1) lr 太大 (1) ╲ · · ╲ · ╲ · · · · ╲ · · ╲__·___·___·__ ╲__·____________·____► loss → NaN 在谷底两侧来回弹 每步都跨过谷底且越跨越远，发散 判断方法：先跑几百步看 loss 曲线 一路平缓不降 → 偏小 剧烈锯齿但整体在降 → 偏大，可用但该降 前几步就冲高 / NaN → 太大 平滑单调下降后趋平 → 合适

📌 关键概念：Batch Size 与泛化

研究发现大 batch 训练容易收敛到尖锐极小值 (sharp minima)，泛化差；小 batch 引入的噪声有正则化效果，倾向收敛到平坦极小值 (flat minima)，泛化更好。

💡 知识要点
  • 实践中几乎不用纯 Batch GD 或纯 SGD，而是 Mini-batch SGD
  • 常见 batch size: 32, 64, 128, 256（视 GPU 显存而定）
  • 学习率是最重要的超参数之一
  • SGD 的噪声是特性而非缺陷——有助于逃离鞍点和尖锐极小值

四、动量法 (Momentum)

动量把参数更新变成一个有惯性的球：一直朝同一方向的分量被反复累加放大，来回震荡的分量则互相抵消。它省下来的正是"在狭长山谷里横向来回弹"那部分步数，而不是让每一步走得更准。

4.1 基本原理

标准 SGD 在高曲率方向上震荡、低曲率方向上移动缓慢（损失面呈椭圆等高线时尤为明显）。动量法引入速度变量，利用历史梯度的指数加权移动平均来平滑更新方向：

vt = β · vt-1 + (1 − β) · ∇L(θt) （或 vt = β · vt-1 + ∇L(θt)）
θt+1 = θt − α · vt

典型取 β = 0.9。

4.2 指数加权移动平均 (EWMA)

展开递推式可知 vt 是过去梯度的加权和，权重指数衰减：

vt ≈ (1−β) Σᵢ βⁱ · gt−i

有效窗口长度约为 1/(1−β)。当 β=0.9 时，约回顾最近 10 步梯度。

物理类比

可以想象一个小球在损失曲面上滚动：

  • 梯度 = 重力加速度
  • 速度 v 会积累（下坡加速）
  • β 相当于"摩擦系数的补数"——β 越大，惯性越强

4.3 Nesterov Accelerated Gradient (NAG)

NAG 的核心改进：先用当前速度做一次"前瞻" (lookahead)，然后在前瞻位置计算梯度：

vt = β · vt-1 + α · ∇L(θt − β · vt-1)
θt+1 = θt − vt

优势：当速度方向错误（即将越过最优点）时，前瞻梯度提供更早的"刹车"信号，减少过冲 (overshoot)。

💡 知识要点
  • Momentum 加速了沿一致方向的梯度，抑制了震荡方向 → 更快收敛
  • NAG 比标准 Momentum 在凸优化上有更好的理论收敛率
  • PyTorch 中 torch.optim.SGD(momentum=0.9, nesterov=True)

五、AdaGrad / RMSProp

自适应学习率的想法是给每个参数配一把自己的尺子：历史梯度一直很大的参数把步子调小，长期没被更新的稀疏参数把步子调大。AdaGrad 用的是累加所以分母只增不减、越走越慢，RMSProp 换成指数移动平均才把它救回来。

5.1 自适应学习率的核心思想

不同参数可能需要不同的学习率：稀疏特征对应参数更新频率低，需要较大学习率；频繁更新的参数需要较小学习率。自适应方法让每个参数有自己的有效学习率。

5.2 AdaGrad (Adaptive Gradient)

Gt = Gt-1 + gt ⊙ gt （累积历史梯度平方和）
θt+1 = θt − α / (√Gt + ε) ⊙ gt

其中 ⊙ 表示逐元素乘法，ε ≈ 10⁻⁸ 防止除零。

优点缺点
自动调节每个参数学习率Gt 单调递增 → 学习率持续衰减 → 训练后期"学死"
对稀疏数据/特征友好不适合深度网络的长时间训练
无需手动调学习率衰减对初始学习率 α 仍然敏感

5.3 RMSProp (Root Mean Square Propagation)

Hinton 在 Coursera 课程中提出（未正式发表论文），通过指数移动平均替代累加解决 AdaGrad 学习率过快衰减的问题：

E[g²]t = γ · E[g²]t-1 + (1 − γ) · gt²
θt+1 = θt − α / (√E[g²]t + ε) ⊙ gt

典型 γ = 0.9, α = 0.001。

对比AdaGradRMSProp
梯度平方累积全历史求和（单调增）指数移动平均（有遗忘）
学习率变化只会越来越小可升可降，自适应当前梯度尺度
长时间训练可能过早停止学习表现稳定
常用场景NLP 稀疏嵌入RNN/通用深度网络
💡 知识要点
  • AdaGrad 适合稀疏场景（如 NLP 词嵌入训练），但不适合深度网络
  • RMSProp = AdaGrad + 指数衰减 → 解决学习率单调衰减问题
  • 两者都是 per-parameter 自适应学习率的先驱，为 Adam 铺路

六、Adam / AdamW

Adam 就是三件东西拼起来：动量（一阶矩 m）、自适应学习率（二阶矩 v）、偏差修正。AdamW 只改了一处——把权重衰减从梯度里拿出来，直接施加在参数更新之后，于是正则强度不会再被自适应系数扭曲。

6.1 Adam (Adaptive Moment Estimation)

Adam 一步更新里的两条并行通路 g_t = ∇L(θ_t) │ ┌───────────┴───────────┐ ▼ ▼ 一阶矩（方向） 二阶矩（步长） m_t = β₁m_{t-1} v_t = β₂v_{t-1} + (1−β₁)g_t + (1−β₂)g_t² β₁=0.9 ≈ 近 10 步平均 β₂=0.999 ≈ 近 1000 步平均 │ │ ▼ ▼ m̂_t = m_t/(1−β₁ᵗ) v̂_t = v_t/(1−β₂ᵗ) ← 偏差修正 │ │ （m₀=v₀=0 导致前期偏小） └───────────┬───────────┘ ▼ θ_{t+1} = θ_t − α · m̂_t / (√v̂_t + ε) └──────┬──────┘ 方向来自 m̂，步长被 √v̂ 归一化 ⇒ 每个参数的有效学习率各不相同 AdamW 在这之后再单独加一刀：θ ← θ − α·λ·θ（不经过 √v̂ 缩放）

Adam 结合了 Momentum（一阶矩估计）和 RMSProp（二阶矩估计）：

mt = β₁ · mt-1 + (1 − β₁) · gt （一阶矩估计：梯度均值）
vt = β₂ · vt-1 + (1 − β₂) · gt² （二阶矩估计：梯度方差）

偏差修正 (Bias Correction)：
m̂t = mt / (1 − β₁ᵗ)
v̂t = vt / (1 − β₂ᵗ)

θt+1 = θt − α · m̂t / (√v̂t + ε)

默认超参：β₁=0.9, β₂=0.999, ε=10⁻⁸, α=0.001

为什么需要偏差修正？

m₀ = v₀ = 0 初始化，训练初期 mt 和 vt 都偏向零。偏差修正项 1/(1−βᵗ) 在初期较大，随着 t 增大趋近于 1，逐步消除初始化偏差。

6.2 Adam 的问题

  • 泛化差：相比 SGD+Momentum，Adam 在某些任务上泛化性能更差（尤其 CV 任务）
  • 自适应学习率不收敛：Reddi et al. (2018) 证明 Adam 在某些凸问题上不收敛 → 提出 AMSGrad
  • L2 正则化失效：Adam 中 L2 weight decay 与自适应学习率交互后效果失真

6.3 AdamW — 解耦权重衰减

Loshchilov & Hutter (2019) 发现问题根源：在 Adam 中直接加 L2 正则项（∇L + λθ），λθ 也会被自适应学习率缩放，导致不同参数的正则化强度不一致。

L2 正则化 vs 解耦权重衰减

方式Adam + L2AdamW (解耦)
梯度修改gt = ∇L + λθgt = ∇L（不修改梯度）
参数更新θ ← θ − α·m̂/(√v̂+ε)θ ← θ − α·m̂/(√v̂+ε) − α·λ·θ
正则效果被自适应系数缩放，不同参数正则强度不同对所有参数施加均匀的权重衰减
对 SGDL2 与 WD 数学等价L2 与 WD 数学等价

为什么 AdamW 是 LLM 训练标配？

  1. 自适应学习率：处理 Transformer 中不同层/参数的梯度尺度差异
  2. 正确的正则化：解耦 weight decay 对所有参数一视同仁
  3. 训练稳定性：一阶矩+二阶矩估计 → 更平滑的更新
  4. 超参鲁棒：默认超参在大多数任务上表现良好
  5. 配合 LR Schedule：与 Cosine Annealing + Warmup 配合效果极佳
💡 知识要点
  • Adam = Momentum + RMSProp + 偏差修正
  • 对于 SGD，L2 与 weight decay 等价；但对于 Adam，二者不等价
  • AdamW 解耦的关键：weight decay 不经过 m̂/(√v̂+ε) 的缩放
  • LLM 标准配置：AdamW + Cosine LR + Linear Warmup
  • torch.optim.AdamW(params, lr=1e-4, weight_decay=0.01)

七、学习率调度 (LR Schedule)

学习率调度的形状几乎都是先升后降：升（Warmup）是给 Adam 的二阶矩攒够统计量，避免开局几步有效学习率异常大；降是让后期在极小值附近细调，而不是一直大步跨过去。

7.1 为什么需要调度？

固定学习率的问题：训练初期需要较大学习率快速接近最优区域；训练后期需要较小学习率精细调整。学习率调度让模型在训练不同阶段使用不同学习率。

7.2 常见调度策略

7.3 Warmup 的原理

训练初期 Adam 的二阶矩 vt 估计不准（样本太少），导致更新步长可能异常大。Warmup 让学习率从小到大缓慢增长，给优化器时间积累可靠的统计量。

αt = αmax · t / Twarmup，当 t ≤ Twarmup

  • Warmup 缓解了 Adam 初期矩估计不稳定的问题

  • OneCycleLR 可实现"超级收敛"，用更少 epoch 达到更好效果

八、梯度问题

梯度消失和梯度爆炸是矩阵连乘的两个极端，不是两种独立的病。梯度裁剪只能治爆炸，而且只治症状不治病因；消失必须靠结构改动（残差连接、LSTM 的门控）或换激活函数来解决。

8.1 梯度消失 (Vanishing Gradient)

反向传播中梯度逐层相乘，当每层梯度 < 1 时，深层网络的梯度呈指数衰减趋近于零。

原因

  • Sigmoid / Tanh 激活：饱和区导数接近 0 → 梯度极小
  • 网络太深：多层小梯度连乘
  • 权重初始化不当：初始权重过小

解决方案

  • 使用 ReLU 系列激活（非饱和激活函数）
  • 残差连接 (Residual Connection)：H(x) = F(x) + x，梯度至少为 1
  • Batch Normalization：保持每层输入分布稳定
  • 适当的权重初始化：Xavier / He initialization
  • LSTM / GRU：门控机制维持梯度流

8.2 梯度爆炸 (Exploding Gradient)

当每层梯度 > 1 时，深层梯度呈指数增长，导致权重更新量极大、参数溢出 NaN。

常见场景

  • RNN / LSTM 中的长序列
  • 深层网络权重初始化过大
  • 学习率过大

8.3 梯度裁剪 (Gradient Clipping)

示例场景：13B 模型继续预训练，bf16、AdamW、全局 batch 512。没有配 warmup（沿用了一个小模型的配置），结果前 60 步 loss 从 2.9 直接冲到 11.4，之后再也没降回去。打日志看到第 3 步的梯度范数是 480，而稳定期只有 0.4——开局 v_t 几乎为 0，即使有偏差修正，√v̂ 做分母仍然让有效学习率放大了两个数量级，前几步就把权重推离了初始化的合理区域。修正是三条一起上：warmup 设为总步数的 2%（约 2,400 步）、clip_grad_norm_(1.0)、峰值 lr 从 3e-4 降到 1.5e-4。重训后梯度范数全程在 1.0 以内，同样的 token 预算下最终 eval loss 从 2.71 降到 2.38，中途没有再出现 loss spike。

防止梯度爆炸的主要手段：

Clip by Norm（按范数裁剪）

如果 ‖g‖ > threshold：g ← threshold · g / ‖g‖

保持梯度方向不变，只缩放大小。最常用。

torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

Clip by Value（按值裁剪）

g ← clamp(g, −threshold, +threshold)

逐元素裁剪，可能改变梯度方向。

torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)
对比Clip by NormClip by Value
操作整体缩放（保持方向）逐元素截断（可能改变方向）
优点方向保持，更稳定实现简单
实践偏好更常用（LLM 训练标配）较少使用
典型阈值1.00.5 ~ 1.0
💡 知识要点
  • 梯度消失 → 深层参数几乎不更新 → 模型无法学习 → 用 ReLU/ResNet/BN 解决
  • 梯度爆炸 → 参数变 NaN → 用 Gradient Clipping 解决
  • Transformer 训练标配：clip_grad_norm_(max_norm=1.0)
  • 残差连接是解决梯度消失的最优雅方案：∂L/∂x = ∂L/∂H · (∂F/∂x + 1)，"+1"保证梯度至少为 1

九、二阶优化

二阶方法不是效果不好，是算不起：n 个参数的 Hessian 有 n² 个元素、求逆 O(n³)，175B 参数意味着 10²² 量级的矩阵。Adam 之所以能流行，正是因为它用一个对角线近似换来了几乎为零的额外开销。

9.1 Newton 法

利用二阶导数（Hessian 矩阵 H）获得更精确的下降方向：

θt+1 = θt − H⁻¹ · ∇L(θt)

直觉：二阶泰勒展开 → 直接跳到二次近似的极小点。对于完美二次函数，一步即可到达最优解。

Hessian 矩阵

n 个参数 → H 是 n×n 的对称矩阵：

Hij = ∂²L / (∂θᵢ ∂θⱼ)
  • H 正定 → 当前点是局部最小值
  • H 负定 → 局部最大值
  • H 不定 → 鞍点

9.2 L-BFGS

BFGS 使用一阶梯度信息近似 Hessian 逆矩阵；L-BFGS 是其有限内存版本，只存储最近 m 步的梯度差信息：

  • 内存复杂度：O(mn) 而非 O(n²)
  • 适合中等规模凸优化问题
  • 常用于传统 ML（如 Logistic 回归、CRF）

9.3 为什么深度学习很少用二阶方法？

原因说明
计算量 Hessian 矩阵大小 O(n²)，对 GPT-3 (175B 参数) 根本不可能存储
非凸性 深度网络的 Loss 面高度非凸，鞍点众多，Newton 法可能往鞍点或极大值方向走
随机梯度 Mini-batch 带来噪声，精确二阶信息意义不大
实践效果 Adam/AdamW + 适当调参 在大规模问题上表现足够好
并行效率 一阶方法更易分布式并行，二阶方法通信开销大
📌 前沿方向

尽管完整二阶方法不实用，但有一些近似二阶方法在特定场景中有价值：

  • K-FAC：用 Kronecker 因子近似 Fisher 信息矩阵
  • Shampoo：Google 提出的矩阵预条件优化器
  • Sophia：LLM 训练的轻量级二阶优化器，用对角 Hessian 近似
💡 知识要点
  • Newton 法收敛快（二次收敛），但计算 H⁻¹ 代价太高 → O(n³) + O(n²) 空间
  • 深度学习参数量级：百万~千亿，Hessian 完全不可行
  • Adam 可看作一种"对角 Hessian 近似"：v̂t ≈ diag(H) 的近似
  • L-BFGS 在 PyTorch 中有实现 torch.optim.LBFGS，但几乎只用于小模型微调
  • 没有特殊理由时，NLP 和大模型直接用 AdamW（β₁=0.9、β₂=0.95~0.999、wd 0.1），CV 从零训用 SGD+Momentum。
  • Transformer 和大 batch 训练一律配 warmup，占总步数 1~5%；这是最便宜的稳定性保险。
  • 调参先调学习率，它的影响远大于优化器种类和 β 的取值。
  • 用 clip_grad_norm_(max_norm=1.0) 而不是按值裁剪，前者保持梯度方向不变。
  • 把梯度范数打进训练日志，它是判断"要不要裁剪、warmup 够不够"最直接的信号。
  • 不要在 Adam 上用 weight_decay 参数当 L2 正则理解，Adam 里两者并不等价，要 AdamW。
  • 不要给 LayerNorm 的 γ/β 和所有 bias 加权重衰减，实践中这几类参数应该从 decay 组里排除。
  • 不要把学习率一路 cosine 降到 0，末端留 5~10% 峰值，否则最后几千步几乎不学东西。
  • 不要靠加大 batch size 来提精度而不同步调学习率，batch 翻倍时至少要考虑线性缩放规则。
  • 不要在深度学习里上 Newton 或完整 L-BFGS，参数上万之后 Hessian 的存储和求逆都不成立。

十、Q&A

Q1: 梯度下降法中，为什么要沿负梯度方向更新参数？

梯度 ∇f(x) 指向函数值增长最快的方向（由方向导数 Duf = ∇f·u 可知，当 u 与 ∇f 同方向时取最大值）。因此，沿负梯度方向移动，函数值下降最快。这就是"最速下降法"的理论基础。需要注意，最速下降只在无穷小步长下成立；步长有限时，实际效果取决于损失曲面的局部曲率。

Q2: SGD 与 Adam 各自适合什么场景？为什么有些 CV 任务仍用 SGD？

Adam 适合：NLP、LLM 训练、训练初期快速收敛的场景、超参不敏感的项目。
SGD+Momentum 适合：CV 任务（如 ImageNet 训练）、追求最佳泛化性能的场景。

原因：Adam 的自适应学习率会为不同参数分配不同有效步长，这在某些情况下使模型收敛到尖锐极小值，泛化性能不如 SGD。经验上，精心调参的 SGD 在 CV benchmark 上的 test accuracy 常优于 Adam。但在 NLP/LLM 领域，Adam/AdamW 几乎是唯一的选择。

Q3: 解释 Adam 中偏差修正的作用。如果去掉偏差修正会怎样？

m₀=0, v₀=0 初始化后，前几步 mt 和 vt 严重偏向零（特别是 vt，因 β₂=0.999 衰减极慢）。若不做偏差修正：

  • v̂t 偏小 → 分母过小 → 有效学习率过大 → 训练初期参数更新剧烈
  • m̂t 偏小 → 影响较轻（因 β₁=0.9 收敛较快）

修正公式 m̂=m/(1−β₁ᵗ) 使得期望 E[m̂t] = E[gt]，即无偏估计。

Q4: AdamW 和 Adam+L2 有什么区别？为什么 LLM 用 AdamW？

在 SGD 中，L2 正则化（将 λθ 加入梯度）和 weight decay（直接从参数中减去 λθ）在数学上等价。但在 Adam 中不等价：

  • Adam+L2：λθ 被加入梯度 gt，然后经过 m̂/(√v̂+ε) 缩放 → 不同参数的正则强度被自适应系数扭曲
  • AdamW：weight decay 直接在参数更新后施加 θ←θ−αλθ，不经过自适应缩放 → 正则化效果均匀

LLM 选择 AdamW 的原因：正确的正则化 + 自适应学习率 + 训练稳定 + 与 LR schedule 配合好。

Q5: 解释梯度消失和梯度爆炸的原因及解决方案。

梯度消失：反向传播时各层梯度连乘，若每层梯度 <1（如 Sigmoid 饱和区导数最大仅 0.25），深层梯度趋近于 0。
→ 解决：ReLU 激活、残差连接、Batch Norm、合适的初始化 (Xavier/He)

梯度爆炸：各层梯度 >1 时连乘导致指数增长，权重变 NaN。
→ 解决：Gradient Clipping (clip_grad_norm_)、合适的初始化、学习率调低

本质：深度网络 = 矩阵连乘，矩阵谱半径 <1 → 消失，>1 → 爆炸。

Q6: Warmup 的原理是什么？什么时候需要 Warmup？

训练初期，Adam 的二阶矩 vt（梯度方差估计）几乎为 0（因初始化为 0 且 β₂=0.999 移动极慢），即使有偏差修正，估计仍不可靠 → 有效学习率可能异常大 → 参数剧烈变化。

Warmup 让学习率从接近 0 缓慢增长到目标值，给优化器足够时间积累可靠的梯度统计信息。

需要 Warmup 的场景：大模型训练（尤其 Transformer/LLM）、大 batch 训练、使用 Adam/AdamW 时。典型 Warmup 步数 = 总步数的 1~5%。

Q7: 比较 Clip by Norm 和 Clip by Value 两种梯度裁剪方式。

Clip by Norm：计算全局梯度范数 ‖g‖，若超过阈值则按比例缩放所有梯度。保持梯度方向不变，只限制大小。实践中更常用。

Clip by Value：逐元素裁剪 g=clamp(g, -c, c)。简单但会改变梯度方向，可能引入不一致的更新。

LLM 训练几乎都用 Clip by Norm (max_norm=1.0)。

Q8: 为什么深度学习不使用 Newton 法等二阶优化方法？
  1. 空间不可行：n 个参数 → Hessian 大小 n²。GPT-3 有 175B 参数 → Hessian 需 ~10²² 个元素，远超任何硬件
  2. 计算不可行：求逆 O(n³)，即使近似也极昂贵
  3. 非凸：Newton 法在非凸函数上可能走向鞍点或极大值
  4. 噪声：Mini-batch 梯度本身有噪声，精确二阶信息意义有限

现代替代：Adam 可视为对角 Hessian 近似；K-FAC/Shampoo/Sophia 是实际可用的近似二阶方法。

Q9: 链式法则在反向传播中是如何工作的？前向模式和反向模式自动微分有何不同？

反向传播就是链式法则在计算图上的系统化应用。设 Loss L 经过 n 层计算，每层输出 zₖ = fₖ(zₖ₋₁)：

∂L/∂z₁ = (∂L/∂zₙ)·(∂zₙ/∂zₙ₋₁)·…·(∂z₂/∂z₁)

反向模式（Backprop）：从 ∂L/∂zₙ 开始，从右向左逐步乘 Jacobian → 一次 pass 得到所有参数的梯度（因为输出是 1 个标量 L）。

前向模式：从 ∂z₁/∂x 开始，从左向右逐步乘 Jacobian → 一次 pass 只得到一个输入变量的导数。

深度学习参数多（输入维度高）、输出是标量 → 反向模式高效：一次 backward 获得全部梯度。
