N08 · 归一化与正则化

Normalization & Regularization — 稳定训练、防止过拟合的核心手段

一、 归一化 vs 正则化 — 概念区分

归一化动的是"数据和激活值的分布"，目的是让训练稳、收得快；正则化动的是"模型的自由度"，目的是别过拟合。BN 顺带有一点正则效果，但那是 mini-batch 统计噪声的副作用，不是它的设计目的。

归一化 (Normalization) 和 正则化 (Regularization) 在中文翻译中极易混淆，但它们的作用对象和目标完全不同：

维度归一化 Normalization正则化 Regularization
作用对象数据 / 中间特征（激活值）模型参数（权重）
核心目标使分布稳定、加速收敛约束模型复杂度、防止过拟合
典型方法BatchNorm / LayerNorm / RMSNorm / GroupNormDropout / Weight Decay / Label Smoothing / Data Aug
何时生效前向传播中，对激活值做变换损失函数或训练过程中施加约束
数学本质对数据做标准化 / 缩放对损失函数添加惩罚项 / 引入噪声
  • 一句话区分：Normalization 管数据分布，Regularization 管模型复杂度
  • BatchNorm 同时具有轻微正则化效果（因 mini-batch 引入噪声），但本质是归一化
  • 英文不会混淆，中文交流时务必开头点明两者区别

二、 Batch Normalization

Batch Normalization 做的事是把每一层的输入分布拉回一个稳定的尺度，让后面的层不必一直追着前面的漂移跑。代价是它依赖 batch 内的统计量——所以训练和推理的行为天生不一致，batch 一小就直接失效。

算法流程（4 步）

对一个 mini-batch B = {x₁, x₂, …, xₘ} 中的每个特征通道：

Step 1 · 计算均值: μ_B = (1/m) Σᵢ xᵢ Step 2 · 计算方差: σ²_B = (1/m) Σᵢ (xᵢ - μ_B)² Step 3 · 归一化: x̂ᵢ = (xᵢ - μ_B) / √(σ²_B + ε) Step 4 · 缩放平移: yᵢ = γ · x̂ᵢ + β ← γ, β 为可学习参数

其中 ε 是防除零的小常数（通常 1e-5），γ 和 β 让网络恢复表达能力——如果最优分布恰好不是标准正态，网络可以学回来。

训练 vs 推理的区别

BN 的两条路径：训练用当前 batch，推理用累积的 running 统计量 训练（model.train()） x [B, C, H, W] │ ① 在 (B, H, W) 上按通道求 μ_B、σ²_B ← 依赖当前这一批样本 ▼ x̂ = (x − μ_B) / √(σ²_B + ε) │ ② y = γ·x̂ + β γ、β 可学习 ▼ 输出 同时顺手更新（不参与反向）： running_mean = (1−m)·running_mean + m·μ_B running_var = (1−m)·running_var + m·σ²_B m = momentum，PyTorch 默认 0.1 推理（model.eval()） x │ 用 running_mean / running_var，不看当前 batch ▼ x̂ = (x − running_mean) / √(running_var + ε) │ y = γ·x̂ + β ⇒ 整个 BN 退化成一次固定的线性变换， ▼ 推理时可以和前面的 Conv 融合掉（BN folding） 输出 两个高频事故： 验证时忘了 model.eval() → 用验证 batch 的统计量，指标偏低且每次都不一样 batch size < 8 → μ_B、σ²_B 噪声过大，训练统计量和 running 值对不上

训练当前 mini-batch 统计量每步实时计算 μ_B 和 σ²_B
推理全局 running mean / running var训练时用指数移动平均(EMA)累积

为什么 BN 有效？

Internal Covariate Shift (ICS) 假说

原论文（Ioffe & Szegedy, 2015）认为：每层输入分布在训练中不断变化（协变量偏移），BN 将每层输入归一化到固定分布，从而加速收敛。

ICS 假说的争议

Santurkar et al. (2018) 的实验表明，BN 的真正作用在于平滑损失曲面（loss landscape），使梯度更稳定、优化更容易。即使人为注入噪声破坏 ICS 修正，BN 仍然有效。

BN 的问题

示例场景：把一个 ImageNet 预训练的检测 backbone 迁到 1333×800 的道路场景检测。单卡显存只放得下 batch size 2，训出来的 mAP 是 0.281，而同一份配置在 batch 16 的机器上能到 0.352，差了 7 个点。定位到 BN：batch=2 时每个通道的均值方差只由 2 张图统计，噪声极大，训练时用的统计量和最终 running 值差异明显，推理阶段等于换了一套归一化参数。试了三条路——冻结 BN（只用预训练的 running 统计量）mAP 到 0.331；换 Group Normalization（32 组）到 0.347 且对 batch 完全不敏感；上跨卡同步 BN 需要 8 卡才有意义，这台机器上不适用。最后选了 GroupNorm，代价是单 epoch 训练时间涨了约 12%（GN 没有 BN 那样成熟的融合优化），换来配置在 1 卡到 8 卡上表现一致。

  • 依赖 batch size：batch 太小（<16）统计量不准，性能下降严重
  • 序列模型不适用：不同序列长度不同，在 batch 维度归一化无意义
  • 分布式训练复杂：需要跨 GPU 同步统计量（SyncBN）
  • 训练/推理不一致：running mean/var 可能引入误差
  • BN 在 CNN + 大 batch 场景效果最好，是 CV 的标配
  • BN 在 NLP/序列模型中基本不用，被 LayerNorm 取代
  • 高频考点："为什么 Transformer 不用 BN？" — 答：序列长度可变、batch 维度统计不稳定、推理时需保存 running stats

三、 Layer Normalization

LN 和 BN 的区别只有一句话：BN 沿 batch 维度统计（横着切），Layer Normalization 沿特征维度统计（竖着切）。竖着切就不依赖 batch，单条样本也算得出来，这正是 Transformer 选它的根本原因。

与 BN 的核心区别

输入张量: [B, C, H, W] （以 CNN 为例） Batch Norm → 沿 B 维度归一化，每个通道独立统计 → 归一化维度: (B, H, W) Layer Norm → 沿 C 维度归一化，每个样本独立统计 → 归一化维度: (C, H, W) ──────────────────────────────────────────── 对于 Transformer 输入: [B, L, D] Batch Norm → 沿 B 维度对每个特征归一化 → 依赖 batch，序列长度可变时不稳定 Layer Norm → 沿 D 维度对每个 token 独立归一化 → 不依赖 batch，推理时与训练一致
Layer Norm 公式: μ = (1/D) Σⱼ xⱼ （沿最后一个维度 D 求均值） σ² = (1/D) Σⱼ (xⱼ - μ)² x̂ⱼ = (xⱼ - μ) / √(σ² + ε) yⱼ = γⱼ · x̂ⱼ + βⱼ （γ, β 为每个特征维度的可学习参数）

为什么 Transformer 用 LN 而不是 BN？

  1. 不依赖 batch：单样本推理也能正常工作
  2. 序列长度可变：LN 对每个 token 独立操作，无需跨样本统计
  3. 训练推理一致：无需维护 running mean/var
  4. 并行友好：无需跨 GPU 同步统计量

Pre-LN vs Post-LN

同一个残差块，LN 放在加法前后，梯度通路完全不同 Post-LN（原始 Transformer 2017） x ───────────────┐ │ │ [SubLayer] │ 残差 │ │ ⊕ ◄──────────────┘ │ [LN] ← LN 挡在残差通路上 │ ▼ y = LN( x + SubLayer(x) ) 反向时梯度必须穿过每一层的 LN，深层堆叠后需要靠 warmup 才训得动 Pre-LN（GPT-2 之后的主流） x ───────────────┐ │ │ [LN] │ 残差：这条线上什么都没有 │ │ [SubLayer] │ │ │ ⊕ ◄──────────────┘ │ ▼ y = x + SubLayer( LN(x) ) 从输出到输入存在一条"什么算子都不经过"的通路 ⇒ 梯度可无衰减回流 代价：最后一层输出需要额外补一个 final LN，否则量纲会随层数累积 现代 LLM（GPT、LLaMA、DeepSeek）几乎全是 Pre-LN， Post-LN 理论表达力略强，但深层训练不稳，工程上不划算
结构位置特点
Post-LN（原始 Transformer）x + LN(SubLayer(x))表达能力略强，但训练不稳定，需 warmup
Pre-LN（GPT-2+, 主流 LLM）x + SubLayer(LN(x))训练更稳定，梯度流更好，可用更大 lr
Post-LN（原始）: Input → Attention → Add → LN → FFN → Add → LN → Output Pre-LN（主流）: Input → LN → Attention → Add → LN → FFN → Add → Output Pre-LN 让残差连接直通主干，梯度可以无衰减地回流
  • Pre-LN 是当前 LLM（GPT、LLaMA、DeepSeek）的主流选择
  • Pre-LN 训练稳定但最终性能可能略低；Post-LN 需要精细的 warmup 和 lr 调度
  • 部分工作（如 DeepNorm）通过调整残差缩放来兼顾 Post-LN 的表达力和训练稳定性

四、 RMSNorm

RMSNorm 把 LN 的两件事砍成一件：不减均值、不要偏置 β，只保留按 RMS 缩放。实验表明 LN 的有效性主要来自 re-scaling 而不是 re-centering，而砍掉的正好是一次 reduce 操作——在千亿参数上积少成多。

公式

RMSNorm(x): RMS(x) = √( (1/D) Σⱼ xⱼ² ) x̂ⱼ = xⱼ / RMS(x) yⱼ = γⱼ · x̂ⱼ 对比 Layer Norm: LN = γ · (x - μ) / √(σ² + ε) + β ← 有均值中心化 + 偏置项 RMS = γ · x / √(mean(x²) + ε) ← 去掉均值中心化，去掉 β

与 LN 的差异

特性Layer NormRMSNorm
均值中心化（re-centering）有（减去 μ）无
偏置项 β有无
缩放方式除以标准差 σ除以 RMS
可学习参数数量2D（γ + β）D（仅 γ）
计算量较高（需 2 pass：均值+方差）较低（仅 1 pass：平方均值）

为什么 LLaMA / DeepSeek 选 RMSNorm？

  • 计算效率高：省去均值计算和减法，在大模型中节省 ~5-10% 归一化计算量
  • 实验验证效果相当：Zhang & Sennrich (2019) 论文表明，re-centering 对性能贡献不大，re-scaling 才是关键
  • Kernel 友好：减少一次 reduce 操作，更容易写高效 CUDA kernel
  • 参数更少：去掉 β 减少参数量和内存
  • RMSNorm 是 LLaMA、LLaMA 2/3、DeepSeek、Gemma、Mistral 等主流 LLM 的标配
  • 核心简化："去均值中心化，只保留 re-scaling"
  • 关键词：re-centering invariance（均值平移不变性不重要）

五、 Group Normalization / Instance Normalization

BN、LN、IN、GN 四个只是在同一个 [B, C, H, W] 张量上换了统计范围而已。选哪个取决于你的 batch 靠不靠得住、通道之间该不该共享统计量——GN 就是在这两者之间取的折中。

Group Normalization (GN)

Wu & He (2018) 提出。将通道分成 G 组，在每组内做归一化，不依赖 batch size。

输入: [B, C, H, W] 将 C 通道分为 G 组，每组 C/G 个通道 Batch Norm → 归一化维度: (B, H, W) 对每个通道，跨 batch 归一化 Layer Norm → 归一化维度: (C, H, W) 对每个样本，跨所有通道归一化 Group Norm → 归一化维度: (C/G, H, W) 对每个样本的每个组，组内归一化 Instance Norm → 归一化维度: (H, W) 对每个样本的每个通道，单独归一化（= G=C 的 GN）

Instance Normalization (IN)

Ulyanov et al. (2016) 提出。等价于 G = C 的 Group Norm（每个通道单独归一化）。

  • 核心应用：风格迁移（Style Transfer）
  • 原理：IN 去除了每个通道的均值和方差（即风格信息），只保留内容结构
  • 在 AdaIN（Adaptive Instance Normalization）中，用风格图像的统计量替换内容图像的统计量，实现风格迁移

六、 Dropout

Dropout 的三种解释其实指向同一件事：训练时每一步都在训练一个随机的子网络，推理时相当于把这些子网络平均起来。它的正则强度来自一条约束——网络不能依赖任何单个神经元。

原理

训练时，以概率 p 将神经元的输出随机置零：

训练时: mask ~ Bernoulli(1 - p) y = mask · x / (1 - p) ← Inverted Dropout（PyTorch 默认） 推理时: y = x ← 不做任何操作 另一种等价方式（原始 Dropout，Hinton 2012）: 训练时: y = mask · x 推理时: y = x · (1 - p) ← 推理时手动缩放

Inverted Dropout（训练时除以 1-p）是现代框架的默认实现，优点是推理时零开销。

为什么有正则化效果？

视角 1：集成学习

每次 dropout 相当于训练一个不同的子网络。最终模型可视为指数级子网络的集成（ensemble）。集成模型方差更低，泛化更好。

视角 2：噪声注入

Dropout 向隐层输出注入乘性噪声（0/1 mask），迫使网络学习更鲁棒的特征，不过度依赖某个特定神经元。等价于给训练过程加了正则化惩罚。

视角 3：自适应正则

Wager et al. (2013) 证明 Dropout 近似于自适应 L2 正则，惩罚强度与特征方差相关。

Dropout 率选择

场景推荐 Dropout 率说明
全连接层0.3 ~ 0.5参数密集，容易过拟合
卷积层0 ~ 0.2（或不用）参数共享已有正则效果
Transformer Attention0.1原论文默认值
大模型预训练0（不用）数据量足够大，不需要 Dropout
微调0.05 ~ 0.1防止在小数据上过拟合
  • Dropout 训练和推理行为不同，必知："Dropout 推理时做什么？" — 不做任何操作（Inverted Dropout 版本）
  • 现代 LLM 预训练通常不使用 Dropout（GPT-3、LLaMA 等），因为数据量大到不需要
  • Dropout 本质是一种乘性噪声正则，与 L2 正则互补

七、 DropPath / Stochastic Depth

核心思想

Huang et al. (2016) 提出 Stochastic Depth：训练时随机丢弃整个残差分支（而不是单个神经元），推理时使用全部层。

标准残差连接: y = x + F(x) DropPath: y = x + mask · F(x) mask ~ Bernoulli(1 - p) 其中 mask 是一个标量（对整个分支生效） 等价于: 以概率 p 直接跳过这一层 → y = x

与 Dropout 的区别

Dropout 和 DropPath 的粒度差一个数量级 Dropout：丢单个神经元（向量里的元素） 激活向量 [ 0.8 , 1.2 , 0.3 , 2.1 , 0.5 , 1.7 , 0.9 , 0.4 ] mask [ 1 , 0 , 1 , 0 , 1 , 1 , 0 , 1 ] p=0.5 输出 [ 1.6 , 0 , 0.6 , 0 , 1.0 , 3.4 , 0 , 0.8 ] └─ Inverted Dropout：留下来的除以 (1−p)，推理时什么都不做 DropPath（Stochastic Depth）：整条残差分支被跳过 保留（概率 1−p） 丢弃（概率 p） x ──┬────────────┐ x ──┬────────────┐ │ │ │ │ [SubLayer] │ (整块不计算) │ │ │ │ │ ⊕ ◄──────────┘ ⊕ ◄──────────┘ │ │ y = x + F(x) y = x ← 该层退化成恒等映射 粒度：Dropout 作用在一层内部，DropPath 作用在"要不要这一层" ViT / ConvNeXt 的做法是让 drop rate 随深度线性递增（浅层 0 → 深层 0.1~0.5）， 浅层特征通用不该丢，深层更冗余、更需要正则
特性DropoutDropPath
丢弃粒度单个神经元整个残差分支/层

在 ResNet / Vision Transformer 中的应用

  • ResNet：原始论文中，DropPath 使 1202 层 ResNet 训练成为可能（缩短有效深度）
  • Vision Transformer (ViT/DeiT)：标准正则化手段，通常 drop_path_rate = 0.1 ~ 0.3
  • Swin Transformer：使用线性递增的 DropPath 率（浅层 0，深层最高）
  • 实现：timm 库中的 DropPath 是 ViT 系列标配
线性递增策略（以 L 层为例）: drop_rate(l) = (l / L) × drop_path_rate 第 1 层: 几乎不丢弃 第 L 层: 丢弃率最高
  • DropPath 是 Vision Transformer 中最重要的正则化手段
  • 关键区别：Dropout 丢神经元，DropPath 丢整个层/分支
  • 考点："ViT 用什么正则化？" — DropPath + Weight Decay，通常不用 Dropout

八、 Weight Decay（L2 正则）

Weight Decay 让权重整体往 0 缩，等价于偏好更平滑的函数。它在 SGD 上和 L2 正则完全等价，但在 Adam 上不等价——正则梯度会被自适应系数扭曲，这就是 AdamW 存在的全部理由。

公式

L2 正则化（添加到损失函数）: L_total = L_original + (λ/2) · Σᵢ wᵢ² 对梯度的影响: ∂L_total/∂w = ∂L_original/∂w + λ · w 权重更新（SGD）: w ← w - lr · (∂L/∂w + λ · w) w ← (1 - lr · λ) · w - lr · ∂L/∂w ↑ "权重衰减" ← 每步将权重乘以一个小于 1 的因子

为什么能防过拟合？

  • 限制权重大小：将权重推向 0 附近，模型函数更"平滑"
  • 减少有效参数：小权重 ≈ 不激活，相当于简化模型
  • 贝叶斯视角：L2 正则 = 对权重施加零均值高斯先验 w ~ N(0, 1/λ)
  • 几何视角：限制权重向量的 L2 范数，将解约束在超球面内

Weight Decay vs L2 Loss 的微妙区别（AdamW 解耦）

示例场景：从零训练一个 ViT-Base，AdamW、lr 1e-3、weight_decay 0.05。训到第 40 个 epoch 验证准确率停在 76.8%，同期公开基线是 81% 左右。检查参数分组时发现整个 model.parameters() 被一股脑塞给了优化器，也就是说 LayerNorm 的 γ、β 和所有 bias 也在吃 0.05 的权重衰减。γ 被持续往 0 拉，等于在削弱每一层归一化的缩放能力，深层的有效激活尺度被压下去。改法是标准的两组参数：所有 ndim ≥ 2 的权重（Linear、Conv 的 W）进 decay 组，所有 bias、LN 和 BN 的 γ/β 进 no-decay 组。只改这一处、其余配置不动，重训后验证准确率到 81.3%，训练曲线也不再有中后期趴平的现象。这个坑在 CV 和 NLP 的从零训练里都很常见，微调时因为步数少通常看不出来。

在 SGD 中，L2 正则和 Weight Decay 数学等价。但在 Adam/AdaGrad 等自适应优化器中，两者不等价！
Adam + L2 正则（传统方式，有问题）: g_t = ∇L + λ · w ← L2 梯度 m_t = β₁ · m_{t-1} + (1-β₁) · g_t ← 正则项也被动量平滑了! v_t = β₂ · v_{t-1} + (1-β₂) · g_t² ← 正则项也影响了自适应学习率! w = w - lr · m̂_t / (√v̂_t + ε) 问题: L2 梯度被 Adam 的动量和自适应 lr 修改，衰减效果不一致 AdamW（解耦 Weight Decay，Loshchilov & Hutter 2019）: g_t = ∇L ← 只计算原始梯度 m_t, v_t 只基于原始梯度 w = w - lr · m̂_t / (√v̂_t + ε) - lr · λ · w ← 权重衰减直接作用于 w ↑ 解耦！不经过 Adam 的动量/自适应
方式正则梯度是否被 Adam 修改效果
Adam + L2 Lossλ·w 加入梯度是（被动量和 v_t 缩放）衰减不均匀
AdamWλ·w 直接减否（独立于优化器状态）衰减均匀一致
  • 现代深度学习几乎全用 AdamW，而不是 Adam + L2
  • AdamW 的关键：将 weight decay 从梯度中解耦出来，直接对权重做衰减
  • 典型 weight decay 值：0.01 ~ 0.1（LLM 训练常用 0.1）
  • 注意：BN/LN 的 γ, β 参数和 bias 项通常不做 weight decay

九、 Label Smoothing

Label Smoothing 不让模型追求 100% 的确信：把 one-hot 换成 soft label，logit 就不会被推向 ±∞。副作用是置信度校准变好——模型说"我 90% 确定"时，真的差不多有 90% 是对的。

公式

标准 one-hot 标签: y_hard = [0, 0, 1, 0, ..., 0] ← 目标类为 1，其余为 0 Label Smoothing (Szegedy et al., 2016): y_smooth = (1 - α) · y_hard + α / K 其中 α 为平滑系数（通常 0.1），K 为类别数 例（K=5, α=0.1, 正确类为第 3 类）: y_hard = [0, 0, 1, 0, 0 ] y_smooth = [0.02, 0.02, 0.92, 0.02, 0.02]

为什么有效？

  • 防止过度自信：硬标签驱使 logit 趋向 ±∞（softmax 饱和区），Label Smoothing 让模型输出更"谦虚"
  • 改善泛化：softmax 不再追求极端值，模型学到更好的特征表示
  • 校准输出概率：模型输出概率更接近真实置信度，减少过拟合
  • 隐式正则：等价于对 KL 散度添加了一个均匀分布的惩罚项

应用场景

场景典型 α 值说明
图像分类0.1ResNet / EfficientNet 训练标配
机器翻译0.1原始 Transformer 论文使用
知识蒸馏需谨慎蒸馏依赖 soft label，Label Smoothing 可能冲突
LLM 预训练一般不用语言模型本身就在学分布
Label Smoothing 与知识蒸馏的关系需要注意：蒸馏的 soft target 本身已经包含了类间关系信息。如果对 teacher 的 soft target 再做 Label Smoothing，可能丢失 teacher 提供的暗知识（dark knowledge）。
  • Label Smoothing 本质："不要让模型太确信——给其他类留一点概率"
  • 数学本质：交叉熵损失 + KL(uniform || p_model) 的混合
  • 与 temperature scaling 的区别：Label Smoothing 改标签，Temperature 改 softmax

十、 其他正则化技术

Data Augmentation（数据增强）

通过对训练数据做变换来扩充数据集，隐式正则化。

  • CV 常用：随机裁剪、水平翻转、颜色抖动、RandAugment、AutoAugment
  • NLP 常用：同义词替换、回译（Back Translation）、随机删除/插入
  • 本质：增加训练分布的多样性 → 防止模型记忆训练集

Mixup

Mixup (Zhang et al., 2018): x̃ = λ · xᵢ + (1 - λ) · xⱼ λ ~ Beta(α, α) ỹ = λ · yᵢ + (1 - λ) · yⱼ 将两个样本的输入和标签做线性插值 α 通常取 0.1 ~ 0.4
  • 让模型学习线性行为（样本间的过渡区域），减少过拟合
  • 实际训练中在 mini-batch 内随机配对

CutMix

CutMix (Yun et al., 2019): 从图像 B 中裁剪一个矩形区域，粘贴到图像 A 上 标签按面积比例混合: ỹ = λ · yₐ + (1 - λ) · y_b λ = 1 - (裁剪面积 / 图像面积)
  • 比 Cutout（直接遮挡）更好：被遮挡区域填入有意义的像素，不浪费信息
  • 强迫模型利用局部特征而非全局特征做分类

Early Stopping

  • 监控验证集损失/指标，当连续 N 个 epoch 不改善时停止训练
  • 等价于隐式限制了优化步数 → 限制模型从训练数据中"记忆"的程度
  • 最简单也最有效的正则化方式之一

Gradient Penalty

梯度惩罚（常见于 GAN 训练）: L_GP = λ · E[(‖∇_x̂ D(x̂)‖₂ - 1)²] 其中 x̂ 是真假样本之间的插值点 约束判别器的梯度范数接近 1 → 强制 Lipschitz 连续性
  • WGAN-GP (Gulrajani et al., 2017) 的核心技术
  • Spectral Normalization 是另一种实现 Lipschitz 约束的方法

正则化方法总览

方法类别作用阶段核心思想
Dropout噪声注入训练时随机关闭神经元
DropPath噪声注入训练时随机跳过整层
Weight Decay参数约束优化时惩罚大权重
Label Smoothing标签约束损失函数软化目标分布
Data Augmentation数据增强输入层扩充训练分布

  • 现代大模型训练的正则化组合：Weight Decay + Data Aug（Dropout 和 Label Smoothing 通常不用）
  • CV 模型标配：DropPath + Weight Decay + Mixup/CutMix + RandAugment
  • 应答思路：先分类（噪声 / 约束 / 增强），再具体展开
  • NLP、Transformer、序列任务一律用 LN 或 RMSNorm；batch 靠不住的视觉任务（检测、分割）用 GroupNorm。
  • 把参数分成 decay 和 no-decay 两组：只给 ndim ≥ 2 的权重加 weight decay，bias 和 LN/BN 的 γ/β 不加。
  • 用 AdamW 而不是 Adam 配 weight_decay 参数，二者在自适应优化器上并不等价。
  • 残差网络和 ViT 的首选正则是 DropPath + Weight Decay + Mixup/CutMix，而不是往里塞 Dropout。
  • 推理前记得 model.eval()；部署时可以把 BN 折进前一层卷积，白拿一点延迟收益。
  • batch size 小于 8 时不要用 BN，统计量噪声会让训练和推理行为对不上。
  • 不要在 Transformer 里用 BN：序列长度可变，batch 维度上的统计量根本不稳定。
  • 不要在大模型预训练阶段加 Dropout，万亿 token 的数据多样性本身就是最强的正则，Dropout 只会削减有效容量。
  • 不要把 BN 的正则效果当作可以省掉 weight decay 的理由，那只是统计噪声带来的副作用。
  • 不要在需要精确概率输出的场景（如需要校准的风控打分）无脑加 Label Smoothing，它会系统性压低最大类概率。

FAQ Q&A Q&A

Q1 Normalization 和 Regularization 有什么区别？

Normalization（归一化）作用于数据/特征，目的是稳定分布、加速收敛，代表方法有 BatchNorm、LayerNorm、RMSNorm。Regularization（正则化）作用于模型参数或训练过程，目的是约束模型复杂度、防止过拟合，代表方法有 Dropout、Weight Decay、Label Smoothing。

一个常见误区：BN 因为在 mini-batch 上计算统计量引入了噪声，所以附带轻微正则化效果，但它的本质仍是归一化。

Q2 为什么 Transformer 用 LayerNorm 而不是 BatchNorm？

四个原因：(1) LN 不依赖 batch size，单样本推理也能工作；(2) NLP 序列长度可变，BN 在 batch 维度统计不稳定；(3) LN 训练推理一致，不需要维护 running mean/var；(4) LN 无需跨 GPU 同步统计量，分布式训练更简单。

Q3 RMSNorm 相比 LayerNorm 做了什么简化？为什么 LLaMA 选 RMSNorm？

RMSNorm 去掉了均值中心化（不减均值）和偏置项 β，只保留 re-scaling。Zhang & Sennrich (2019) 的实验表明，LayerNorm 的有效性主要来自 re-scaling 而非 re-centering。

LLaMA 选 RMSNorm 的原因：(1) 计算量更低（少一次 reduce 操作），在超大模型中积少成多；(2) CUDA kernel 更容易优化；(3) 实验性能与 LN 相当甚至更好。

Q4 Pre-LN 和 Post-LN 有什么区别？现代 LLM 用哪个？

Post-LN（原始 Transformer）：x + LN(SubLayer(x))，LN 在残差加法之后。Pre-LN（GPT-2+）：x + SubLayer(LN(x))，LN 在子层之前。

Pre-LN 训练更稳定：残差连接形成一条"高速公路"，梯度可以无衰减地回流。Post-LN 理论上表达能力更强，但需要 learning rate warmup 等技巧。

现代 LLM（GPT、LLaMA、DeepSeek）几乎全用 Pre-LN。

Q5 Dropout 推理时做什么？为什么 LLM 预训练不用 Dropout？

使用 Inverted Dropout（主流实现）时，推理时不做任何操作（直接输出原始值），因为训练时已经用 1/(1-p) 缩放过了。

LLM 预训练不用 Dropout 的原因：(1) 训练数据量极大（万亿 token），数据本身的多样性已经足够防止过拟合；(2) Dropout 降低了有效模型容量，大模型需要最大化容量来学习；(3) Weight Decay 已经提供了足够的正则化。GPT-3、LLaMA、DeepSeek 等都不使用 Dropout。

Q6 AdamW 和 Adam + L2 正则有什么区别？

在 SGD 中两者等价，但在 Adam 中不等价。Adam + L2 会将正则化梯度 λ·w 纳入动量 m 和自适应学习率 v 的计算，导致衰减力度被 Adam 自适应地修改，不同参数的衰减效果不一致。

AdamW 将 weight decay 从梯度计算中解耦出来，直接在权重更新后做 w ← w - lr·λ·w，衰减效果均匀一致。Loshchilov & Hutter (2019) 证明 AdamW 优于 Adam + L2。现代深度学习几乎全用 AdamW。

Q7 BN 的 Batch Size 太小会怎样？有什么替代方案？

Batch size 太小（如 <16）时，BN 计算的均值和方差统计不准确，噪声大，性能严重下降。

替代方案：(1) Group Normalization：分组归一化，不依赖 batch，在目标检测（小 batch）中广泛使用；(2) Layer Normalization：不依赖 batch，适合 NLP；(3) Synchronized BN：跨 GPU 同步统计量，等效增大 batch；(4) Instance Normalization：每个样本每个通道独立，适合风格迁移。

Q8 DropPath 和 Dropout 有什么区别？ViT 用哪些正则化？

Dropout 随机丢弃单个神经元（向量中的元素），DropPath 随机丢弃整个残差分支（整层被跳过，直接走 skip connection）。DropPath 的粒度更粗，更适合残差网络。

ViT 的标准正则化组合：DropPath（线性递增 drop rate）+ Weight Decay + Mixup/CutMix + RandAugment + Label Smoothing。注意 ViT 中通常不用传统 Dropout。

Q9 Label Smoothing 为什么能防止过拟合？它和温度缩放有什么不同？

Label Smoothing 将 one-hot 标签改为 soft label（给非目标类分配少量概率），防止模型 logit 趋向 ±∞。这等价于在交叉熵损失中加入了对均匀分布的 KL 散度惩罚，起到正则化作用。

与 Temperature Scaling 的区别：Label Smoothing 修改的是标签（训练目标），Temperature 修改的是softmax 输出（模型预测）。Label Smoothing 在训练时生效，Temperature Scaling 通常在推理/蒸馏时使用。

Q10 各种归一化方法（BN/LN/GN/IN/RMSNorm）的统计维度分别是什么？

以 CNN 输入 [B, C, H, W] 为例：

  • Batch Norm：沿 (B, H, W) 归一化 → 每个通道一套 μ, σ² → 依赖 batch
  • Layer Norm：沿 (C, H, W) 归一化 → 每个样本一套 μ, σ² → 不依赖 batch
  • Instance Norm：沿 (H, W) 归一化 → 每个样本每个通道一套 → 不依赖 batch
  • Group Norm：将 C 分成 G 组，沿 (C/G, H, W) 归一化 → 不依赖 batch
  • RMSNorm：与 LN 类似但去掉均值中心化，仅对最后一个维度做 RMS 归一化

记忆技巧：BN 跨 batch（横切），LN 跨 feature（纵切），GN 在中间（部分纵切），IN 是最细粒度的纵切。
