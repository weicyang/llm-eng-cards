L16 · Kimi K3 核心技术

MuonClip 优化器 / QK-Clip 稳定性 / MoE 架构 / 训练工程

Kimi K3 的故事不是"把模型堆到 2.8 万亿参数"，而是三件解耦的事：用 Muon 系二阶优化把"算力"与"学到的智能"解耦（约 2 倍 token 效率），用 QK-Clip 把"激进更新"与"训练崩溃"解耦（15.5T token 零 loss spike），用稀疏 MoE 把"知识容量"与"单 token 计算量"解耦（896 个专家只激活 16 个）。三层解耦叠加，才有第一个 3 万亿级的开放权重旗舰。

一、Kimi K3 定位与演进

2026 年 7 月 16 日，月之暗面（Moonshot AI）发布旗舰模型 Kimi K3：总参数约 2.8 万亿（2.8T），是全世界第一个进入"3 万亿参数级"的开放权重模型，支持 1,048,576（1M）token 上下文，原生处理文本、图像、视频与音频，并以"始终开启"的深度思考模式运行。它在 Kimi 应用、Kimi Code、Kimi Work 与 API（模型 ID kimi-k3）同步上线，完整权重于 2026 年 7 月 27 日前后开放下载，延续了 Kimi 系列的开源路线。

理解 K3 必须放在 Kimi 系列的演进线上看。2025 年 7 月的 Kimi K2 用"1T 总参数 / 32B 激活 / 384 专家选 8"的激进稀疏 MoE 奠定了开放权重阵营的性价比标杆；此后一年，K2.5 补上原生多模态与 256K 上下文并引入 Agent Swarm，K2.6 把并行子智能体扩到 300 路，K2.7 Code 专攻软件工程；K3 则是这条线上第一次"架构换代"：注意力换成 Kimi Delta Attention（KDA）混合堆叠 + AttnRes 注意力残差，FFN 换成 Stable LatentMoE（896 个细粒度微专家、每 token 激活 16 个），优化器沿用 Muon 家族并为注意力投影引入 Per-Head 变体。

规格跃迁可以直接量化：总参数从 1T 涨到 2.8T（约 2.8 倍），专家数从 384 翻到 896、每 token 激活数从 8 翻到 16，上下文从 128K 拉满到 1M（8 倍），模态从纯文本扩展到音视觉全覆盖。但 Moonshot 官方强调的核心指标不是"更大"，而是扩展效率（scaling efficiency）：第三方对 K3 架构的分析显示，Stable LatentMoE 的极端稀疏化使整体扩展效率达到 K2 架构的约 2.5 倍——达到同等损失水平所需的计算量约为 K2 的 40%。这是架构（KDA + Stable LatentMoE + AttnRes）与优化器（Muon 家族）联合改善 scaling 曲线的结果，而不是单纯堆卡。

生态定位上，K3 站在开源与闭源的交界地带：官方口径中它在多项编程与 agent 评测上逼近前沿闭源旗舰，个别长程任务实现反超，同时完整权重开放下载——这使它既是研究对象（首个可完整剖析的 3T 级样本），也是工程上可自建的生产模型。K2 时代的 Modified MIT 类许可为社区自建打下了基础，K3 把这条路线推到了前所未有的规模。

看 Kimi 的演进不要只盯参数量：K2 证明"稀疏 MoE 能便宜地跑"，K2.5/K2.6 补多模态和 agent，K2.7 磨垂直场景，K3 才轮到架构本身换代——注意力、FFN、优化器三处同时动刀。

二、MuonClip 优化器

Kimi 团队在 GTC 2026 的演讲里给过一个判断：用了 11 年以上的 Adam/AdamW 在万亿参数时代已经力不从心。问题不在 Adam 不收敛，而在它的逐坐标缩放只归一化梯度的"平均幅度"，对梯度矩阵内部的条件数（奇异值分布的失衡程度）毫无办法——一个权重矩阵的梯度如果只有几个巨大奇异值、其余方向都很小，Adam 的更新仍然主要沿主导方向走，损失曲面上的窄谷还是窄谷，平坦方向上的进展依旧缓慢。数据是有限的高品质"化石燃料"，谁的 token 利用效率高，谁就能从同样多的数据里萃取出更多智能——这就是 Kimi 转向二阶优化器的动机。

Muon：动量 + Newton-Schulz 正交化

Muon（Momentum + Orthogonalization）由 Keller Jordan 等人于 2024 年提出，核心只有三步：先对梯度做重球动量平滑得到 M_t，再对 M_t 做正交化，最后按参数形状缩放后更新权重。正交化的目标是动量矩阵 SVD 分解 M = UΣVᵀ 中的 U·Vᵀ——相当于把奇异值谱"拍平"成单位矩阵，让梯度指出的每一个方向都获得单位幅度的推进。真实 SVD 每步都算不起，Muon 用五次 Newton-Schulz 迭代近似：这是一个只含矩阵乘法的多项式递推，约 5 轮迭代即可收敛，全程跑在 tensor core 上，bf16 下数值稳定。

X₀ = M_t/‖M_t‖_F，　X_k = a·X_{k−1} + b·(X_{k−1}X_{k−1}ᵀ)X_{k−1} + c·(X_{k−1}X_{k−1}ᵀ)²X_{k−1}　（5 轮 ≈ U·Vᵀ）

Moonshot 在《Muon is Scalable for LLM Training》（arXiv 2502.16982）中补上了 Muon 规模化的两块关键拼图：其一是加入权重衰减（weight decay），其二是按每个参数的形状精细调整更新幅度（RMS-to-RMS 缩放）。这两招让 Muon 无需逐规模调参就能直接上大规模训练，并且学习率可以从小模型直接迁移到大模型——对超参搜索成本占总算力大头的团队来说，这项可迁移性与原始加速同样值钱。注意 Muon 只适用于二维权重矩阵；Embedding 和输出头这类"行对应词表、梯度极稀疏"的参数仍然交给 AdamW，混合使用才是完整方案。

效率数据：Moonshot 的 scaling law 实验显示，在 compute-optimal 训练设定下，Muon 达到同等损失所需计算量约为 AdamW 的一半，即 约 2 倍的 token 学习效率（FLOPs/Token 口径）。基于此训练的 Moonlight（3B/16B MoE，5.7T token）推进了"性能 vs 训练 FLOPs"的帕累托前沿。K3 世代官方口径将这一优势概括为"2 倍算力转化为实打实的认知能力"。

从 Muon 到 MuonClip：给激进更新装上安全网

Muon 的更新比 AdamW 激进得多——正交化后的更新方向谱范数受控、步幅一致，收敛更快，但也更容易触碰大规模训练的数值雷区。把 Muon 扩到千卡集群时，Kimi 团队撞上了致命问题：注意力 logit 爆炸（attention logits explosion），QK 点积从正常的 10~20 瞬间飙到 1000 以上，梯度发散、出现 NaN，耗资数百万美元的训练任务崩溃重启。解法就是 MuonClip：保留 Muon 的全部效率优势，集成权重衰减与一致性 RMS 匹配，并在每次更新之后追加一道 QK-Clip 安全网（机制细节见下一节）。K3 进一步为注意力投影引入 Per-Head Muon：不再对整个 Q/K/V 投影矩阵做全矩阵正交化，而是沿注意力头维度把动量矩阵切块、对每个头的块分别正交化——全矩阵正交化把所有头当成一个整体处理，逐头正交化让每个头保有独立的更新几何。

Adam 是"每个方向按各自的坡度调脚步"，Muon 是"把所有方向的坡度统一成同一档再齐步走"——谱被拍平之后，窄谷不再卡住训练；MuonClip 则是给这支走得更快更齐的队伍配了一个随时盯着注意力温度计的安全员。

三、QK-Clip 与训练稳定性

问题：logit 爆炸为什么是万亿级训练的生死线

注意力分数（QK 点积除以 √d）是 softmax 的输入，直接决定注意力分布。训练规模上去之后，这个量会变得极不安分：在 K2 世代 15.5T token 级别的预训练中，Moonshot 观测到某些注意力头的 logit 会从正常的 10~20 毫无征兆地冲到 1000 以上。logit 一旦爆炸，softmax 输出趋向 one-hot，梯度要么消失要么发散，紧接着就是 NaN——一次价值数百万美元的长跑训练直接崩溃重启。更麻烦的是，K2/K3 采用 MLA（多头潜在注意力）这类压缩 KV 的架构，Key 在推理时并不完全实体化，业界常用的 QK-Norm 等对显式 Q/K 张量做归一化的手段在这里没有着力点，传统防线直接失效。

两类直觉性的补救方案都被验证不行：其一是 logit soft-capping（对注意力分数做软截断），它会人为扭曲注意力分布，让模型学到不自然的聚焦模式；其二是 Query-Key 归一化，只约束了张量范数，没有触及权重本身持续膨胀的根因。MuonClip 的 QK-Clip 选择了第三条路——在权重源头做最小侵入的负反馈控制。

机制：每步一次的比例回缩

QK-Clip 的逻辑极其简洁：每次 Muon 更新之后，检查当前注意力 logit 的最大值 m；若 m 超过预设阈值 τ，就计算超出比例 η′ = τ/m（η′ < 1），然后按比例反向缩小 Q 和 K 的投影权重——W_q 乘 η′ 的 α 次方，W_k 乘 η′ 的 1−α 次方，α 通常取 0.5 左右以便在 Query 侧与 Key 侧之间均衡分摊调整幅度。两个矩阵各承担一半回缩量，乘积恰好把最大 logit 压回阈值 τ；不触发阈值时什么都不做。整个过程不引入新的可训练参数，不改更新方向，只在"越界"的瞬间做一次温和的比例回缩，相当于一个作用在权重空间上的恒温器。

m = max(QKᵀ/√d)；　m > τ ⇒ W_q ← W_q · (τ/m)^α，W_k ← W_k · (τ/m)^(1−α)，α ≈ 0.5
# QK-Clip 最小骨架（示意）
m = (q @ k.T / sqrt(d)).abs().max()   # 本步注意力 logit 最大值
if m > tau:                           # tau：预设安全阈值
    eta = tau / m                     # 超出比例，eta < 1
    w_q.data *= eta ** alpha          # Query 侧分摊 alpha
    w_k.data *= eta ** (1 - alpha)    # Key 侧分摊剩余部分

效果：可查证的稳定性数据

训练稳定性数据：Kimi K2 世代在 15.5T（15.5 万亿）token 的高强度连续预训练中，搭载 MuonClip 的集群实现了全程零 loss spike 的平滑收敛——这是当时公开资料中首个在此规模上无不稳定事件训完的开放权重 MoE。日志显示，仅训练初期约 13% 的注意力头触发了 QK-Clip 机制，随着模型自行调整到稳定区间，触发比例持续回落，说明它只在危险的过渡期出手，而非全程干预。

值得注意的因果链是：正因为 QK-Clip 把"激进的 Muon 更新"变得可以安全使用，Kimi 才拿得到那约 2 倍的 token 效率；反过来，若只上 QK-Clip 不换优化器，就只是多了一份保险而没有效率收益。稳定性与效率在这里是一对互相成就的组合，而不是此消彼长的权衡。K3 世代在这套地基上叠加 Stable LatentMoE 自身的均衡路由（下一节），进一步降低了优化器侧的兜底压力。

QK-Clip 不像截断阀那样砍掉已经算出来的分数，而是回到水龙头——谁的 logit 超标，就把对应的 Q/K 权重按比例拧小一圈；水管（更新方向）不动，只调水压。

四、MoE 架构设计

混合专家模型（Mixture of Experts，MoE）把 Transformer 每层的前馈网络（FFN）拆成一组并行的专家子网络，每个 token 只路由给其中少数几个专家。FFN 通常占模型参数量与计算量的大头，是"扩容"性价比最高的位置。K3 把这条路线推向极致：896 个细粒度微专家，每个 token 精确激活 16 个——激活率不到 2%，比 K2 的 8/384 更稀疏。

Top-K 门控：一次轻量的专家招标

门控路由器是一个极轻量的线性层，对每个 token 的隐状态算出 896 个专家得分，经 Softmax 归一化后取 Top-K=16，权重重新归一化，最后对 16 个专家的输出做加权和：

y = Σᵢ∈Top-16 Gᵢ · Eᵢ(x)　（G 为 Softmax-TopK 后的路由权重）

K3 的专家布局称为 Stable LatentMoE：token 先被投影到约为主干宽度一半的潜在空间，再送入各专家的 FFN，最后投影回主干。这个"先压缩、再分发"的结构显著降低了专家并行时 all-to-all 的通信量和每专家的参数冗余，是 896 个细粒度专家能在千卡集群上高效铺开的前提。"Stable"前缀指向的是训练稳定性：配合路由层的约束手段，K3 在这个规模上保持了全程平稳的收敛曲线。

负载均衡：防止专家坍缩的关键一战

MoE 训练最经典的灾难是专家坍缩：路由器存在天然的正反馈——某个专家早期稍占优，就被路由更多 token、拿到更多梯度、变得更专业，于是吸引更多 token。不加约束时负载迅速极化，热门专家负载冲到 95% 以上，冷门专家长期低于 20% 甚至彻底"饿死"。一旦坍缩，896 个专家实际只剩几十个在工作，模型容量大打折扣，各 GPU 上的专家负载不均还会拖垮专家并行的通信效率，训练直接发散。

业界标准解法是 Switch Transformer 式的负载均衡辅助损失：把各专家接收 token 的频率与路由概率均值做内积惩罚，逼路由器摊匀。但惩罚系数极难调——调大伤模型质量，调小压不住坍缩。K3 一系采用分位数负载均衡：给每个专家引入可学习偏置 b 加到路由 logits 上，按负载分位数用一条极简的 sign 规则更新：

b ← b − η · sign(qᵢ − q*)　（qᵢ：专家当前负载分位数；q*：目标分位数）

过载专家的偏置被持续压低、闲置专家的偏置被抬高，整个系统像恒温器一样自动收敛到目标负载分布，免去了传统辅助损失那组敏感超参数。这与 QK-Clip 的设计哲学一脉相承：不做粗暴截断，而是加一个作用在参数上的负反馈控制器。

五、训练工程实践

15.5T token 的预训练地基

K3 的训练工程不是从零开始的，它继承的是 Kimi K2 世代验证过的完整流水线——那条在 15.5T（15.5 万亿）token 上跑出零 loss spike 的流水线。这个量级意味着什么：按每秒处理百万 token 计也要连续跑近半年，任何一次数值发散都意味着以周为单位的回滚。MuonClip 的 QK-Clip 机制、分位数负载均衡、专家并行的静态调度，全部是为了把"长跑不出事"从运气变成工程保证。K3 世代的公开材料没有单独披露预训练总 token 数，而是把叙事重心放在扩展效率上：架构与优化器的联合改进让达到同等损失所需计算量降到 K2 路线的约 40%，"更多智能"不再必须用"更多 token"来换。

训练流程遵循三段式：预训练阶段在大规模通用语料上渐进式扩展上下文——先便宜地学短文本，再逐步拉长窗口学程依赖，最终拉满到 1M；中训练（退火）阶段切换到高质量配比数据，上调推理、代码、长文档与多模态样本比例并衰减学习率，把"广"收敛成"准"；后训练阶段做 SFT 与偏好对齐，主路线是 DPO（直接偏好优化）——用一个损失函数直接吃人类偏好对，省去 RLHF 的奖励模型训练环节，训练效率相对传统 RLHF 提升约 5 倍，再辅以可验证环境（代码执行、终端操作）中的强化学习打磨 agent 能力。

系统层：让千卡不掉链子

2.8T 参数的专家并行是另一场硬仗。K3 一系的工程做法包括预计算 token→专家的映射以做静态调度，让各 GPU 上的专家负载尽可能绝对均衡，消除流水线气泡，把 GPU 利用率推向极限；Stable LatentMoE 的潜在空间压缩则直接砍掉 all-to-all 通信量的大头。推理侧，Moonshot 的 Mooncake 基础设施把编程场景的前缀缓存命中率维持在 90% 以上——这是"1M 上下文 + agent 多轮交互"能以合理成本运行的底层支撑。

长上下文：KDA + AttnRes 的协同

1M 上下文对标准 Softmax 注意力是"生死问题"：O(n²) 的计算与随长度线性膨胀的 KV 缓存，在 93 层规模的模型上会涨到不可行的地步。K3 的答案是按约 3:1 混合堆叠：多数层采用 KDA（Kimi Delta Attention）线性注意力——通过改变矩阵乘法顺序 Q·(Kᵀ·V) 把复杂度从 O(n²d) 降到 O(nd²)，并写成只维护固定大小状态的循环形式，每 token 常数成本、无 KV 膨胀；每隔约三层插入一层全局注意力做精确召回兜底。配套的 AttnRes 注意力残差让后层可以越过中间层直接读取更早的注意力表示，形成深度方向的"梯度高速公路"，技术报告口径下深层网络训练稳定性提升约 300%，这是层数敢继续往上堆的底气。KDA 系架构的公开实测：KV 缓存最多削减 75%，1M 上下文下每 token 解码耗时从 11.48ms 降至 1.84ms，提速约 6.3 倍。

长上下文实测数据：KDA 混合架构将 KV 缓存使用量最多削减 75%，在 1M token 上下文下每 token 解码耗时（TPOT）从 11.48ms 降至 1.84ms（提速约 6.3 倍）；在 Kimi Linear 的公平对比实验中（同配方训练），长上下文基准 RULER 得分 84.3 且推理速度提升约 3.98 倍，质量与速度同时拿下——1M 上下文从此不是演示数字，而是用得起的能力。

K3 的训练工程可以概括成一句话：优化器负责"每一步走得更值"，QK-Clip 和负载均衡负责"半年长跑不摔跤"，专家并行和缓存负责"千卡每一秒都不空转"——三者缺一，2.8T 就只是 PPT 上的数字。

Q&A

MuonClip 与 AdamW 的本质区别是什么？为什么 Kimi 团队要换优化器？
AdamW 是一阶逐坐标优化器，只按每个坐标梯度的历史幅度做归一化，对权重矩阵梯度的奇异值分布失衡（条件数大）无能为力，更新仍然主要沿少数主导方向推进。MuonClip 的底座 Muon 先对梯度动量做 Newton-Schulz 正交化，近似取其 SVD 的 U·Vᵀ 因子，相当于把奇异值谱拍平，让梯度指出的每个方向都获得单位幅度推进，因此收敛更快——在 compute-optimal 设定下达到同等损失只需约一半计算量。Kimi 换优化器的直接动机是数据约束：高质量人类数据正在枯竭，token 利用效率成为第一变量，约 2 倍的效率在 15T 级训练上就是天文数字般的算力节省。代价是 Muon 更新更激进，必须配 QK-Clip 才能压住注意力 logit 爆炸。
Newton-Schulz 正交化为什么能加速收敛？每步都算 SVD 不会很贵吗？
收敛速度的瓶颈往往不是梯度的平均大小，而是损失曲面在不同方向上的曲率差异：权重矩阵梯度的奇异值若严重失衡，更新就会反复沿主导方向震荡、在平坦方向上龟速前进。正交化把动量的奇异值谱统一为单位幅度，等价于一个针对矩阵结构的预条件子，让所有方向齐步走，因此可以用更大的有效学习率且不发散。成本方面，Muon 不做真实 SVD，而是用五次 Newton-Schulz 多项式迭代 X ← aX + b(X Xᵀ)X + c(X Xᵀ)²X 逼近正交因子，约 5 轮收敛，全程是 tensor core 最擅长的矩阵乘法，bf16 下数值稳定。每步确实比 Adam 多几轮 matmul，但步数的大幅减少和免调参的可迁移性让总账明显更划算。
QK-Clip 为什么要缩放 W_q/W_k 权重，而不是直接裁剪注意力分数？
直接裁剪注意力分数（logit soft-capping）是在下游打补丁：分数被压扁后 softmax 分布被人为扭曲，模型学到的聚焦模式失真，而且每步前向都要持续干预。QK-Norm 一类张量归一化则没有触及根因——权重本身在持续增长，且在 MLA 架构里 Key 不完全实体化，归一化缺少着力点。QK-Clip 选择在源头做负反馈：发现最大 logit m 超过阈值 τ 时，计算比例 η′=τ/m，把 W_q 乘 η′^α、W_k 乘 η′^(1−α)（α≈0.5），两矩阵各分摊一半回缩，乘积恰好把 logit 压回阈值内。它不改更新方向、不引入可训练参数、不扭曲注意力分布，只在越界的瞬间出手——实测训练初期约 13% 的注意力头触发，随后比例持续回落。
为什么 logit 爆炸在 MLA 这类架构里更难处理？爆炸的后果链是什么？
注意力 logit 是 softmax 的输入，一旦从正常的 10~20 冲到 1000 以上，softmax 输出急剧趋向 one-hot：注意力分布坍缩到个别位置，反向传播的梯度要么消失要么爆炸，紧接着出现 NaN，整个训练 step 报废，价值数百万美元的长跑只能回滚重启。难点在于防御手段的失效：常规 QK-Norm 需要对显式的 Q/K 张量做归一化，而 MLA 为了省显存把 KV 压缩进低维潜在空间，Key 在推理时并不完全实体化，归一化没有稳定的作用对象。这就是 Kimi 选择绕过张量层、直接约束权重矩阵幅度（QK-Clip）的原因——无论 KV 以什么形态存在，W_q/W_k 永远在场。
K3 的 2.8T 总参数和"896 选 16"的激活方式是什么关系？部署按哪个数字算账？
2.8T 是模型容量：全部 896 个路由专家、共享专家、注意力投影和 Embedding 的参数总和，决定模型能装下多少知识。每个 token 前向时只被路由给 16 个专家，加上共享专家和公共模块，真正参与计算的只是总量的零头——激活率不到 2%，这就是稀疏 MoE"容量与算力解耦"的本质。但解耦是有边界的：推理时任何专家都可能被下一个 token 命中，所以全部 2.8T 权重必须驻留在显存/内存里，显存账单仍按 2.8T 计算。结论是：算力成本按激活参数估算（便宜），显存与部署难度按总参数估算（必须多卡分布式或量化承载），两者不能混用。
MoE 为什么必须做负载均衡？分位数偏置方案比辅助损失好在哪？
Top-K 路由存在天然正反馈：早期稍占优的专家被路由更多 token、拿到更多梯度、变得更专业，进而吸引更多 token。不加约束时负载迅速极化，热门专家负载可冲到 95% 以上，冷门专家低于 20% 甚至彻底饿死——896 个专家实际只有几十个在工作，容量利用率崩塌，专家并行的 all-to-all 通信也因长尾失衡而吞吐骤降，训练最终发散。Switch 式辅助损失通过惩罚"频率×概率"内积逼路由器摊匀，但惩罚系数极敏感：调大伤质量、调小压不住。分位数偏置方案给每个专家一个可学习偏置 b 加进路由 logits，按 b ← b − η·sign(qᵢ − q*) 更新：过载专家偏置被压低、闲置专家被抬高，像恒温器一样自动收敛到目标负载分布，免去敏感系数调参。
K3 的价格比 K2 世代贵约 5 倍，为什么还说它有性价比？什么任务该用、什么任务不该用？
K3 的 API 标价是输入 $3 / 输出 $15（每百万 token），确实远高于 K2 世代；但缓存命中价格压到约 $0.30，而长程 agent 与仓库级代码迭代恰恰是重复上下文占比极高的负载，前缀缓存命中可以吞掉大部分输入成本——Moonshot 的推理基础设施在编程场景把命中率维持在 90% 以上，实际账单可能不升反降。选型上：反复撞 256K 上下文墙、需要多领域深度与长程自主性的硬任务上 K3；日常 PR 级编码留给 K2.7 Code（256K 上下文、更低价格带）；已经在 K2.6 上稳定运行的长任务没必要为 logo 升级。K3 是旗舰层，不是 K2.7 的免费改名。
为什么说 K3 对研究界的价值可能大于其直接使用价值？
K3 是第一个进入 3 万亿参数级并开放完整权重的模型，这意味着社区第一次可以对一个真实训完的 3T 级样本做完整剖析：896 专家的路由分布是否真的均衡、Stable LatentMoE 的潜在空间压缩带来多大的通信收益、Per-Head Muon 相对全矩阵正交化的增益、KDA 与全局注意力 3:1 混合在超长序列上的实际召回表现——这些此前只能在论文里读到的设计，第一次有了可以逐层验证的实物。配合 K2 世代留下的 MuonClip 开源实现与 15.5T token 零 loss spike 的公开记录，Kimi 系列实际上给出了一条从 1T 到 2.8T 的、可复现的超大规模 MoE 训练路线图，这是闭源旗舰永远不会提供的公共品。
